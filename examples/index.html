예시 자료로 직접 해 보기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 내 업무 자료를 넣기 전에 예시 자료로 먼저 연습해 보고 싶을 때
  • 업무 페이지의 요청문을 그대로 보내 결과를 비교해 보고 싶을 때
  • 체험 장비에서 해 볼 예제 파일이 필요할 때

업무별로 해 보기 페이지의 예시 자료를 zip 파일로 받습니다.
zip 하나에 자료 폴더 하나와 읽어 보세요.txt가 들어 있습니다.
읽어 보세요.txt에는 보낼 요청문, 받게 될 결과, 같이 볼 페이지가 적혀 있습니다.

1. 받아서 내 PC에 풉니다​

아래 카드에서 내려받기를 누르면 zip 파일을 내려받습니다.
압축을 내 PC의 편한 곳에 풉니다.

이렇게 보이면 된 것 자료 폴더 하나와 읽어 보세요.txt가 보입니다.

2. 폴더를 고르고 요청문을 보냅니다​

새로 생성을 누르고 푼 자료 폴더를 (맡길 파일을 넣어 둔 폴더)로 고릅니다.
폴더를 고르는 법은 체험 첫날에 있습니다.
업무 페이지의 요청문 카드에서 복사를 누르고, 입력창에 붙여 넣어 보냅니다.

이렇게 보이면 된 것 보낸 요청문이 대화에 보이고, 에이전트가 폴더의 파일을 읽기 시작합니다.

요령

읽어 보세요.txt에서 복사할 때는 "여기부터" 줄과 "여기까지" 줄 사이만 복사합니다.

3. 결과를 업무 페이지와 대조합니다​

읽어 보세요.txt의 결과 맞춰 보기나 업무 페이지의 확인할 점 표를 보며, 받은 결과를 폴더의 원본 파일과 맞춰 봅니다.
결과는 초안입니다.
숫자와 근거 조항은 원본 파일에서 직접 찾아봅니다.

사무⁠·⁠기획 예제​

월간 업무보고 초안지난달 양식으로 이번 달 업무보고 초안을 한글 파일로 받습니다.구성10월 보고서(한글, 7장·표 9개), 11월 실적(엑셀 6시트)따라 할 페이지월간 업무보고 초안 받기내려받기34KB
과업내용서 초안작년 범위에 올해 계획을 더한 과업내용서 초안과 바뀐 부분 표를 받습니다.구성작년 제안요청서(한글, 7장·표 14개), 올해 사업계획 발췌(한글)따라 할 페이지과업내용서 초안 받기내려받기28KB
업체 월간보고 검수과업지시서와 대조해 빠졌거나 기준에 못 미치는 항목과 보완 요청 문구를 받습니다.구성과업지시서(한글, 12조), 업체 10월 월간보고서(Word, 표 12개)따라 할 페이지업체 월간보고서 검수하기내려받기22KB
회의록 정리40분 회의 전사로 결정 3줄, 후속 업무 표, 보류 안건을 받습니다.구성회의 전사(화자 6명, 텍스트)따라 할 페이지회의록 정리하기내려받기12KB
계약서 점검용역계약서를 사내 기준표와 대조해 세 항목의 판정을 받습니다.구성용역계약서(Word, 21조·특약 5), 점검 기준표(엑셀 25항목)따라 할 페이지계약서를 사내 점검 기준과 대조하기내려받기19KB
인수인계 정리보조금 지급 업무 인수인계 자료로 업무 순서와 확인 질문을 받습니다.구성인터뷰 전사, 메모, 매뉴얼, 메일(텍스트), 체크리스트(엑셀)따라 할 페이지인수인계 자료 정리하기내려받기13KB
개정 규정 질의청년 월세 지원 지침 개정 전후로 날짜에 맞는 버전, 필수 서류, 근거 조항을 세 줄로 받습니다.구성개정 전후 지침, 개정 알림(한글), 질의 목록(엑셀)따라 할 페이지개정 규정에서 적용 기준 찾기내려받기33KB

개발⁠·⁠운영 예제​

공공시설 예약 시스템결함을 고쳐 장애 처리 보고서를 쓰고, DB 구조 정의서와 한글 파일을 받습니다.구성예약 서버 소스(Python), 테스트, 운영 DB 사본(SQLite)따라 할 페이지결함을 고치고 장애 처리 보고서 쓰기DB 구조 정의서 만들기결과를 한글 문서로 저장하기내려받기759KB
민원 포털 소스문서가 README 하나뿐인 소스로 근거 경로가 붙은 현행 분석서를 받습니다.구성포털 소스(Java·JSP·SQL 매핑), 배치 설정, README따라 할 페이지현행 분석서 만들기내려받기226KB
쇼핑몰 소스보안 문제 네 가지를 넣어 둔 소스로 보안 검토를 해 봅니다.구성주문 처리 소스(Java·JSP·SQL 매핑), DB 정의, 정산 배치따라 할 페이지코드 보안 검토하기내려받기10KB

알아 둘 점​

  • 예시 자료에 나오는 기관, 이름, 숫자, 주소는 모두 연습용으로 만든 것입니다.
  • 에이전트가 폴더 안의 파일을 고칩니다. 다시 해 볼 때는 압축을 새로 풉니다.
  • 민원 포털 소스와 쇼핑몰 소스에는 보안 검토를 연습하도록 일부러 넣은 가짜 비밀번호와 내부 주소가 있습니다.
  • 보안 검토는 커밋하지 않은 변경이 없으면 마지막 커밋 전체를 봅니다. 쇼핑몰 소스는 Git으로 저장소를 만들고 한 번 커밋한 뒤 보냅니다.
  • 내 자료로 바꿀 때는 업무 페이지의 "우리 상황에 맞게 아래 말만 바꿉니다" 표를 봅니다.

다음에 볼 글

업무별로 해 보기월간 업무보고, 과업내용서, 보고서 검수, 회의록, 계약서 점검, 인수인계, 규정 질의 같은 사무 업무와 개발·운영 업무를 받는 결과물로 골라 따라 합니다.체험 첫날설치가 끝난 PC에서 설치 확인, 웹 화면 열기, 첫 요청, 월간 업무보고 같은 업무 하나까지 체험 첫날 순서대로 해 봅니다. 교육 뒤에도 이 페이지를 보며 다시 따라 합니다.요청문 모음업무별 요청문을 사무·기획과 개발·운영으로 나눠 모았습니다. 복사해서 우리 자료에 맞게 고쳐 씁니다.
