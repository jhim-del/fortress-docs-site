관리 화면 둘러보기

Fortress AI 2.6.1 · 게이트웨이 3.3.0 기준

이럴 때 봅니다

  • 관리 화면에 어떤 메뉴가 있고 무엇을 하는지 알고 싶을 때
  • 관리자 계정과 사용자 계정이 무엇이 다른지 정할 때
  • 임직원이 "오류가 났다"고 할 때 원인을 찾을 때

관리 화면은 브라우저로 <장비 주소>:8080/admin을 열어 씁니다.
모든 계정이 로그인할 수 있고, 사용자는 자기 것만, 관리자는 모든 사용자의 것을 봅니다.
화면은 운영체제 설정을 따라 밝은 화면이나 어두운 화면으로 보입니다.

메뉴​

메뉴는 왼쪽 사이드바에 있습니다.
위에서부터 개요⁠·⁠토큰 사용량⁠·⁠호출 기록, 내 계정 그룹, 관리 그룹 순서입니다.
사이드바 맨 아래 계정 줄을 누르면 내 정보, 클라이언트 설치, 로그아웃이 나옵니다.

메뉴누가하는 일
개요모두24시간 동안의 호출, 실패, 취소와 그 흐름, 실패 종류, 모델 서버 연결과 버전. 로그인하면 처음 보는 화면입니다.
토큰 사용량모두기간의 호출, 실패, 토큰 합계와 일자별⁠·⁠유저별⁠·⁠모델별 차트와 표. CSV로 내보냅니다.
호출 기록모두7일 안의 기간을 결과, 실패 종류, 유저로 필터링해 호출과 세션을 봅니다.
내 정보모두계정 정보, 비밀번호 바꾸기
API Key모두내 API 키 만들기와 폐기
로그인한 기기모두Fortress AI 클라이언트와 관리 화면으로 로그인한 기기를 보고 로그인을 끊습니다.
유저관리관리자한 명이나 여러 명 추가, 30일 사용량. 사용자를 열면 실패, 키, 기기, 기록과 계정, 비밀번호, 사용 중지
전체 API Key관리자모든 사용자의 키를 보고 폐기합니다.
감사 기록관리자로그인, 계정, 키, 기기에 한 일을 기간과 사용자로 필터링해 봅니다. CSV로 내보냅니다.

클라이언트 설치는 홈 화면을 엽니다.
관리 화면에서 임직원에게 설치 순서를 보여 줄 때 씁니다.

사이드바 위의 찾기 칸에 (모델 호출마다 붙는 번호)의 앞 8자리 이상이나 아이디를 넣으면 그 호출이나 사용자로 갑니다.
요청 ID의 앞자리는 만든 시각이어서, 앞자리가 여러 호출과 맞으면 그 시각의 호출 기록을 엽니다.
사용자의 찾기 칸은 요청 ID만 받습니다.

관리자와 사용자​

계정의 권한은 와 둘입니다.
둘 다 Fortress AI로 일할 수 있고, 관리 화면에서 볼 수 있는 범위가 다릅니다.

찾기 칸내 호출 가운데서 요청 ID로 찾습니다.모든 호출과 사용자를 찾습니다.

사용자가 관리자 메뉴의 주소를 직접 열면 "관리자 전용 화면"과 개요로 버튼이 나옵니다.

설치 때 만든 첫 관리자 admin 말고도 관리자를 더 둘 수 있습니다.
관리자 권한 부여에 순서가 있습니다.

주의

관리자 계정은 모든 사용자의 계정과 API 키를 다룹니다.
관리 담당자에게만 관리자 권한을 줍니다.

개요​

로그인하면 처음 보는 화면입니다.

위에서부터 아래가 차례로 나옵니다.

  • 24시간 호출, 24시간 실패, 24시간 취소. 관리자에게는 7일 동안 쓴 유저, 사용자에게는 이번 달 토큰이 나옵니다.
  • 최근 24시간 흐름 막대
  • 실패 종류 표
  • 상태: 모델 서버 연결, 모델, 게이트웨이 버전, 주소, 이 장비에 올린 클라이언트 버전
  • 관리자에게는 토큰(최근 7일, 이번 달), 사용자에게는 바로 가기

모델 서버에 연결되지 않으면 맨 위에 "모델 서버에 닿지 않습니다" 알림이 나옵니다.
사용자가 답을 받기 전에 끊은 호출은 취소로 보이고, 실패로 세지 않습니다.

사용자의 바로 가기에는 API Key, 로그인한 기기, 클라이언트 설치가 있습니다.

토큰 사용량​

기간을 고르면 그 기간의 호출, 실패, 입력 토큰, 캐시 토큰, 출력 토큰 합계가 나옵니다.
아래에는 일자별⁠·⁠유저별⁠·⁠모델별 차트와 표가 있고, 유저별은 관리자에게만 나옵니다.

  • 기간: 7일, 30일, 90일, 이번 달, 지난달, 또는 시작과 끝 날짜를 넣고 보기
  • 날짜와 시각은 한국 시간입니다.
  • 차트는 많이 쓴 12개만 막대로 그리고 나머지는 한 줄로 합칩니다. 표에는 모두 나옵니다.
  • 관리자는 아이디를 넣어 한 명만 봅니다.
  • CSV도 화면과 같은 필터를 따릅니다. 날짜⁠·⁠사용자⁠·⁠모델마다 나눈 세부는 CSV로 받습니다.

월별 사용 보고에는 지난달을 고르고 CSV로 받으면 됩니다.

호출 기록​

기간 안의 호출을 필터링해 조회하는 화면입니다.
제목 옆에 90일 보관이 표시됩니다.

필터값
기간1시간, 24시간, 7일, 또는 시작과 끝을 넣은 7일 안의 기간
결과전체, 실패, 취소, 성공
실패 종류실패 종류 표의 한 줄
유저아이디를 입력해 고릅니다(관리자).

위에는 기간의 호출, 실패, 취소 수와 호출 흐름 막대가 있습니다.
흐름 막대의 한 칸을 누르면 그 칸의 기간으로 좁혀집니다.

호출 탭은 시각, 유저, 도구, 모델, 결과, 첫 응답, 전체, 토큰을 보여 줍니다.
세션 탭은 대화마다 마지막 호출, 유저, 도구, 길이, 호출, 실패, 토큰을 보여 줍니다.

필터 값은 모두 주소에 들어가, 그 주소를 다른 관리자에게 보내면 같은 화면이 열립니다.
호출 하나를 열면 원인(실패 종류, 게이트웨이⁠·⁠모델 서버 쪽인지 요청 쪽인지, 볼 곳)과 같은 세션의 앞뒤 호출이 나옵니다.
관리자에게는 앞뒤 5분 동안 같은 종류로 실패한 사용자 수도 나옵니다.

"오류가 났다"는 연락을 받았을 때​

  1. 언제, 어느 아이디로 겪었는지 묻습니다. 요청 ID를 알면 함께 받습니다.
  2. 개요에서 실패 종류 표와 모델 서버 연결을 봅니다.
  3. 호출 기록에서 그 무렵의 기간, 결과 실패, 그 사용자의 아이디로 필터링합니다.
  4. 실패한 호출을 열어 원인과 볼 곳을 봅니다.
  5. 앞뒤 5분 동안 같은 종류로 실패한 사용자 수를 봅니다. 여럿이면 여러 사용자가 겪은 장애이고, 한 명이면 그 사용자의 문제입니다.

요청 ID를 받았으면 3~4 대신 찾기 칸에 앞 8자리 이상을 넣어 그 호출을 엽니다.

이렇게 보이면 된 것 실패한 호출의 원인과 볼 곳이 보입니다.

계정을 만드는 순서는 도입 첫날에 있습니다.

비밀번호 다시 정하기​

비밀번호를 잊었거나 처음 비밀번호를 놓친 사용자에게 씁니다.

  1. 유저관리에서 그 사용자를 엽니다.
  2. 비밀번호 다시 정하기에 새 비밀번호와 새 비밀번호 확인을 넣고 정하기를 누릅니다.
  3. 전할 안내가 다시 나오면 안내 복사로 그 사용자에게 보내고, 새 비밀번호는 따로 알려 줍니다.

다시 정하면 그 사용자의 모든 기기 로그인이 끝납니다.
그 사용자는 PC에서 새 비밀번호로 fortress login을 다시 합니다.

이렇게 보이면 된 것 화면 위에 "비밀번호를 정했습니다"가 나옵니다.

누가 바꾸나어디서로그인이 끝나는 곳
본인내 정보의 바꾸기바꾼 브라우저 말고 다른 기기 모두
관리자그 사용자 화면의 정하기그 사용자의 모든 기기

사용자가 스스로 비밀번호를 다시 정하는 기능은 없습니다.
로그인하지 못하는 상태에서 비밀번호를 잊으면 관리자가 다시 정하는 것이 유일한 방법입니다.
관리자 비밀번호도 제품 안에서 복구하는 기능이 없어 다른 관리자가 다시 정합니다(두 번째 관리자 만들기).

퇴사자 계정 사용 중지​

  1. 유저관리에서 그 사용자를 엽니다.
  2. 맨 아래 사용 중지를 누릅니다. 버튼이 다시 눌러 중지로 바뀌면 한 번 더 누릅니다.
  3. 화면 위에 "사용을 중지했습니다"와 로그인 멈춤, API Key 멈춤이 나옵니다.

사용 중지된 사용자가 로그인하면 "아이디나 비밀번호가 맞지 않습니다"가 나옵니다.
중지됐다는 말은 나오지 않으므로, 그 사용자가 문의하면 사용 중지 탭에서 확인합니다.

이렇게 보이면 된 것 목록의 사용 중지 탭에 그 사용자가 보입니다.

사용 중지 해제​

사용 중지한 사용자가 복귀하면 같은 화면에서 사용 중지를 해제합니다.

  1. 유저관리의 사용 중지 탭에서 그 사용자를 엽니다.
  2. 맨 아래 다시 사용을 누릅니다.

이렇게 보이면 된 것 화면 위에 "다시 쓸 수 있게 했습니다"와 다시 로그인 필요가 나옵니다.

그 사용자는 PC에서 fortress login으로 다시 로그인합니다.

관리자 권한 부여​

  1. 유저관리에서 그 사용자를 엽니다.
  2. 계정 칸의 관리자 스위치를 켜고 저장을 누릅니다.

권한을 바꾸면 그 사용자의 로그인이 끝나고, 다시 로그인해야 합니다.
같은 칸에서 아이디도 바꿉니다.
처음부터 관리자로 만들려면 유저 추가에서 관리자 스위치를 켭니다.

이렇게 보이면 된 것 화면 위에 "저장했습니다"가 나오고, 목록의 관리자 탭에 그 사용자가 보입니다.

API Key​

(다른 개발 도구를 게이트웨이에 연결하는 키)를 만들고 폐기합니다.
누구나 자기 키를 만듭니다.
Fortress AI 클라이언트는 키 없이 브라우저 승인으로 로그인하므로, Fortress AI만 쓰는 임직원에게는 키가 필요 없습니다.

  1. 새 키의 이름에 쓰는 곳을 알아볼 이름을 넣습니다(1~64자).
  2. 만료에서 30일, 90일, 1년, 없음 가운데 하나를 고릅니다. 처음 값은 90일입니다.
  3. 만들기를 누릅니다.
  • 키 값은 한 번만 보임입니다. 복사로 그 자리에서 옮겨 둡니다. 목록에는 앞자리만 남습니다.
  • 키는 axk_로 시작합니다.
  • 도구 연결을 펼치면 다른 도구의 연결 설정 예가 탭으로 나옵니다. 키를 만든 직후에는 그 키가 들어간 설정이 나옵니다.
  • 내 키 목록에는 이름, 앞자리, 상태, 마지막 사용, 만든 때, 만료가 나오고 CSV로 내보냅니다.
  • 쓰고 있는 키는 한 명에 10개까지입니다. 11번째를 만들면 "사용 중인 키는 10개까지입니다"가 나옵니다.
  • 줄 끝의 폐기를 누르면 다시 눌러 폐기로 바뀝니다. 한 번 더 누르면 "키를 폐기했습니다"가 나오고 상태가 폐기됨이 됩니다.

사용 중과 전체 탭으로 나눠 보고, 줄마다 유저가 함께 나옵니다.
여러 키를 골라 한 번에 폐기하고, 목록을 CSV로 내보냅니다.

로그인한 기기​

Fortress AI 클라이언트와 관리 화면으로 로그인한 기기가 나옵니다.
줄마다 기기, 마지막 사용, 로그인, 만료가 있고, 지금 쓰는 브라우저에는 이 브라우저가 붙습니다.

  • 줄 끝의 로그아웃으로 그 기기의 로그인을 끊습니다. PC를 잃어버렸을 때 씁니다.
  • 다른 기기 모두 로그아웃을 두 번 누르면 지금 브라우저 말고 모두 끊고 "다른 기기를 모두 로그아웃시켰습니다"가 나옵니다.
  • 만료는 로그인한 날부터 90일 뒤입니다. 30일 동안 쓰지 않아도 끝납니다.

로그인이 끝난 PC의 클라이언트에는 "다시 로그인하세요"가 나옵니다.

내 정보​

아이디, 권한, 가입, 마지막 로그인이 나오고, 아래에서 비밀번호를 바꿉니다.
연결 칸에는 사용 중인 API 키 수와 로그인한 기기 수가 나옵니다.

  1. 지금 비밀번호, 새 비밀번호, 새 비밀번호 확인을 넣습니다.
  2. 바꾸기를 누릅니다.

이렇게 보이면 된 것 화면 위에 "비밀번호를 바꿨습니다"가 나옵니다.

새 비밀번호는 8자 이상 256자 이하이고, 글자 종류를 섞으라는 요구는 없습니다.
두 칸이 다르면 일치하지 않음이 나옵니다.
바꾸면 지금 브라우저는 로그인된 채 남고, 다른 기기의 로그인은 끝납니다.

참고

같은 계정으로 첫 실패부터 15분 안에 비밀번호를 5번 틀리면 그다음 시도부터 15분 동안 막힙니다.
이때 "실패가 많아 15분 동안 막았습니다"가 나오고 로그인과 기기 승인이 모두 안 됩니다.

접속하는 PC나 주소가 달라도 같은 계정이면 함께 셉니다.
내 정보에서 지금 비밀번호를 틀린 것도 같은 횟수에 들어갑니다.

관리 화면에는 잠금 표시나 잠금 풀기가 없고, 관리자가 비밀번호를 다시 정해도 풀리지 않습니다.
15분 뒤 다시 로그인합니다.

감사 기록​

관리자가 로그인, 계정, API 키, 기기에 한 일을 보는 곳입니다.
제목 아래 읽기 전용이 표시됩니다.

  • 기간은 24시간, 7일, 30일, 90일이나 시작과 끝 날짜로 고르고 보기를 누릅니다.
  • 날짜 옆 칸에 아이디를 넣어 한 명으로 좁힙니다. 한 명으로 좁히면 그 사용자가 한 일, 그 사용자에게 한 일, 그 아이디로 시도한 로그인 실패가 함께 나옵니다.
  • 분류 탭 전체, 로그인, 계정, API Key, 기기로 좁힙니다.
  • 표에는 시각, 누가, 동작, 대상, 접속한 곳(IP 주소와 브라우저⁠·⁠운영체제)이 나옵니다.
  • 로그인 옆에는 어디로 로그인했는지 관리 화면이나 기기가 붙습니다.
  • 로그인 실패와 이미 쓴 로그인 토큰이 다시 쓰인 기록은 줄 앞의 점으로 구별합니다.
  • 없는 아이디로 시도한 로그인 실패는 남기지 않습니다. 비밀번호를 아이디 칸에 잘못 친 경우 그 값이 기록에 남지 않게 하려는 것입니다.
  • CSV로 내보냅니다. 파일 이름은 ax-fortress-audit-<시작>_<끝>.csv 형식이고, 스프레드시트에서 열어도 칸의 값이 수식으로 실행되지 않습니다.
