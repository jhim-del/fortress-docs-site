도입 첫날: 계정 발급과 전달

Fortress AI 2.6.1 · 게이트웨이 3.3.0 기준

이럴 때 봅니다

  • Fortress AI 장비를 막 받아 임직원 계정을 발급해야 할 때
  • 처음 받은 관리자 계정으로 무엇부터 할지 정할 때
  • 임직원이 아이디와 비밀번호를 어디서 받는지 물을 때

Fortress AI 계정은 회사의 관리자가 발급해 임직원에게 전달합니다.
임직원은 받은 아이디와 비밀번호로 각자 PC에서 로그인합니다.
관리자가 쓰는 화면은 게이트웨이의 (계정과 사용 기록을 다루는 웹 화면)입니다.

순서누가할 일이렇게 보이면 된 것
1설치 담당자장비 설치와 첫 관리자 계정 인수브라우저로 장비 주소를 열면 홈 화면이 나옵니다.
2관리자관리 화면 로그인과 비밀번호 바꾸기"비밀번호를 바꿨습니다"가 나옵니다.
3관리자두 번째 관리자 만들기유저관리의 관리자 탭이 2입니다.
4관리자임직원 계정 만들기유저관리 목록에 새 아이디가 보입니다.
5관리자계정 정보 전달임직원마다 전할 안내와 처음 비밀번호를 받습니다.
6임직원설치하고 로그인하기브라우저에 "○○ 계정으로 승인했습니다"가 나옵니다.
7관리자로그인 확인유저관리에 그 사용자의 마지막 로그인 시각이 보입니다.

쓰는 주소 두 개​

주소열리는 화면누가
<장비 주소>:8080(클라이언트 설치 명령이 있는 첫 화면)임직원
<장비 주소>:8080/admin관리 화면관리자. 임직원도 자기 비밀번호를 바꿀 때 엽니다.

<장비 주소>는 설치 담당자가 알려 주는 장비의 사내 주소입니다.
게이트웨이는 8080 포트를 씁니다.

1. 장비 설치를 마치고 첫 관리자 계정을 인수합니다​

설치 담당자가 장비에 게이트웨이를 설치합니다.
설치할 때 첫 관리자 계정이 하나 만들어집니다.
아이디는 admin이고, 비밀번호는 설치할 때 정합니다.

설치 담당자에게 아래 두 가지를 받습니다.

  • 장비 주소
  • 첫 관리자 admin의 비밀번호

이렇게 보이면 된 것 관리자 PC의 브라우저로 <장비 주소>:8080을 열면 홈 화면이 나옵니다.

주의

관리자 계정은 모든 사용자의 계정과 API 키를 다룹니다.
첫 관리자 비밀번호는 관리 담당자만 알게 둡니다.
관리자 계정은 두 명 이상 둡니다(3단계).

2. 관리 화면에 로그인하고 비밀번호를 바꿉니다​

  1. 브라우저에서 <장비 주소>:8080/admin을 엽니다.
  2. 로그인 화면의 아이디에 admin, 비밀번호에 받은 비밀번호를 넣고 로그인을 누릅니다.
  3. 왼쪽 사이드바의 내 정보를 엽니다.
  4. 지금 비밀번호, 새 비밀번호, 새 비밀번호 확인을 넣고 바꾸기를 누릅니다.

아이디나 비밀번호가 틀리면 "아이디나 비밀번호가 맞지 않습니다"가 나옵니다.
로그인 화면에는 비밀번호 찾기가 없습니다.

새 비밀번호는 8자 이상 256자 이하로 정합니다.
글자 종류를 섞으라는 요구는 없습니다.

비밀번호를 바꾸면 지금 쓰는 브라우저는 로그인된 채 남고, 이 계정으로 로그인한 다른 기기의 로그인은 끝납니다.
화면의 다른 기기 로그아웃 표시가 이 뜻입니다.

이렇게 보이면 된 것 화면 위에 "비밀번호를 바꿨습니다"가 나옵니다. 다음 로그인부터 새 비밀번호를 씁니다.

3. 두 번째 관리자를 만듭니다​

관리자 비밀번호를 잊으면 제품 안에서 복구하는 기능은 없습니다.
다른 관리자가 유저관리에서 그 비밀번호를 다시 정하는 것이 유일한 방법입니다.
첫날에 관리자 계정을 하나 더 만들어 둡니다.

  1. 유저관리에서 유저 추가를 누릅니다.
  2. 아이디, 처음 비밀번호, 비밀번호 확인을 넣습니다.
  3. 관리자 스위치를 켜고 추가를 누릅니다.
  4. 두 번째 관리자는 다른 관리 담당자가 맡고, 받은 뒤 내 정보에서 비밀번호를 바꿉니다.

관리 담당자가 더 있으면 담당자마다 계정을 만듭니다.
감사 기록에 누가 무엇을 했는지 계정마다 남습니다.

이렇게 보이면 된 것 유저관리의 관리자 탭 숫자가 2입니다.

4. 임직원 계정을 만듭니다​

사이드바의 유저관리에서 만듭니다.
위쪽 버튼 유저 추가로 한 명씩, 여러 명 추가로 한꺼번에 만듭니다.

유저 추가여러 명 추가
입력 항목아이디, 처음 비밀번호, 비밀번호 확인, 관리자 스위치아이디 칸에 한 줄에 하나씩, 한 번에 최대 200명
(계정을 만들 때 정해지는 첫 비밀번호)관리자가 정합니다.게이트웨이가 한 명씩 만듭니다.
추가한 뒤그 사용자의 화면이 열리고 "유저를 추가했습니다"와 전할 안내가 나옵니다.처음 비밀번호 칸에 아이디,비밀번호 줄이 나옵니다.
쓰는 경우몇 명만 추가할 때, 관리자를 만들 때부서 단위로 한꺼번에 발급할 때

아이디는 1자 이상 128자 이하이고, 띄어쓰기와 제어 문자를 넣을 수 없습니다.
비밀번호는 8자 이상 256자 이하입니다.
사번이나 메일 아이디처럼 누구인지 알아볼 수 있는 값을 쓰면 사용량과 호출 기록에서 찾기 쉽습니다.

여러 명 추가의 결과​

추가를 누르면 처음 비밀번호 칸에 만든 계정 수와 아이디,비밀번호 줄이 나옵니다.
모두 복사를 누르면 이 줄을 통째로 복사합니다.
만들지 못한 아이디는 아래 추가하지 못한 아이디 표에 까닭과 함께 나옵니다.

주의

처음 비밀번호는 한 번만 보임입니다.
이 화면을 떠나면 다시 볼 수 없으므로 모두 복사로 그 자리에서 옮겨 둡니다.
놓쳤으면 그 사용자를 열어 비밀번호를 다시 정합니다.

같은 아이디를 두 줄에 넣으면 한 명만 만들어집니다.

자세히: 계정을 만들 때 나오는 문구
나오는 문구원인
비밀번호는 8자 이상이어야 합니다처음 비밀번호가 8자보다 짧습니다.
비밀번호는 256자를 넘을 수 없습니다처음 비밀번호가 256자보다 깁니다.
아이디에 공백이나 제어 문자를 쓸 수 없습니다아이디에 띄어쓰기가 있습니다.
아이디는 1~128자여야 합니다아이디가 128자보다 깁니다.
이미 있는 아이디입니다같은 아이디가 이미 있습니다.

이렇게 보이면 된 것 유저관리 목록의 전체 탭에서 새 아이디가 보입니다.

5. 계정 정보를 전달합니다​

유저 추가로 만들면 그 사용자의 화면에 전할 안내가 나옵니다.
안내 복사를 눌러 메일이나 메신저에 붙여 보냅니다.
비밀번호를 다시 정했을 때도 같은 안내가 나옵니다.

안내에는 아래가 들어 있습니다.

  • 아이디
  • 홈 화면 주소에서 클라이언트를 설치하는 순서
  • 터미널에서 fortress login <주소>를 실행하고 브라우저에서 승인하는 순서
  • <주소>/admin에 로그인해 내 정보에서 비밀번호를 바꾸는 순서

안내에는 비밀번호가 들어 있지 않습니다.
처음 비밀번호는 안내와 따로 전합니다.
여러 명 추가로 만든 계정은 전할 안내가 나오지 않으므로, 한 명의 안내를 복사해 아이디만 바꿔 보냅니다.

주의

보내기 전에 안내에 든 주소가 임직원 PC에서 여는 장비 주소인지 봅니다.
주소가 127.0.0.1이나 localhost이면 임직원 PC에서 동작하지 않으므로 장비 주소로 고쳐 보냅니다.

처음 로그인할 때 비밀번호를 바꾸라는 요구는 나오지 않습니다.
임직원이 내 정보에서 비밀번호를 바꾸면 그 브라우저 말고 다른 기기의 로그인이 끝납니다.

PC에서 fortress login으로 한 로그인도 다른 기기에 포함됩니다.
안내의 3번(비밀번호 바꾸기)을 1번보다 먼저 하면 PC에서 다시 로그인할 일이 없습니다.

이렇게 보이면 된 것 임직원마다 전할 안내와 처음 비밀번호를 받았습니다.

6. 임직원이 설치하고 로그인합니다​

임직원은 받은 안내와 설치하고 첫 요청 보내기의 순서를 따릅니다.

  1. 자기 PC의 브라우저로 홈 화면을 열고, 설치 명령을 복사해 터미널에서 실행합니다.
  2. 브라우저에 기기 로그인 화면이 열리면 코드가 터미널의 코드와 같은지 봅니다.
  3. 아이디와 비밀번호를 넣고 승인을 누릅니다.
  4. fortress doctor로 설치를 점검합니다.

승인하면 "○○ 계정으로 승인했습니다"와 "이 창은 닫아도 됩니다"가 나옵니다.
거부를 누르면 "로그인을 거부했습니다"가 나옵니다.

코드는 15분 동안 유효합니다.
지났거나 없는 코드면 "코드가 없거나 만료되었습니다"가 나오고, 터미널에서 fortress login을 다시 실행합니다.

Fortress AI 클라이언트는 API 키 없이 이 브라우저 승인으로 로그인합니다.

이렇게 보이면 된 것 fortress doctor 끝에 "모두 정상입니다."가 나옵니다.

7. 로그인을 확인합니다​

관리 화면에서 임직원이 로그인했는지 봅니다.

보는 곳보이는 것
유저관리 목록줄마다 30일 토큰, 30일 호출, 30일 실패, 마지막 사용, 마지막 로그인
유저관리에서 사용자를 연 화면로그인한 기기에 그 사용자가 로그인한 기기. 클라이언트로 로그인한 기기 이름은 Fortress AI on <PC 이름> 형식입니다.
개요24시간 호출과 7일 동안 쓴 유저

이렇게 보이면 된 것 유저관리에서 그 사용자의 마지막 로그인에 시각이 보입니다.

그다음에 하는 일​

이럴 때할 일
비밀번호를 잊은 임직원이 있을 때유저관리에서 그 사용자를 열어 비밀번호 다시 정하기를 합니다. 비밀번호 다시 정하기
퇴사자가 생겼을 때그 사용자를 사용 중지합니다. 퇴사자 계정 사용 중지
사용 중지한 사용자가 복귀했을 때그 사용자 화면에서 다시 사용을 누릅니다. 사용 중지 해제
사용량을 보고해야 할 때토큰 사용량에서 기간을 고르고 CSV로 받습니다. 토큰 사용량
"오류가 났다"는 연락을 받았을 때호출 기록에서 그 시각과 아이디로 조회합니다. 원인 찾기
조직 공통 규칙을 걸 때관리자 정책을 배포합니다.

안 될 때​

증상확인할 것
처음 비밀번호를 옮겨 두지 못했습니다처음 비밀번호는 다시 볼 수 없습니다. 유저관리에서 그 사용자를 열어 비밀번호 다시 정하기를 합니다.
"실패가 많아 15분 동안 막았습니다"가 나옵니다같은 계정으로 첫 실패부터 15분 안에 5번 틀리면, 그다음 시도부터 15분 동안 그 계정의 로그인과 기기 승인이 막힙니다. 다른 계정은 영향이 없습니다. 관리 화면에서 잠금을 푸는 기능은 없고, 관리자가 비밀번호를 다시 정해도 풀리지 않습니다. 15분 뒤 맞는 비밀번호로 로그인합니다.
맞는 비밀번호인데 "아이디나 비밀번호가 맞지 않습니다"가 나옵니다사용 중지된 계정도 같은 문구가 나옵니다. 관리자가 유저관리의 사용 중지 탭에 그 아이디가 있는지 봅니다.
임직원이 비밀번호를 잊었습니다스스로 다시 정하는 기능은 없습니다. 관리자가 유저관리에서 그 사용자를 열어 비밀번호 다시 정하기를 합니다. 그 사용자의 모든 기기 로그인이 끝나므로, 새 비밀번호로 fortress login을 다시 합니다.
관리자 비밀번호를 잊었습니다제품 안에서 복구하는 기능은 없습니다. 다른 관리자가 유저관리에서 그 계정의 비밀번호를 다시 정합니다.
임직원 PC에서 설치 명령이 동작하지 않습니다장비에서 127.0.0.1로 연 홈 화면의 명령을 복사하지 않았는지 봅니다. 임직원 PC의 브라우저로 장비 주소를 열어 명령을 다시 복사합니다.
