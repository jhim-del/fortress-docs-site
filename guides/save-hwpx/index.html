결과를 한글 문서로 저장하기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 업무보고나 과업내용서처럼 한글 파일로 내야 하는 결과를 받을 때
  • 이미 받은 Markdown 결과를 한글 문서로 바꾸고 싶을 때
  • 받은 한글 파일의 표와 줄바꿈을 내기 전에 다듬을 때
입력 자료결과물
한글 파일로 달라는 요청, 또는 이미 만든 Markdown 파일한글(HWPX) 파일

Fortress AI는 결과를 Markdown으로 쓰고, 그것을 한글(HWPX) 문서로 바꿔 저장합니다.
업무 결과를 처음부터 한글 파일로 받으려면 방법 1, 이미 받은 결과를 바꾸려면 방법 2를 씁니다.

방법언제어디서
1. 요청문에 적기결과를 처음부터 한글 파일로 받을 때입력창
2. 파일 칸에서 저장이미 만든 Markdown 파일을 바꿀 때오른쪽 파일 칸의 한글로 저장
3. 터미널 명령웹 화면 없이 터미널에서 바꿀 때터미널의 fortress hwpx

방법 1. 요청문에 한글 파일로 저장해 달라고 적습니다​

요청문 끝에 받을 파일 이름과 함께 한글 파일로 저장해 달라고 적습니다.
아래는 같은 표를 Markdown과 한글 파일 두 가지로 받은 요청문입니다.

예시 자료 내려받기759KB위 요청문을 그대로 해 볼 수 있는 예시 자료(운영 DB 사본이 든 예약 시스템 폴더)입니다. 쓰는 법

사무 업무의 요청문도 같은 방식으로 끝납니다.
월간 업무보고 초안과 과업내용서 초안의 요청문은 "결과는 한글 파일 … 로 저장해줘"로 끝납니다.

(실행 전에 묻는 확인 창)가 뜨면 무엇을 하려는지 읽고 허용합니다.

이렇게 보이면 된 것 답에 .hwpx 파일 이름이 나오고, 답 아래 명령으로 바뀐 파일에도 같은 이름이 보입니다.

오른쪽 결과물 칸에 Markdown 파일만 보이면, 한글 파일은 파일 칸의 폴더에서 찾습니다.

방법 2. 파일 칸에서 Markdown을 한글로 저장합니다​

이미 만들어진 Markdown(.md) 파일을 한글 문서로 바꿉니다.

1. Markdown 파일을 열어 미리 봅니다​

대화 화면 위쪽의 파일을 누르고 .md 파일을 엽니다.
미리보기에서 제목, 문단, 표를 확인합니다.

이렇게 보이면 된 것 파일 내용 위쪽에 미리보기, 원문 탭과 한글로 저장이 보입니다.

2. 한글로 저장을 누릅니다​

한글로 저장을 누르면 HWPX 파일이 내려받아집니다.
파일은 브라우저의 다운로드 설정에 따라 저장됩니다.

이렇게 보이면 된 것 브라우저의 다운로드 목록에 .hwpx 파일이 있습니다.

3. 한글에서 열어 확인합니다​

내려받은 파일을 한글에서 엽니다.
표와 줄바꿈을 확인하고 필요한 부분을 편집합니다.

이렇게 보이면 된 것 한글에서 파일이 열리고 제목, 문단, 표가 보입니다.

한글이 없는 PC에서는 파일 칸에서 .hwpx 파일을 눌러 텍스트만 미리 봅니다(파일 형식).

방법 3. 터미널 명령으로 바꿉니다​

자세히: 터미널 명령
명령하는 일
fortress hwpx <입력.md> [-o 출력.hwpx]Markdown을 한글(.hwpx) 문서로 바꿉니다.
fortress docx <입력.md> [-o 출력.docx]Markdown을 Word(.docx) 문서로 바꿉니다.

--title로 문서 제목을 정하고, --force를 붙이면 이미 있는 파일을 바꿉니다.
다른 터미널 명령은 단축키와 명령에 있습니다.

확인할 점​

내기 전에 담당자가 한글에서 열어 아래를 봅니다.

볼 곳확인할 것
표칸이 밀리거나 합쳐지지 않았는지, 숫자가 Markdown 원문과 같은지 봅니다.
줄바꿈문단과 목록이 원문 순서대로 나뉘었는지 봅니다.
기관 양식결재란, 로고, 글꼴은 한글에서 직접 맞춥니다.

알아 둘 제한​

  • 한글 파일은 Markdown에서 바꿔 만듭니다. 기관 양식의 표 모양과 로고를 그대로 채우는 기능이 아닙니다.
  • 구형 한글 파일(.hwp)은 읽을 수 있는 형식 표에 없습니다. 한글에서 HWPX로 저장한 뒤 씁니다.
  • 형식별로 읽고 만드는 범위는 파일 형식에 있습니다.

막히면

  • 답은 있는데 결과 파일이 없습니다확인할 것 보기
  • 서식이 원본과 다릅니다확인할 것 보기
  • 새 파일이 목록에 없습니다확인할 것 보기
