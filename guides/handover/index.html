인수인계 자료 정리하기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 업무를 넘겨받았는데 설명 기록과 메모가 흩어져 있을 때
  • 처음 맡은 업무의 순서를 한눈에 잡고 싶을 때
  • 자료끼리 말이 달라 선배에게 무엇을 물어야 할지 정리할 때
입력 자료결과물
인수인계 발췌본 (인터뷰 기록과 업무 메모를 모은 텍스트 파일)업무 순서 여섯 줄, 확인 질문 두 개와 근거 ID (대화창)

예시 자료는 선배 담당자 인터뷰 기록 일곱 줄과 개인 업무 메모 세 줄을 한 파일에 모은 것입니다.
줄마다 [INT-07] 같은 ID가 붙어 있습니다.
마감 시각과 입력⁠·⁠검토 담당 분리에 대해 인터뷰와 메모의 말이 다릅니다.

1. 자료를 한 폴더에 모읍니다​

새 폴더를 하나 만들고 인수인계 기록과 메모를 복사해 넣습니다.
이 폴더가 가 됩니다.
(요청을 받아 파일을 읽고 고치고 명령을 실행하는 주체)가 이 폴더에서 일합니다.

이렇게 보이면 된 것 폴더에 인수인계 자료 파일이 있습니다.

예시 자료 내려받기13KB실무 분량의 예시 자료입니다. 요청문은 이 페이지와 같고 파일 이름만 다르며, 압축 안의 읽어 보세요.txt 에 그대로 들어 있습니다. 쓰는 법
요령

요청문은 근거를 ID로 달라고 합니다.
우리 자료에 줄 번호가 없으면 문단마다 번호를 붙여 둡니다.

2. 폴더를 고르고 요청문을 보냅니다​

새로 생성을 누르고 "어디서 작업할까요?"에서 1단계의 폴더를 고릅니다.
아래 요청문을 입력창에 붙여 넣고 보냅니다.

우리 상황에 맞게 아래 말만 바꿉니다.

요청문의 말바꿀 것
인수인계_발췌.txt폴더에 넣은 인수인계 자료 파일 이름
여섯 줄업무 단계 수에 맞는 줄 수
마감 시각과 입력⁠·⁠검토 담당 분리자료끼리 말이 다르거나 비어 있어 물어볼 주제

(실행 전에 묻는 확인 창)가 뜨면 무엇을 하려는지 읽고 허용합니다.

이렇게 보이면 된 것 요청이 대화에 올라가고, 에이전트가 인수인계 자료를 읽기 시작합니다.

3. 업무 순서와 질문을 받습니다​

끝나면 대화창에 업무 순서와 선배에게 물어볼 질문이 나옵니다.
파일로 저장하지 않고 대화창에서 봅니다.

이렇게 보이면 된 것 대화창에 업무 순서 여섯 줄이 있고, 그 아래 질문 두 개에 근거 ID가 붙어 있습니다.

4. 근거 ID를 열어 대조합니다​

대화 화면 위쪽의 파일을 누르고 인수인계 자료를 엽니다.
질문에 붙은 ID의 줄을 찾아 읽고, 자료끼리 정말 말이 다른지 봅니다.

이렇게 보이면 된 것 질문의 근거 ID가 자료에 있고, 서로 다른 설명이 질문으로 남아 있습니다.

확인할 점​

업무를 시작하기 전에 새 담당자가 아래를 직접 대조합니다.

볼 곳확인할 것
순서여섯 줄이 원문의 순서와 같은지 근거 줄을 따라가며 봅니다.
말이 다른 곳자료끼리 다른 설명을 한쪽으로 정해 적지 않았는지 봅니다.
근거 ID질문에 붙은 ID를 원문에서 찾아 읽습니다.
없는 설명원문이 설명하지 않았다고 한 절차를 지어 채우지 않았는지 봅니다.
확정질문의 답은 선배나 규정 담당자에게 받아 확정합니다.
