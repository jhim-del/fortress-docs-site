긴 문서 여러 개 요약 받기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 지침, 규정, 매뉴얼처럼 긴 문서 여러 편을 끝까지 읽혀야 할 때
  • 새로 온 사람에게 줄 요약을 문서별로 받고 싶을 때
  • 읽는 동안 컨텍스트가 얼마나 찼는지 보고 싶을 때
입력 자료결과물
문서 10개가 든 폴더문서별 한 줄 요약, 실수하기 쉬운 점 세 가지와 근거 파일 이름 (대화창)

아래 요청문은 공개된 개발 가이드 문서 10개로 실행했습니다.
규정집이나 업무 매뉴얼 묶음이라면 문서 이름과 물을 내용만 바꿉니다.

1. 문서가 든 폴더를 고르고 요청문을 보냅니다​

새로 생성을 누르고 문서가 든 폴더를 (에이전트가 읽고 고치는 폴더)로 고릅니다.
아래 요청문을 입력창에 붙여 넣고 보냅니다.

우리 상황에 맞게 아래 말만 바꿉니다.

요청문의 말바꿀 것
전자정부 표준프레임워크 가이드 문서 10개폴더에 넣은 문서 묶음의 이름과 개수
새로 온 개발자요약을 받을 사람
iBATIS Dynamic SQL과 resultMap에서 실수하기 쉬운 점 세 가지문서에서 꼭 짚어 받고 싶은 것

이렇게 보이면 된 것 요청이 대화에 올라가고, 에이전트가 문서를 차례로 읽기 시작합니다.

2. 읽는 동안 컨텍스트 칸을 봅니다​

문서를 끝까지 읽히면 읽는 만큼 (에이전트가 답할 때 한 번에 참고하는 내용)가 찹니다.
오른쪽 컨텍스트 칸의 비율로 얼마나 찼는지 봅니다.

이렇게 보이면 된 것 문서를 읽는 동안 컨텍스트 칸의 비율이 오릅니다.

3. 요약을 받습니다​

다 읽으면 대화창에 문서별 한 줄 요약과 실수하기 쉬운 점이 나옵니다.

이렇게 보이면 된 것 문서마다 한 줄씩 요약이 있고, 실수하기 쉬운 점 세 가지에 근거 파일 이름이 붙어 있습니다.

4. 근거 파일을 열어 대조합니다​

답에 적힌 근거 파일 이름으로 파일을 열어 내용이 맞는지 대조합니다.

이렇게 보이면 된 것 열어 본 근거 파일에 답의 내용이 있습니다.

확인할 점​

볼 곳확인할 것
문서 수요약 줄 수가 폴더의 문서 수와 같은지 봅니다. 빠진 문서가 없어야 끝까지 읽은 것입니다.
근거 파일근거로 적힌 파일을 열어 그 내용이 정말 있는지 읽습니다.
요약 활용요약은 초안입니다. 새로 온 사람에게 주기 전에 담당자가 읽어 봅니다.

컨텍스트가 찼을 때​

  • 메시지 옆의 압축을 누르면 지난 대화를 요약해 공간을 비웁니다.
  • 주제가 바뀌면 새 (대화 하나)을 엽니다. 관련 없는 지난 대화가 컨텍스트를 차지하지 않습니다.
  • 자세한 방법은 컨텍스트 압축에 있습니다.

다음에 볼 글

컨텍스트, 모델, 사용 현황에이전트가 한 번에 참고하는 양을 보고 컨텍스트를 압축하는 법, 모델과 노력 수준을 고르는 곳, 모델 서버 상태와 답 하나·기간별 사용량을 보는 법입니다.개정 규정에서 적용 기준 찾기개정 공지와 개정 전후 규정을 함께 읽혀, 특정 날짜의 건에 어느 버전이 적용되고 무엇이 필요한지 근거 조항과 함께 받는 과정입니다.요청문 모음업무별 요청문을 사무·기획과 개발·운영으로 나눠 모았습니다. 복사해서 우리 자료에 맞게 고쳐 씁니다.
