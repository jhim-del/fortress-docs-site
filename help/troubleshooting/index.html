문제 해결

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 화면에 처음 보는 안내가 떴을 때
  • 요청을 보냈는데 결과가 나오지 않을 때
  • 설치나 업데이트 명령이 끝나지 않을 때

증상에서 시작해 먼저 확인할 것을 찾습니다.
같은 작업을 다시 요청하기 전에는 이미 만들어진 결과가 있는지 봅니다.
그래도 풀리지 않으면 담당자에게 문의합니다.

설치와 업데이트​

증상확인할 것
fortress 명령을 찾을 수 없다고 나옵니다터미널을 닫고 새로 엽니다. 설치가 실행 파일 위치를 사용자 PATH(명령을 찾는 경로)에 더하므로, 설치 전에 열어 둔 터미널은 새 위치를 모릅니다. 새로 열어도 같으면 사용자 PATH에 설치 폴더가 들어 있는지 봅니다. Windows는 %LOCALAPPDATA%\Programs\fortress\<버전>, macOS⁠·⁠Linux는 ~/.local/bin입니다. 없으면 이 폴더를 사용자 PATH에 더하고 터미널을 새로 엽니다. 그래도 같으면 설치가 끝났는지 설치하고 첫 요청 보내기에서 확인합니다.
업데이트했는데 이전 버전이 실행됩니다Windows에서는 열려 있던 터미널을 닫고 새로 엽니다. 열려 있던 터미널은 이전 버전을 씁니다. fortress --version으로 버전을 확인합니다.
새 버전이 있다는 알림이 나옵니다터미널에서 fortress update를 실행합니다. 알림만으로는 설치되지 않습니다. 업데이트 순서를 봅니다.
업데이트 파일을 받았는데 설치되지 않습니다받은 파일의 SHA-256 값이 게이트웨이가 알린 값과 맞을 때만 설치합니다. 다시 받아도 같으면 관리자에게 게이트웨이의 설치 파일을 확인해 달라고 요청합니다.
웹 화면이 열리지 않습니다fortress web을 실행한 터미널의 안내를 봅니다. 웹 화면은 fortress web을 실행한 PC의 브라우저에서만 열립니다.

로그인과 연결​

증상확인할 것
"다시 로그인하세요"라고 나옵니다30일 동안 쓰지 않았거나, 로그인한 지 90일이 지났거나, 관리자가 로그인을 끝낸 경우입니다. fortress login으로 다시 로그인합니다. 웹 화면에서는 설정 › 계정 탭의 다시 로그인을 누릅니다. 방법은 설치하고 첫 요청 보내기에 있습니다.
아이디와 비밀번호를 받지 못했습니다계정은 회사의 Fortress AI 관리자가 게이트웨이 관리 화면에서 발급합니다. 관리자에게 요청합니다. 관리자가 하는 순서는 도입 첫날에 있습니다.
비밀번호를 잊었습니다스스로 다시 정하는 기능은 없습니다. 관리자에게 비밀번호를 다시 정해 달라고 요청합니다. 다시 정하면 그 계정의 모든 기기 로그인이 끝나므로, 새 비밀번호로 fortress login을 다시 합니다. 비밀번호 다시 정하기
비밀번호를 여러 번 틀려 로그인이 안 됩니다같은 계정으로 첫 실패부터 15분 안에 5번 틀리면, 그다음 시도부터 15분 동안 "실패가 많아 15분 동안 막았습니다"가 나오고 브라우저 승인도 막힙니다. 잠금을 푸는 기능은 없고 관리자가 비밀번호를 다시 정해도 풀리지 않으니, 15분 뒤 다시 로그인합니다.
맞는 비밀번호인데 "아이디나 비밀번호가 맞지 않습니다"가 나옵니다관리자가 계정을 사용 중지했을 때도 같은 문구가 나옵니다. 관리자에게 계정이 사용 중인지 확인해 달라고 요청합니다. 사용 중지 해제
서버에 연결되지 않습니다fortress doctor의 로그인, 모델 서버, 게이트웨이 줄을 봅니다. 브라우저로 게이트웨이 홈페이지가 열리는지, PC가 사내 망에 연결돼 있는지 확인합니다.
"관리 정책을 gateway에서 받지 못했습니다"라고 나옵니다게이트웨이에서 관리 정책을 한 번도 받지 못한 PC는 대화를 시작하지 않습니다. 네트워크 연결을 확인하고 새 대화를 엽니다. 계속되면 관리자에게 문의합니다. 관리자 정책에 정책을 받는 시점과 받지 못할 때의 동작이 있습니다.

파일​

증상확인할 것
첨부한 파일이 보이지 않습니다보내기 전에 입력창 위에 파일 이름이 표시되는지 확인합니다. 잘못 첨부했다면 지우고 다시 추가합니다.
파일을 읽지 못합니다원본 파일이 정상적으로 열리는지, 암호가 걸려 있거나 손상되지 않았는지 확인합니다. 구형 한글 파일(.hwp)은 HWPX로 저장한 뒤 첨부합니다. 형식별 범위는 파일 형식에서 봅니다.
새 파일이 목록에 없습니다작업 폴더와 결과 파일 이름을 확인하고 파일 칸의 목록을 새로 고칩니다.
답은 있는데 결과 파일이 없습니다파일로 저장해 달라고 요청했는지, 승인을 기다리는 확인 창이 있는지 확인합니다. 저장할 경로와 이름을 정해 다시 요청합니다.
서식이 원본과 다릅니다파일 칸은 문서에서 추출한 텍스트를 보여 줍니다. 원본 서식은 원래 프로그램에서 확인합니다.

거부와 승인​

증상확인할 것
작업이 거부됩니다보안⁠·⁠감사의 해당 기록에서 대상, 근거, 모드를 확인합니다. 파일 경로, 명령, 관리자 정책 가운데 무엇이 막았는지 봅니다. 모드별 동작은 권한 모드에서 봅니다.
작업이 멈춰 있습니다승인을 기다리는 확인 창이 있는지 확인합니다. 사이드바 대화 줄 오른쪽의 주황 점은 입력이 필요하다는 표시입니다.
같은 명령을 매번 묻습니다신뢰하지 않았거나 정하지 않은 폴더에서는 "이 프로젝트에서 다시 묻지 않기"가 나오지 않습니다. 내가 만든 폴더라면 폴더 신뢰를 정합니다.

느릴 때​

증상확인할 것
응답이 느리거나 대기가 길어집니다입력창 아래의 모델 서버 상태 표시에서 대기 요청이 있는지 봅니다. 대기 요청이 많으면 붐빔 안내가 뜨고, 밤에 실행으로 요청을 밤 시간대로 미룹니다. 야간 큐와 느릴 때를 봅니다.

샌드박스​

증상확인할 것
설치 점검에 "샌드박스 꺼짐 (Windows 기본값, 정책으로 켬)"이 나옵니다Windows의 기본값이며, 이때 허용 규칙에 없는 명령은 실행 전에 묻습니다. 켜려면 관리자가 Windows 샌드박스 켜기 순서를 따릅니다.
"샌드박스 시작 실패: 켜져 있었다면 묻지 않음"이 함께 보입니다켜져야 했던 샌드박스가 시작되지 못해 이 대화의 명령이 샌드박스 없이 실행되고 있습니다. 새 대화를 열면 다시 시도합니다. 원인은 fortress doctor에서 봅니다.
"샌드박스 꺼짐: 켜져 있었다면 묻지 않음"이 함께 보입니다샌드박스가 꺼져 있어 묻는 명령입니다. 내용을 읽고 허용하거나 거부합니다. 상태는 입력창 아래 표시와 샌드박스에서 봅니다.

검색과 예약​

증상확인할 것
검색 결과가 없습니다검색어를 짧게 바꿉니다. 대화 내용은 두 글자부터 찾습니다. 보관한 대화는 목록에서 빠지므로 검색 창의 보관됨 탭에서 찾습니다.
예약한 작업이 실행되지 않습니다예약됨에서 스위치가 켜져 있는지, 다음 실행 시각이 맞는지 확인합니다. Fortress 웹이 켜져 있어야 실행되고, 터미널 화면만 켠 상태에서는 실행되지 않습니다. 조건은 예약과 반복 실행에서 봅니다.

담당자에게 문의​

문의할 때는 아래를 함께 보냅니다.
비밀번호 같은 비밀값은 빼고 보냅니다.

  • 운영체제, 클라이언트 버전(fortress --version), 발생 시각
  • 재현 순서와 화면에 나온 안내 문구
  • 아래 명령의 결과
fortress doctor --verbose
