파일 형식

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 한글, 엑셀, PDF 파일을 읽혀도 되는지 확인할 때
  • 파일 칸에서 열었더니 원본과 모양이 다를 때
  • 결과를 한글이나 Word 파일로 받고 싶을 때

파일 형식마다 읽는 범위가 다릅니다.
에이전트에게 전달되는 내용, 파일 칸에 보이는 모습, 새로 만드는 파일은 서로 다르므로 나눠서 봅니다.

첨부해서 읽히기​

입력창의 +나 Ctrl+U로 파일을 붙이면 아래처럼 처리합니다.
작업 폴더에 둔 파일은 붙이지 않아도 에이전트가 직접 읽습니다.

붙인 것처리
PDF, Office, 한글(HWPX) 파일텍스트를 추출해 요청에 붙입니다.
UTF-8이 아닌 텍스트 (예: 한국어 Windows 엑셀에서 저장한 CSV)풀어서 붙이고 원래 인코딩을 알려 줍니다.
256KB가 넘는 텍스트나 추출한 텍스트, 바이너리 파일파일로 남겨 두고 에이전트가 도구로 나눠 읽습니다.
텍스트 층이 없는 페이지가 있는 PDF (스캔 문서)그림을 읽는 모델이 연결되어 있으면 파일로 남겨 두고 페이지를 그림으로 읽습니다.

연결된 모델이 그림을 읽는지는 설정 › 정보 탭의 모델 칸에서 봅니다. 입력 줄에 "텍스트, 이미지"가 보이면 그림을 읽는 모델입니다(버전과 설치 점검).

그림을 읽는 모델이면 텍스트 층이 없는 공문의 표 숫자도 읽을 수 있습니다.
여러 페이지나 도표가 많은 문서는 결과를 원본과 대조합니다.

파일 칸에서 보기​

대화 화면 위쪽의 파일을 누르면 작업 폴더의 파일 목록이 나오고, 파일을 누르면 오른쪽 칸에 탭으로 열립니다.

형식파일 칸에서 보이는 것
한글(HWPX)텍스트로 미리 봅니다. 표는 칸이 하나씩 풀린 텍스트 줄로 보이고, 서식은 보이지 않습니다. 표 모양은 기본 앱으로 열기로 PC의 프로그램에서 열어 확인합니다.
Word, 엑셀에이전트가 읽는 글(Markdown)로 보입니다. 서식과 배치는 원래 프로그램에서 확인합니다.
PowerPoint슬라이드의 텍스트와 발표자 노트가 보입니다. 그림과 배치는 보이지 않습니다.
CSV, TSV표와 원문을 바꿔 봅니다.
PDF원본과 텍스트를 바꿔 보고, 기본 앱으로 열기로 PC의 프로그램에서 엽니다.
Markdown미리 보기로 보이고, 한글(HWPX) 파일로 저장할 수 있습니다.
코드, JSON, HTML, 그림코드는 색을 칠해 보이고, JSON은 펼치는 나무 모양, HTML은 스크립트를 막은 상태, 그림은 그대로 보입니다.

만들기​

만드는 것방법
한글 문서 (HWPX)요청문에 한글 파일로 저장해 달라고 적거나, 파일 칸의 Markdown을 한글로 저장합니다. 터미널에서는 fortress hwpx <파일.md>를 씁니다.
Word 문서 (DOCX)터미널에서 fortress docx <파일.md>로 Markdown을 Word 파일로 바꿉니다. 2.5.2부터 들어 있습니다.

두 명령 모두 -o <파일>로 받을 파일 이름을, --title로 문서 제목을 정하고, --force를 붙이면 이미 있는 파일을 바꿉니다.
자세한 순서는 한글 문서로 저장에 있습니다.

알아 둘 제한​

  • 문서는 텍스트로 읽습니다. 서식, 배치, 그림은 그대로 전달되지 않습니다.
  • 한글과 Word 문서는 Markdown에서 바꿔 만듭니다. 기관 양식의 표 모양과 로고를 그대로 채우는 기능은 아닙니다.
  • 구형 한글 파일(.hwp)은 형식 표에 없습니다. 한글에서 HWPX로 저장한 뒤 첨부합니다.
  • 암호가 걸렸거나 손상된 파일은 읽지 못할 수 있습니다.

다음에 볼 글

결과를 한글 문서로 저장하기업무 결과를 한글(HWPX) 파일로 받는 세 가지 방법과, 받은 파일을 내기 전에 확인할 점입니다.요청 보내고 이어 가기파일을 첨부하거나 @로 가리켜 에이전트에게 전달하는 방법입니다.
