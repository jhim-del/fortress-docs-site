자주 묻는 질문

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 도입을 검토하며 먼저 궁금한 것을 확인할 때
  • 보안 담당자나 동료의 질문에 답해야 할 때

답의 첫 줄이 결론입니다.
자세한 내용은 답 끝의 페이지로 이어집니다.

처음 묻는 질문​

외부 AI 서비스와 무엇이 다른가요?​

모델이 회사 안에 둔 장비에서 실행됩니다.

데이터를 보내는 곳은 웹 화면의 보안⁠·⁠감사에 표시됩니다.
2.6.1 화면에서는 전송 대상이 "이 서버만"으로, 외부 버전 확인⁠·⁠원격 측정⁠·⁠자동 설치⁠·⁠세션 업로드가 "꺼짐"으로 표시됩니다.
어디로 무엇을 보내는지는 서버로 가는 데이터에 화면과 함께 있습니다.

무엇부터 해 보면 되나요?​

체험 첫날의 다섯 단계를 차례로 따라 합니다.
사무 업무를 맡는 분은 월간 업무보고 초안 받기처럼 결과를 원본과 맞춰 볼 수 있는 일부터 해 봅니다.

공개된 모델을 직접 띄워 쓰는 것과 무엇이 다른가요?​

모델만 띄우면 질문에 답하는 서버가 생깁니다.
Fortress AI에는 모델 서버와 함께 아래가 들어 있습니다.

구성설명
작업 화면파일을 읽고 고치고 명령을 실행하는 에이전트를 웹 화면과 터미널에서 씁니다.
실행 전 확인권한 모드와 권한 규칙으로 무엇을 묻고 막을지 정합니다.
샌드박스샌드박스가 작업 폴더 밖 쓰기와 허용하지 않은 외부 접속을 막습니다. Windows는 관리자가 켭니다.
관리자 정책관리자 정책을 PC의 정책 파일로 배포합니다. 게이트웨이 3.4.0 이상이면 게이트웨이에서도 배포합니다. 거부 규칙은 어느 권한 모드에서도 우선하고, 에이전트는 정책 파일을 고칠 수 없습니다.
감사 로그도구를 쓸 때마다 허용⁠·⁠거부가 PC의 감사 로그에 남고, CSV로 내보냅니다.
되돌리기되감기로 대화와 코드를 이전 시점으로 되돌립니다.

에이전트가 파일을 마음대로 바꾸면 어떻게 하나요?​

기본 설정에서는 파일을 고치거나 명령을 실행하기 전에 묻습니다.
작업 폴더 밖의 파일을 읽을 때도 묻고, 기본 동작은 권한 모드에 표로 있습니다.

이미 바뀐 내용은 되감기로 되돌립니다.
명령으로 바뀐 파일은 되돌려지지 않으니 그 페이지의 표를 먼저 봅니다.
작업 폴더에는 원본 대신 사본을 넣습니다.

에이전트가 틀리면 어떻게 확인하나요?​

결과는 담당자가 확인하고 씁니다.
업무 페이지마다 끝에 있는 확인할 점 표가 원본과 맞춰 볼 곳을 알려 줍니다.

에이전트가 읽은 파일, 실행한 명령, 걸린 시간은 타임라인에서 차례로 봅니다.
도구를 쓸 때마다의 허용⁠·⁠거부는 감사 로그에 남습니다.

보안​

회사 데이터가 밖으로 나가지 않는지 확인할 수 있나요?​

화면에서 확인합니다.

사이드바의 보안⁠·⁠감사를 열면 망분리 칸에 데이터를 보내는 곳이 나옵니다.
2.6.1 화면에 표시되는 값은 위 외부 AI 서비스와 무엇이 다른가요?와 같습니다.
서버로 가는 데이터에 화면이 있습니다.

어떤 내용이 모델 서버로 가나요?​

사용자가 쓴 요청과 에이전트가 읽은 파일 내용, 실행한 명령의 출력이 갑니다.
세션을 시작할 때는 작업 폴더 경로, 운영체제, 지침 파일도 함께 갑니다.

모델 서버와 게이트웨이는 사내 장비입니다.
게이트웨이에는 모델을 부를 때마다 클라이언트 버전, 정책의 출처, 샌드박스 상태도 갑니다.
시점별로는 무엇을 언제 보내나에 있습니다.

개인정보를 입력하면 어떻게 되나요?​

입력창에 쓴 주민등록번호, 외국인등록번호, 휴대전화 번호, 카드 번호, API 키 같은 비밀 값은 모델로 보내기 전에 가립니다.
에이전트가 읽은 파일 안의 개인정보는 가리지 않습니다.

주의

개인정보가 든 파일은 작업 폴더에 넣기 전에 그 값을 지우거나 가린 사본을 넣습니다.
원본을 그 폴더에 둬야 하면 권한 규칙으로 읽기를 막습니다.

기록은 어디에 남나요? 관리자가 한곳에서 볼 수 있나요?​

감사 로그(권한 판단 기록)는 각 PC의 ~/.fortress/agent/audit/permissions.jsonl 파일에 남습니다.
중앙에서 모으는 기능은 없고, 사내에서 쓰는 수집 도구로 PC마다 이 파일을 모을 수 있습니다.

게이트웨이 관리 화면에는 모델 호출 기록과 감사 기록(계정⁠·⁠로그인 기록)이 한곳에 모입니다.
이 기록은 PC의 감사 로그와 다릅니다.
감사 로그에 파일 위치와 차이가 있습니다.

거부된 기록만 골라 보고 파일로 받을 수 있나요?​

됩니다.
보안⁠·⁠감사에서 거부를 고르고 CSV 내보내기를 누르면 보이는 기록을 파일로 받습니다.

Windows에서도 샌드박스가 되나요?​

됩니다.
Windows에서는 기본으로 꺼져 있어 관리자가 켭니다.

켜는 방식은 두 가지입니다.
전용 계정 방식은 PC마다 관리자가 한 번 준비하고, MXC 방식은 Windows 11 최신 빌드에서 관리자 설치 없이 씁니다.
꺼져 있는 동안에는 허용 규칙에 없는 명령을 실행 전에 묻습니다.

Windows 샌드박스 켜기에 비교 표가 있습니다.

관리와 배포​

직원 계정은 어떻게 만드나요?​

회사의 관리자가 게이트웨이 관리 화면의 유저관리에서 만듭니다.
한 명씩 만들거나, 아이디를 줄마다 넣어 한 번에 최대 200명을 만듭니다.
만든 사용자 화면의 전할 안내를 복사해 보내고 처음 비밀번호를 따로 전하면, 임직원이 각자 설치하고 로그인합니다.

순서는 도입 첫날: 계정 발급과 전달에 있습니다.

관리자와 사용자는 무엇이 다른가요?​

둘 다 Fortress AI로 일합니다.
관리 화면에서 사용자는 자기 사용량과 기록만 보고, 관리자는 모든 사용자의 것을 보며 계정을 발급하고 사용 중지합니다.
표는 관리 화면 둘러보기에 있습니다.

비밀번호를 잊으면 어떻게 하나요?​

관리자에게 비밀번호를 다시 정해 달라고 요청합니다.
스스로 다시 정하는 기능은 없고, 관리자가 유저관리에서 그 사용자를 열어 새 비밀번호를 정합니다.
같은 계정으로 15분 안에 5번 틀리면 15분 동안 막히고 관리자가 다시 정해도 풀리지 않으니, 기억나지 않으면 더 시도하지 않습니다.

비밀번호 다시 정하기에 순서가 있습니다.

퇴사자 계정은 어떻게 처리하나요?​

관리자가 유저관리에서 그 사용자를 열어 사용 중지합니다.
사용 중지하면 그 계정의 로그인과 API 키가 함께 멈춥니다.
퇴사자 계정 사용 중지에 순서가 있습니다.

계정을 지우는 기능은 없습니다.
복귀한 사용자는 같은 화면의 다시 사용으로 사용 중지를 해제합니다(사용 중지 해제).

조직 규칙을 PC마다 설치해야 하나요?​

게이트웨이 3.3.0에서는 PC마다 정책 파일을 둡니다.
Windows는 그룹 정책이나 Intune으로 한 번에 배포합니다.

게이트웨이 3.4.0 이상이면 관리 화면의 관리 정책에서 한 번 정하면 됩니다.
로그인한 PC가 대화를 시작할 때 받고, 켜져 있는 PC는 1시간마다 다시 받습니다.
둘 다 쓰면 PC 파일이 정한 값이 우선합니다.

관리자 정책에 두 방법과 우선순위가 있습니다.

조직 규칙을 사용자가 바꾸지 못하게 할 수 있나요?​

관리자 정책으로 정합니다.
관리자 정책의 거부 규칙은 어느 권한 모드에서도 우선하고, 에이전트는 정책 파일을 읽거나 고칠 수 없습니다.

사용자가 절대 바꾸면 안 되는 값은 PC의 관리 정책 파일에 둡니다.
게이트웨이 정책에는 서명이 없어, PC 파일이 비워 둔 값은 그 PC 사용자가 바꿀 수 있기 때문입니다.

PC 파일은 관리자만 쓸 수 있는 위치에 두어 일반 사용자가 고치지 못하게 합니다.
Windows의 위치는 C:\Program Files\fortress\policy.json입니다.

정책이 내 PC에 적용됐는지 어떻게 보나요?​

보안⁠·⁠감사의 정책⁠·⁠기록 칸에서 봅니다.
관리자 정책을 받은 PC는 관리자 줄에 정책 이름과 버전이 나오고, 없으면 "없음"으로 나옵니다.
확인하는 다른 방법은 관리자 정책에 있습니다.

파일과 문서​

한글, 엑셀, PowerPoint 파일도 읽나요?​

읽습니다.
텍스트를 추출해 읽으므로 서식, 배치, 그림은 그대로 전달되지 않습니다.
PowerPoint는 슬라이드의 텍스트와 발표자 노트를 읽습니다.

형식별 범위는 파일 형식에 있습니다.

스캔한 문서의 표도 읽나요?​

이미지를 읽는 모델이 연결되어 있으면 읽습니다.
설정 › 정보 탭의 모델 칸에서 입력 줄에 "텍스트, 이미지"가 보이면 이미지를 읽는 모델입니다.

여러 페이지나 도표가 많은 문서는 결과를 원본과 대조합니다.

구형 한글 파일(.hwp)도 읽나요?​

형식 표에 없는 형식입니다.
한글에서 HWPX로 저장한 뒤 첨부합니다.

우리 기관의 한글 양식에 그대로 채워 주나요?​

그대로 채우는 기능은 아닙니다.
결과를 Markdown으로 쓰고 한글 문서로 바꾸므로 양식의 표 모양과 로고는 재현되지 않습니다.

지난달 보고서를 함께 넣으면 장과 표 구성은 따라 씁니다.
월간 업무보고 예시에서는 결재란이 남았지만 칸 배치가 지난달과 달라졌습니다.
월간 업무보고 초안 받기와 한글 문서로 저장을 봅니다.

큰 파일도 첨부할 수 있나요?​

256KB가 넘는 텍스트와 바이너리 파일은 거절하지 않고 파일로 남겨 둔 뒤 에이전트가 나눠 읽습니다.
파일 형식에서 형식별 범위를 봅니다.

사내 문서 수천 건을 검색해서 답하나요?​

기본 제품에는 사내 문서 전체를 색인해 검색하는 기능이 없습니다.
작업 폴더에 둔 파일을 읽어 일합니다.

예약과 반복​

예약한 시각에 PC가 꺼져 있으면 어떻게 되나요?​

다시 켜서 Fortress 웹을 열 때 놓친 실행을 한 번 실행합니다.
최근 7일 안의 것만 해당합니다.
예약과 반복 실행에 조건이 있습니다.

모델 서버가 붐빌 때는 어떻게 하나요?​

붐빔 안내가 뜨면 밤에 실행으로 요청을 밤 시간대로 미룹니다.
실행 시간대는 설정의 일반 탭에서 정하며, 2.6.1 화면의 기본값은 22:00~07:00입니다.
야간 큐를 봅니다.

반복 실행의 가장 짧은 간격은 얼마인가요?​

/loop의 간격은 1분에서 24시간 사이입니다.
예약과 반복 실행을 봅니다.

설치와 접속​

인터넷이 없는 망에서 설치할 수 있나요?​

됩니다.
반입한 설치 패키지의 설치 스크립트로 설치합니다.
설치 방식과 점검에 순서가 있습니다.

내 버전은 어떻게 확인하나요?​

웹 화면의 설정(Ctrl+,) › 정보 탭에서 봅니다.
터미널에서는 fortress --version을 씁니다.

2.6.1부터는 로고 옆에 버전 번호가 나오지 않습니다.
내 버전 확인하기를 봅니다.

웹 화면을 다른 PC에서 열 수 있나요?​

웹 화면은 fortress web을 실행한 PC에서만 열립니다.
공용 개발 서버에 설치한 경우에는 fortress web이 보여 주는 명령으로 연결한 뒤 자기 PC 브라우저에서 엽니다.

업데이트는 자동으로 되나요?​

새 버전이 있으면 알려 주고, 업데이트 실행은 사용자가 fortress update로 직접 합니다.
업데이트 순서를 봅니다.

다음에 볼 글

문제 해결설치, 로그인, 파일, 승인, 속도, 샌드박스, 예약에서 자주 생기는 증상과 먼저 확인할 것을 정리합니다.한 장으로 보는 보안Fortress AI의 보호를 경계와 안전망으로 나눠, 무엇을 막고 묻고 기록하는지 한 장으로 정리합니다.체험 첫날설치가 끝난 PC에서 설치 확인, 웹 화면 열기, 첫 요청, 월간 업무보고 같은 업무 하나까지 체험 첫날 순서대로 해 봅니다. 교육 뒤에도 이 페이지를 보며 다시 따라 합니다.
