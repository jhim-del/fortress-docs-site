Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 문서나 화면에 나온 용어의 뜻을 모를 때
  • 점선 밑줄 용어의 뜻을 한곳에서 다시 보고 싶을 때

문서 본문의 점선 밑줄 용어에 마우스를 올리면 아래 뜻이 뜹니다.
화면 글자와 같은 용어는 화면에 나오는 그대로 적었습니다.

기본 용어​

용어뜻
세션한 가지 일을 맡기고 주고받는 대화 하나입니다. 화면에서는 대화라고도 부릅니다.
작업 폴더세션이 일하는 폴더입니다. Fortress AI는 이 폴더의 파일을 읽고 고칩니다.
요청문에이전트에게 일을 맡기려고 입력창에 쓰는 글입니다.
결과물세션이 만든 파일입니다. 에이전트가 쓴 파일은 대화 화면 오른쪽의 결과물 칸에 모입니다.
클라이언트사용자 PC에 설치하는 Fortress AI 프로그램입니다. 웹 화면과 터미널이 들어 있습니다.
게이트웨이로그인, 모델 연결, 클라이언트 배포, 호출 기록을 맡는 사내 서버입니다. 게이트웨이 3.4.0 이상은 관리자가 정한 관리 정책도 배포합니다.
모델 서버사내 장비에서 AI 모델을 실행하는 서버입니다.
에이전트요청을 받아 파일을 읽고, 고치고, 명령을 실행하는 주체입니다.
서브에이전트에이전트가 일을 나눠 맡기는 보조 에이전트입니다.
터미널글자로 명령을 입력해 프로그램을 실행하는 창입니다. Windows에서는 PowerShell을 씁니다.

화면과 기능​

용어뜻
폴더 검색새 대화 화면의 폴더 선택… 메뉴에서 이미 쓴 폴더를 이름으로 찾는 기능입니다.
폴더 찾아보기폴더 선택… 메뉴에서 이 PC의 폴더 선택 창을 띄워 작업 폴더를 고르는 기능입니다. Windows에서는 Ctrl+Alt+1로도 엽니다.
승인 카드에이전트가 실행 전에 확인을 묻는 카드입니다. 허용하거나 거부합니다.
대기열지금 응답이 끝난 뒤 처리하도록 요청을 넣어 두는 곳입니다. 작업 중에 Ctrl+Enter로 넣습니다. Enter로 보내는 "지금 전달"은 진행 중인 작업에 끼워 넣습니다. 요청 보내고 이어 가기
다음 메시지 제안입력창이 비어 있을 때 다음에 보낼 만한 메시지를 흐리게 보여 주는 기능입니다. Tab으로 받고, 설정의 일반 탭에서 끕니다.
사이드 채팅대화에 남기지 않고 작업 중에 묻는 기능입니다. /btw 질문으로 씁니다.
타임라인에이전트가 한 일을 시간 순서로 보여 주는 화면입니다. 결과 확인하고 되돌리기
되감기대화의 이전 시점으로 돌아가 코드와 대화를 되돌리는 기능입니다. 되돌리기, 복구에 해당합니다. 결과 확인하고 되돌리기
컨텍스트에이전트가 답할 때 한 번에 참고하는 내용입니다. 컨텍스트⁠·⁠모델⁠·⁠사용 현황
컨텍스트 압축컨텍스트가 찼을 때 지난 대화를 요약해 공간을 비우는 기능입니다. 컨텍스트 칸의 압축을 누르거나 터미널에서 /compact를 씁니다. 대화 압축
보관대화를 목록에서 빼 두는 일입니다. 보관하면 위쪽에 "보관됨" 알림과 되돌리기가 나옵니다.
포크세션의 내용을 복사해 새 세션을 만드는 일입니다.
프로젝트큰 일을 스레드로 나눠 맡기고 보고를 받는 단위입니다. 프로젝트로 묶기
스레드프로젝트 안에서 나눠 맡긴 일 하나입니다.
예약 작업정한 시각에 실행하도록 맡겨 둔 일입니다. 예약과 반복 실행
야간 큐모델 서버가 붐빌 때 요청을 밤 시간대로 미뤄 두는 기능입니다. 실행 시간대는 설정의 일반 탭에서 정하며, 2.6.1 화면의 기본값은 22:00~07:00입니다.
백그라운드 작업오래 걸리는 명령을 백그라운드에서 실행하게 한 것입니다. 실행 중인 명령을 Ctrl+B로 보냅니다.
지침 파일에이전트가 따를 규칙을 적어 둔 파일입니다. 작업 폴더의 FORTRESS.md가 해당합니다.
스킬자주 하는 일의 절차를 묶어 둔 것입니다.
커넥터외부 도구와 연결하는 장치입니다. MCP 커넥터라고도 부릅니다.
PowerShell 도구Windows에서 에이전트가 PowerShell 명령을 직접 실행하는 도구입니다. 관리자 정책으로 켭니다. 규칙은 권한 규칙에 있습니다.

계정과 관리 화면​

용어뜻
홈 화면브라우저로 게이트웨이 주소(<장비 주소>:8080)를 열면 나오는 첫 화면입니다. 클라이언트 설치 명령이 있습니다.
관리 화면게이트웨이 주소 뒤에 /admin을 붙여 여는 웹 화면입니다. 계정, 사용량, 호출 기록을 다룹니다. 관리 화면 둘러보기
관리자관리 화면에서 계정을 만들고 모든 사용자의 사용량과 기록을 보는 역할입니다. 설치 때 만드는 첫 관리자의 아이디는 admin입니다.
사용자Fortress AI로 일하는 기본 역할입니다. 관리 화면에서는 자기 사용량, 호출 기록, API 키, 로그인한 기기만 봅니다.
처음 비밀번호계정을 만들 때 정해지는 첫 비밀번호입니다. 한 명을 추가할 때는 관리자가 정하고, 여러 명을 한 번에 추가할 때는 게이트웨이가 만들어 추가한 화면에서 한 번만 보여 줍니다.
API 키다른 개발 도구를 게이트웨이에 연결할 때 쓰는 키입니다. axk_로 시작합니다. Fortress AI 클라이언트는 키 없이 브라우저 승인으로 로그인합니다.
사용 중지관리자가 계정의 로그인과 API 키를 멈추는 일입니다. 퇴사자 계정에 씁니다. 같은 화면의 다시 사용으로 해제합니다.
전할 안내관리자가 계정을 만들거나 비밀번호를 다시 정한 뒤 사용자 화면에 나오는 안내 글입니다. 아이디와 설치⁠·⁠로그인 순서가 들어 있고 비밀번호는 들어 있지 않습니다. 안내 복사로 보냅니다.
요청 ID게이트웨이가 모델 호출마다 붙이는 번호입니다. 관리 화면의 찾기 칸에 앞 8자리 이상을 넣어 그 호출을 찾습니다.

안전장치와 관리​

용어뜻
권한 모드에이전트가 실행 전에 어디까지 묻는지 정하는 설정입니다. 권한 모드
권한 규칙도구와 대상마다 허용, 물어봄, 거부를 정해 둔 규칙입니다. 권한 규칙
폴더 신뢰처음 여는 폴더를 신뢰할지 폴더마다 한 번 정하는 설정입니다. 정하기 전에는 입력창 아래에 "신뢰 미정"이 보입니다. 폴더 신뢰
샌드박스에이전트가 실행하는 명령을 운영체제 수준에서 격리하는 장치입니다. 2.6.1부터 입력창 아래에 켜짐, 꺼짐이 표시됩니다. 샌드박스
경계명령을 어떤 형태로 쓰든 막는 보호입니다. 파일을 실제로 여는 지점의 검사와 운영체제 샌드박스가 해당합니다. 한 장으로 보는 보안
안전망실행 전에 명령 문자열을 읽고 판단해 묻거나 막는 보호입니다. 흔한 실수를 잡지만 모든 형태를 막지는 않습니다. 샌드박스 밖에서 실행되는 명령에는 안전망만 남습니다.
MXCWindows 11의 컨테이너 기능으로 명령을 격리하는 Windows 샌드박스 방식입니다. 관리자 설치가 필요 없고, PowerShell 명령만 실행합니다. Windows 샌드박스 켜기
관리자 정책조직이 정해 모든 사용자에게 적용하는 규칙입니다. PC의 정책 파일로 두거나 게이트웨이에서 받습니다. 거부 규칙은 어느 권한 모드에서도 우선합니다. 관리자 정책
게이트웨이 정책게이트웨이 3.4.0 이상에서 관리자가 관리 화면에 정한 관리자 정책입니다. 로그인한 PC가 대화를 시작할 때와 1시간마다 받습니다.
입력 가림입력창에 쓴 주민등록번호, 휴대전화 번호, 카드 번호, API 키 같은 값을 모델로 보내기 전에 가리는 기능입니다. 서버로 가는 데이터
감사 로그에이전트가 도구를 쓸 때마다 허용했는지 거부했는지 각 PC에 남는 기록(권한 판단 기록)입니다. 보안⁠·⁠감사에서 봅니다. 관리 화면의 감사 기록과는 다릅니다. 감사 로그
감사 기록게이트웨이 관리 화면의 메뉴입니다. 로그인, 계정, API Key, 기기에 한 일이 남고, 관리자만 봅니다. 관리 화면 둘러보기
보안⁠·⁠감사데이터를 보내는 곳, 샌드박스와 정책의 상태, 감사 로그를 보여 주는 웹 화면입니다. 사이드바에서 엽니다.
