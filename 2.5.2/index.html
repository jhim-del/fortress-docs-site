Fortress AI 문서

Fortress AI는 회사 안 장비에서 실행하는 업무용 AI입니다.
평소 쓰는 말로 일을 맡기면 작업 폴더의 문서와 코드를 읽고, 보고서⁠·⁠분석서⁠·⁠정의서 같은 결과물 초안을 만듭니다.

이 문서를 읽는 법​

  • 판 고르기: 오른쪽 위에서 쓰는 판을 고릅니다. 쪽마다 제목 아래에 확인한 판을 적었습니다. 내 판은 웹 화면 왼쪽 위 로고 옆의 번호로 확인합니다.
  • 검색: 위쪽 검색창(Ctrl+K)에 평소 말로 적어도 찾습니다. 예) 파일 올리기, 되돌리기, 오류가 나요. 검색은 이 사이트 안에서만 동작하며 외부로 요청을 보내지 않습니다.
  • 낱말 뜻: 점선 밑줄이 있는 낱말은 마우스를 올리거나 누르면 뜻이 나옵니다. 낱말의 뜻은 용어집에 모았습니다.
  • 요청문 복사: 요청문 카드의 복사를 누르면 요청문을 그대로 복사합니다.
  • 움직이는 화면: 화면에 보일 때만 재생됩니다. 누르면 멈추고, 크게 보기로 키워 봅니다.
