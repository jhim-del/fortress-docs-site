Windows 샌드박스 켜기

Fortress AI 2.5.2 기준

이 쪽을 읽으면 Windows PC에서 샌드박스를 켜고, 켠 뒤 달라지는 점에 대비할 수 있습니다.

Windows에서는 샌드박스가 기본으로 꺼져 있습니다.
켜려면 PC마다 관리자가 한 번 설정하고 정책에서 켭니다.
Windows 방식은 알파 단계입니다.

동작 방식​

장치하는 일
전용 로컬 계정에이전트의 명령이 이 계정으로 실행됩니다.
Windows 방화벽그 계정의 바깥 연결을 막습니다.
NTFS 권한작업 폴더 밖에 쓰는 것을 막습니다.

켜는 순서​

  1. 관리자 권한으로 아래 명령을 실행합니다. 사용자 계정 컨트롤 확인이 한 번 뜹니다.

    fortress windows-install

  2. 정책 파일에 아래 항목을 넣습니다. 사용자 정책(~/.fortress/agent/policy.json)이나 관리자 정책에 둡니다.

    { "sandbox": { "enabled": true } }

  3. 상태를 확인합니다. "샌드박스 켜짐"이 나오면 끝입니다.

    fortress doctor

설정 명령은 다시 실행해도 안전합니다.
되돌리려면 fortress windows-uninstall로 계정과 방화벽 규칙을 지웁니다.

켠 뒤 달라지는 점​

상황동작대처
사용자 프로필에만 설치한 도구샌드박스 안에서 열 수 없습니다.모든 사용자용으로 설치합니다.
로그인이 필요한 git 원격 저장소로그인 창을 띄우지 않고 실패합니다. 공개 저장소는 그대로 됩니다.그런 저장소는 사람이 터미널에서 받습니다.
일부 도구의 HTTPS 연결묶음에 든 Git Bash의 curl은 허용한 주소에도 HTTPS 연결이 실패합니다.HTTP 연결과 git의 HTTPS는 됩니다.
관리자 권한으로 만든 폴더그 세션만 샌드박스 없이 실행하고 이유를 보여 줍니다.사용자가 권한을 가진 폴더에서 작업합니다.
ssh로 접속한 세션샌드박스가 시작되지 않습니다.데스크톱에서 씁니다.
다른 폴더의 세션을 열 때샌드박스를 다시 초기화해 잠깐 기다립니다.

정책으로 켰는데 설정이 안 된 PC에서는 fortress windows-install을 안내하고 샌드박스 없이 명령을 실행합니다.

샌드박스가 막는 범위는 샌드박스에서 봅니다.

다음에 볼 글

샌드박스샌드박스가 막는 범위와 막지 않는 범위, 운영체제별 차이를 설명합니다.도입 첫 주 점검표관리자가 Fortress AI를 들인 첫 주에 설치 방식, 정책 배포, 샌드박스, 설치 뒤 점검, 사용자 안내, 기록 확인을 차례로 점검하는 목록입니다.
