버전: 2.5.2

관리자 정책

Fortress AI 2.5.2 기준

이 쪽을 읽으면 사용자가 덮어쓸 수 없는 조직 공통 규칙을 정책 파일로 정하고 배포할 수 있습니다.

관리자 정책은 사용자가 덮어쓸 수 없는 조직 공통 규칙입니다.
PC마다 정해진 위치에 정책 파일을 둡니다.

파일 위치​

운영체제경로
WindowsC:\Program Files\fortress\policy.json
macOS/Library/Application Support/fortress/policy.json
Linux/etc/fortress/policy.json

관리자만 쓸 수 있고 사용자는 읽을 수 있게 둡니다.
Windows에서는 그룹 정책이나 Intune으로 파일을 배포합니다.
레지스트리는 읽지 않습니다.

예시​

폐쇄망 기준의 예입니다.
주소와 이름은 조직에 맞게 바꿉니다.

policy.json
{
  "permissions": {
    "deny": ["Bash(curl *)", "Bash(wget *)", "Read(~/.ssh/**)"],
    "defaultMode": "default"
  },
  "sandbox": {
    "enabled": true,
    "required": true,
    "allowUnsandboxedCommands": false,
    "network": { "allowedDomains": ["nexus.corp.local", "git.corp.local"], "strictAllowlist": true }
  },
  "disableBypassPermissionsMode": true,
  "redactInput": true,
  "packageMirrors": {
    "npm": "http://nexus.corp.local/repository/npm/",
    "pip": "http://nexus.corp.local/repository/pypi/simple"
  },
  "commandMemoryLimit": "8G",
  "about": { "name": "보안팀 표준", "version": "v3", "contact": "sec@corp.local" }
}

항목​

항목뜻
permissions.deny거부할 도구와 대상. 어느 권한 모드에서도 적용됩니다.
permissions.defaultMode기본 권한 모드
sandbox.enabled샌드박스를 켭니다.
sandbox.required샌드박스 없이는 명령을 실행하지 않습니다.
sandbox.allowUnsandboxedCommandsfalse면 샌드박스 밖 재실행을 묻지 않고 막습니다.
sandbox.network.allowedDomains샌드박스 안 명령이 접속할 수 있는 주소
sandbox.network.strictAllowlisttrue면 목록 밖 주소를 묻지 않고 막습니다.
disableBypassPermissionsMode권한 무시 모드를 쓰지 못하게 합니다.
redactInput입력 가림을 켭니다.
packageMirrors사내 패키지 저장소 주소
commandMemoryLimit에이전트 명령이 함께 쓰는 메모리 상한. Linux에서만 적용됩니다.
about정책의 이름, 판, 연락처

적용 규칙​

  • 관리자 정책의 거부 규칙은 어느 모드에서도 우선합니다.
  • 정책 파일은 에이전트가 읽거나 고칠 수 없습니다.
  • 파일이 있는데 JSON으로 읽히지 않으면 모든 도구 호출을 거부합니다. 배포한 뒤 fortress doctor로 확인합니다.
  • about을 적으면 사용자의 보안⁠·⁠감사 화면에 정책 이름, 판, 지문이 보입니다. 배포한 파일이 실제로 적용됐는지 사용자가 확인할 수 있습니다.
  • packageMirrors의 주소는 allowedDomains에도 넣습니다. 넣지 않으면 접속할 때 묻고, strictAllowlist가 켜져 있으면 거부합니다.
  • 사내 저장소 주소는 IP 주소로 쓰지 않고 호스트 이름으로 씁니다. IP 주소로 쓰면 샌드박스 안 명령이 접속하지 못합니다.

정책으로 정해진 규칙은 사용자의 사용자 지정 화면에서 보기만 할 수 있습니다.

주의

환경 변수 AXF_MANAGED_POLICY로 정책 파일을 가리키는 방법은 사용자가 값을 바꿀 수 있어 강제 수단이 아닙니다.
위 표의 위치에 파일이 있으면 그 파일만 적용됩니다.
