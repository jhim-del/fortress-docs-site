Fortress AI 2.5.2 기준

이럴 때 봅니다

  • Fortress AI가 무엇이고 어디에 쓰는지 처음 알아볼 때
  • 도입을 검토하며 구성과 제한을 먼저 확인하고 싶을 때
  • 동료에게 한 쪽으로 설명해야 할 때

Fortress AI는 이런 도구입니다​

Fortress AI는 회사 안 장비에서 실행하는 업무용 AI입니다.
평소 쓰는 말로 일을 맡기면 (맡길 파일을 넣어 둔 폴더)의 문서와 코드를 읽고, 고치고, 결과물을 만듭니다.
결과물은 보고서, 분석서, Word⁠·⁠한글 문서 같은 초안입니다.
담당자가 근거와 숫자를 확인한 뒤 씁니다.

세 부분으로 이루어집니다​

부분쉬운 말로하는 일
내 PC에 설치하는 프로그램요청을 받고, 작업 폴더의 파일을 읽고 고치고, 명령을 실행합니다.
로그인과 연결을 맡는 사내 서버로그인, 모델 연결, 클라이언트 배포를 맡습니다.
AI가 실제로 도는 사내 장비사내 장비에서 AI 모델을 실행합니다.

데이터가 어디로 가는지 화면에서 확인합니다​

데이터를 보내는 곳은 웹 화면의 보안⁠·⁠감사에 표시됩니다.
2.5.2 화면에서는 망분리 칸의 전송 대상이 "이 서버만"으로, 외부 버전 확인⁠·⁠원격 측정⁠·⁠자동 설치⁠·⁠세션 업로드가 "꺼짐"으로 표시됩니다.
무엇을 언제 보내는지는 서버로 가는 데이터에 화면과 함께 있습니다.

화면은 두 가지입니다​

업무 담당자는 화면 글이 한국어인 웹 화면부터 쓰면 됩니다.

화면여는 명령특징
웹 화면fortress web브라우저에서 씁니다. 실행한 PC에서만 열립니다. 화면 글은 한국어입니다.
화면fortress글자로 명령을 입력하는 창에서 씁니다. 화면 글은 영어입니다.

웹 화면의 메뉴는 화면 지도에서 번호로 짚어 봅니다.

맡길 수 있는 일​

아래는 가상 자료로 직접 실행해 결과를 확인한 일입니다.
일마다 요청문과 순서가 있는 쪽으로 이어집니다.

일받는 결과확인한 판
문서 없는 시스템 분석모듈 구조, 처리 흐름, 근거 파일 경로가 붙은 현행 분석서2.4.0, 2.5.2
결함 수정과 테스트오류 재현, 수정, 테스트 추가와 실행 결과, 장애 처리 보고서 초안2.4.0, 2.5.2
DB 구조 정의서 작성테이블, 관계, 제약 조건을 정리한 문서2.4.0, 2.5.2
스캔한 PDF의 표 읽기글자 층이 없는 문서의 표 숫자2.4.0
한글 문서로 저장Markdown으로 쓴 결과를 한글(HWPX) 파일로2.5.2
보안 검토심각도와 위치가 붙은 점검 목록과 보고서2.4.0
예약 작업정한 시각에 실행하고 결과를 보고2.4.0

알아 둘 제한​

  • Windows에서는 (명령이 작업 폴더 밖에 쓰거나 허용하지 않은 곳에 접속하지 못하게 가두는 장치)가 기본으로 꺼져 있습니다. 관리자가 Windows 샌드박스 켜기 순서로 켭니다.
  • 명령으로 바뀐 파일은 (이전 시점으로 되돌리기)로 되돌려지지 않습니다. 결과 확인하고 되돌리기에 범위가 있습니다.
  • 스캔한 PDF는 그림을 읽는 모델이 연결되어 있을 때 읽습니다. 형식별 범위는 파일 형식에서 봅니다.
  • 사내 문서 전체를 색인해 검색하는 기능은 기본 제품에 들어 있지 않습니다. 작업 폴더에 둔 파일을 읽어 일합니다.

다음에 볼 글

설치하고 첫 요청 보내기내 PC에 Fortress AI를 설치하고, 브라우저에서 로그인을 승인하고, 설치를 점검한 뒤 웹 화면에서 첫 요청을 보내는 순서입니다. 업데이트와 제거도 이 쪽에 있습니다.체험 첫날설치가 끝난 PC에서 설치 확인, 웹 화면 열기, 첫 요청, 업무 세 가지 따라 하기까지 체험 첫날 순서대로 해 봅니다. 교육 뒤에도 이 쪽을 보며 다시 따라 합니다.업무별로 해 보기장애 처리 보고서, 현행 분석서, DB 구조 정의서, 한글 문서 저장, 보안 검토, 긴 문서 요약, 반복 업무 예약을 업무별로 따라 합니다.
