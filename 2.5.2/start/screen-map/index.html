사이드바 메뉴​

사이드바의 메뉴를 차례로 누르면 각 화면이 가운데에 열립니다.

메뉴여는 화면설명한 쪽
검색지난 세션 찾기요청 보내고 이어 가기
새로 생성작업 폴더를 고르고 새 세션 시작설치와 첫 요청
프로젝트프로젝트 목록프로젝트로 묶기
예약됨모든 예약 작업예약과 반복 실행
사용자 지정스킬, 커넥터, 에이전트, 명령, 메모리, 권한내 방식으로 맞추기
보안⁠·⁠감사망분리⁠·⁠샌드박스 상태와 판단 기록감사 기록
사용 현황기간별 요청 수, 모델이 일한 시간, 토큰컨텍스트⁠·⁠모델⁠·⁠사용 현황

입력창 아래​

입력창 아래에는 지금 권한 모드와 모델 이름 단추가 있습니다.

새 세션​

새로 생성을 누르면 "어디서 작업할까요?"가 열립니다.
작업 폴더를 고른 뒤 입력창에 요청을 적습니다.
