요청문 모음

Fortress AI 2.5.2 기준

이 쪽을 읽으면 직접 실행해 본 요청문을 골라 복사하고 내 업무에 맞게 고쳐 쓸 수 있습니다.

아래 요청문은 가상 자료로 직접 실행해 결과를 확인한 것입니다.
코드 블록 오른쪽 위의 복사 버튼으로 복사한 뒤, 파일 이름과 사업 이름을 상황에 맞게 고칩니다.

좋은 요청의 모양​

요청문에 아래 네 가지가 들어 있으면 결과를 확인하기 쉽습니다.

넣을 것예
상황"구축사가 철수해서 문서가 README 하나뿐인 민원 포털이야."
결과 파일의 이름과 형식"결과는 한글 파일 과업내용서_2027_초안.hwpx 로 저장해줘."
들어갈 항목"꼭 들어갈 것 1. … 2. … 3. …"
근거를 적으라는 말"항목마다 근거 파일 경로를 적어줘."

분량이나 범위를 정해 주면 결과가 길어지는 것을 막습니다. 예: "분량은 A4 2쪽 안팎으로"

문서 업무​

작년 문서로 올해 초안 만들기​

넣는 것받는 것걸린 시간
작년 제안요청서, 올해 사업계획서 (한글 파일)과업내용서 초안 (한글 파일)1~4분
요청문
이 폴더에 있는 작년 제안요청서와 올해 사업계획서를 읽고, 2027년 통합민원포털 유지관리 사업의 과업내용서 초안을 만들어줘.
작년 과업 범위를 기본으로 하되 올해 사업계획에서 이 사업에 포함하기로 한 것만 반영하고, 바뀐 부분은 표로 따로 정리해줘.
분량은 A4 2쪽 안팎으로, 결과는 한글 파일 과업내용서_2027_초안.hwpx 로 저장해줘.

업체 보고서를 과업지시서와 대조하기​

넣는 것받는 것걸린 시간
과업지시서, 업체의 월간보고서빠진 항목 표와 보완 요청 문구 (화면)1~2분
요청문
이 폴더에 있는 과업지시서의 월간보고 필수 항목과 업체가 낸 10월 월간보고서를 대조해서, 빠졌거나 기준에 못 미치는 항목을 표로 정리해줘.
항목마다 근거(과업지시서 몇 조 몇 번)와 업체에 보낼 보완 요청 문구도 같이 써줘.

로그로 장애 보고서 쓰기​

넣는 것받는 것걸린 시간
서버 로그, 장애처리보고서 양식 (한글 파일)장애 처리 보고서 (한글 파일)1~4분
요청문
11월 12일 오전에 민원 신청이 안 된다는 신고가 있었어. 이 폴더에 있는 서버 로그를 분석해서 원인과 조치 내용을 찾고,
장애처리보고서 양식에 맞춰 보고서를 작성해줘. 결과는 한글 파일 장애처리보고서_20261112.hwpx 로 저장해줘.

지난달 양식으로 이번 달 업무보고 쓰기​

넣는 것받는 것걸린 시간
지난달 업무보고 (한글 파일), 이번 달 실적 (엑셀)이번 달 업무보고 초안 (한글 파일)약 3분
요청문
이 폴더에 있는 10월 업무보고와 같은 양식으로 11월 업무보고 초안을 만들어줘. 숫자는 11월 실적 엑셀에서 가져오고,
전월 대비 증감도 같이 적어줘. 결과는 한글 파일 2026_11월_주요업무추진실적.hwpx 로 저장해줘.
참고

한글 파일로 받은 결과는 표 모양이 원래 양식과 다를 수 있습니다.
한글에서 열어 확인하고 필요한 부분을 편집합니다.
결과를 한글 문서로 저장하기에 확인할 점이 있습니다.

결과는 사람이 확인합니다​

  • 숫자는 원본 파일과 대조합니다.
  • 근거로 적힌 조항과 파일을 직접 열어 봅니다.
  • 초안으로 받고, 내보내기 전에 담당자가 검토합니다.
