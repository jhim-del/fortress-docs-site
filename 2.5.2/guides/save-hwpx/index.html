Fortress AI 2.5.2 기준

이 쪽을 읽으면 Fortress AI가 만든 결과를 한글(HWPX) 문서로 받을 수 있습니다.

Fortress AI는 결과를 Markdown으로 쓰고, 이를 한글(HWPX) 문서로 바꿔 저장합니다.
방법은 두 가지입니다.
말로 요청하거나, 이미 만들어진 Markdown 파일을 파일 패널에서 저장합니다.

방법 1. 말로 요청합니다​

요청문에 한글 파일로도 만들어 달라고 적습니다.

요청 예
운영 DB(db/reserve.sqlite)의 테이블별 컬럼 수와 건수를 표로 정리해
docs/테이블현황.md 로 써줘.

발주처 제출용으로 같은 내용을 한글(HWPX) 파일로도 만들어줘.

방법 2. 파일 패널에서 저장합니다​

이미 만들어진 Markdown 파일을 한글 문서로 바꿉니다.

1. Markdown 파일을 열어 미리 봅니다​

파일 패널에서 Markdown(.md) 파일을 엽니다.
미리보기에서 제목, 문단, 표를 확인합니다.

2. 한글로 저장을 누릅니다​

한글로 저장을 누릅니다.
파일은 브라우저의 다운로드 설정에 따라 저장됩니다.

3. 한글에서 열어 확인합니다​

내려받은 HWPX 파일을 한글에서 엽니다.
표와 줄바꿈을 확인하고 필요한 부분을 편집합니다.

저장한 뒤 확인할 것​

  • 한글에서 표와 줄바꿈을 확인하고 필요한 부분을 편집합니다.
  • 숫자와 표의 칸이 Markdown 원문과 같은지 대조합니다.

알아 둘 제한​

  • Markdown에서 변환합니다. 기관 양식의 표 모양과 로고를 그대로 채우는 기능이 아닙니다.
  • Word 문서가 필요하면 파일 형식의 만들기 항목을 봅니다.
