Fortress AI 2.5.2 기준

이 쪽을 읽으면 Fortress AI가 어디로 무엇을 보내는지 화면에서 확인하고, 개인정보 가림과 판단 기록의 범위를 알 수 있습니다.

Fortress AI는 로그인한 사내 모델 서버 한 곳으로만 데이터를 보냅니다.
상태는 사이드바의 보안⁠·⁠감사에서 확인합니다.

어디로 보내나​

항목화면 표시
전송 대상이 서버만
외부 버전 확인꺼짐
원격 측정꺼짐
자동 설치꺼짐
세션 업로드꺼짐

무엇을 보내나​

시점보내는 것
세션을 시작할 때작업 폴더 경로, 운영체제, git 상태, 지침 파일(FORTRESS.md, AGENTS.md), PC의 스킬 목록
일하는 동안사용자가 쓴 요청, 에이전트가 실행한 도구의 결과(읽은 파일 내용, 명령 출력)

에이전트가 파일을 읽으면 그 내용이 모델 서버로 갑니다.
읽게 할 범위는 작업 폴더와 권한 설정으로 정합니다.

개인정보 가림​

입력창에 쓴 주민등록번호, 휴대폰 번호, 카드 번호는 모델로 보내기 전에 가립니다.
기본으로 켜져 있습니다.

주의

가림은 사용자가 입력창에 쓴 글에만 적용됩니다.
에이전트가 읽은 파일 안의 개인정보는 가리지 않습니다.

판단 기록​

에이전트가 도구를 쓸 때마다 허용했는지 거부했는지가 기록됩니다.

  • 자동⁠·⁠규칙 허용, 사람이 허용, 거부로 골라 봅니다.
  • 모든 대화와 이 대화 가운데 범위를 고릅니다.
  • CSV 내보내기로 기록을 파일로 받습니다.

기록 한 줄에는 시각, 결과, 도구, 대상, 근거, 모드, 대화가 들어 있습니다.

기록이 남는 곳과 모으는 법은 감사 기록에서 봅니다.

다음에 볼 글

감사 기록에이전트의 도구 사용 판단이 어디에 어떤 내용으로 남는지, 어떻게 보고 모으는지 설명합니다.한 장으로 보는 보안Fortress AI가 데이터를 어디로 보내고, 에이전트의 실행을 무엇으로 묻고 막고 기록하는지 한 장으로 정리합니다.
