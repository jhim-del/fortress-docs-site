권한 모드

Fortress AI 2.5.2 기준

이 쪽을 읽으면 에이전트가 실행 전에 어디까지 묻게 할지 정하고 바꿀 수 있습니다.

권한 모드는 에이전트가 파일을 고치거나 명령을 실행하기 전에 어디까지 묻는지 정하는 설정입니다.
웹 화면에서는 입력창 아래에 지금 모드가 표시됩니다.

기본 동작​

따로 규칙을 두지 않았을 때의 동작입니다.

대상동작
작업 폴더 안의 파일 읽기허용
작업 폴더 밖의 파일 읽기물어봄
.env 파일 읽기물어봄
파일 수정, 읽기 전용이 아닌 명령물어봄. 샌드박스가 켜져 있으면 샌드박스 안에서 실행되는 명령과 그 쓰기는 자동으로 허용됩니다.
.git/ 안의 파일 수정항상 물어봄
예약 작업 만들기와 고치기물어봄
정책 파일 수정항상 거부
게이트웨이 로그인 파일 읽기와 수정항상 거부

실행 전에 묻는 모습​

"물어봄"이면 실행 전에 확인 창이 뜹니다.
내용을 읽고 허용하거나 거부합니다.

모드​

화면 이름명령에서 쓰는 이름동작
수동default위의 기본 동작. 편집 전에 묻습니다.
편집 자동 수락acceptEdits작업 폴더 안의 파일 수정은 묻지 않습니다.
계획plan읽기만 합니다. 파일을 고치거나 쓰는 명령을 거부하고, 살펴본 뒤 계획을 내놓습니다.
권한 무시bypassPermissions물어볼 일을 허용으로 처리합니다. 거부 규칙과 정책 파일 보호는 그대로 적용됩니다.
묻지 않기dontAsk물어볼 일을 거부로 처리합니다.

모드 바꾸기​

  • 웹 화면에서는 입력창 아래의 모드 이름을 눌러 메뉴에서 고릅니다. Shift+Tab으로 차례로 바꿀 수도 있습니다.
  • 세션 중에는 입력창에 /mode <모드>를 입력합니다.
  • 시작할 때 정하려면 --permission-mode <모드>를 붙여 실행합니다.
예
/mode acceptEdits

권한 무시에서도 묻는 삭제​

bypassPermissions 모드에서도 아래 삭제는 실행 전에 묻습니다.
한 번의 실수가 되돌릴 수 없는 삭제로 이어지는 것을 막기 위한 장치입니다.

  • 루트와 그 바로 아래 폴더, 홈 폴더, 작업 폴더와 그 위 폴더를 지우는 명령
  • 위 폴더나 작업 폴더를 통째로 비우는 명령

사람 없이 실행할 때​

화면 없이 실행하면 물어볼 수 없으므로 "물어봄"이 거부로 처리됩니다.
멈춰서 기다리지 않습니다.
파일을 고치게 하려면 acceptEdits 모드나 허용 규칙을 씁니다.

판단 결과는 감사 기록에서 확인합니다.
명령을 가두는 범위는 샌드박스에서 봅니다.
규칙을 쓰는 법은 권한 규칙에서, 폴더별 결정은 폴더 신뢰에서 봅니다.
