Fortress AI 2.5.2 기준

이 쪽을 읽으면 데이터가 어디로 가는지와 보안 장치 네 가지가 각각 무엇을 맡는지 한 번에 알 수 있습니다.

데이터는 사내 모델 서버로만 갑니다​

Fortress AI는 로그인한 사내 모델 서버 한 곳으로만 데이터를 보냅니다.
사이드바의 보안⁠·⁠감사를 열면 전송 대상이 "이 서버만"으로, 외부 버전 확인⁠·⁠원격 측정⁠·⁠자동 설치⁠·⁠세션 업로드가 "꺼짐"으로 표시됩니다.
무엇을 언제 보내는지는 서버로 가는 데이터에서 봅니다.

네 가지 장치​

장치맡는 것정하는 곳
① 권한 확인파일을 고치거나 명령을 실행하기 전에 묻거나 막습니다. 작업 폴더 밖의 파일을 읽을 때도 묻습니다.권한 모드, 권한 규칙, 폴더 신뢰
② 샌드박스에이전트가 실행하는 명령을 운영체제 수준에서 가둡니다. 작업 폴더 밖 쓰기와 허용하지 않은 외부 접속을 막습니다.샌드박스
③ 관리자 정책사용자가 덮어쓸 수 없는 조직 공통 규칙입니다. 거부 규칙은 어느 권한 모드에서도 우선하고, 에이전트는 정책 파일을 읽거나 고칠 수 없습니다.관리자 정책
④ 감사 기록에이전트가 도구를 쓸 때마다 허용했는지 거부했는지 남깁니다. CSV로 내보냅니다.감사 기록

실행 전에 묻는 모습​

기본 설정에서는 파일을 고치거나 명령을 실행하기 전에 묻습니다.
작업 폴더 밖의 파일을 읽을 때도 묻습니다.

장치마다 맡는 범위​

  • 작업 폴더 밖의 파일을 읽는 것은 샌드박스가 막지 않습니다. 이 부분은 권한 확인이 맡아 실행 전에 묻습니다.
  • 거부 규칙은 명령의 글자를 맞춰 보는 방식입니다. 외부 접속과 작업 폴더 밖 쓰기를 확실히 막으려면 샌드박스를 함께 켭니다.
  • Windows에서는 샌드박스가 기본으로 꺼져 있습니다. 켜는 순서는 Windows 샌드박스 켜기에 있습니다.
  • 입력 가림은 사용자가 입력창에 쓴 글에만 적용됩니다. 에이전트가 읽은 파일 안의 개인정보는 가리지 않습니다.
  • 기록은 각 PC에 남습니다. 중앙에서 모으는 기능은 없습니다.

다음에 볼 글

서버로 가는 데이터Fortress AI가 어디로 무엇을 보내는지, 개인정보를 어떻게 가리는지, 판단 기록을 어디서 보는지 설명합니다.권한 모드에이전트가 실행 전에 어디까지 묻는지 정하는 권한 모드와 기본 동작을 설명합니다.도입 첫 주 점검표관리자가 Fortress AI를 들인 첫 주에 설치 방식, 정책 배포, 샌드박스, 설치 뒤 점검, 사용자 안내, 기록 확인을 차례로 점검하는 목록입니다.
