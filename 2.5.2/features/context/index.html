컨텍스트, 모델, 사용 현황

Fortress AI 2.5.2 기준

이 쪽을 읽으면 컨텍스트가 얼마나 찼는지 보고 줄이고, 모델을 고르고, 답 하나와 기간별 사용량을 확인할 수 있습니다.

1. 컨텍스트를 봅니다​

컨텍스트는 에이전트가 답할 때 한 번에 참고하는 내용입니다.
대화가 길어지고 읽은 파일이 늘면 컨텍스트가 찹니다.
세션 정보의 컨텍스트 칸에서 지금 쓰고 있는 양과 남은 양을 봅니다.

항목내용
메시지주고받은 대화와 에이전트가 읽은 내용
기본 도구, 확장 도구에이전트가 쓸 수 있는 도구의 설명
시스템 프롬프트에이전트의 기본 지침
스킬불러온 스킬의 설명
자동 압축 여유분자동 압축을 위해 비워 두는 공간
남은 공간더 쓸 수 있는 양

2. 컨텍스트를 줄입니다​

  • 메시지 옆의 압축을 누르면 지난 대화를 요약해 공간을 비웁니다.
  • 주제가 바뀌면 새 세션을 엽니다. 관련 없는 지난 대화가 컨텍스트를 차지하지 않습니다.
  • 필요한 파일만 가리킵니다. 폴더 전체를 읽히는 것보다 파일을 @로 가리키는 편이 덜 찹니다.
참고

2.4.0에서 한 시험에서는 대화가 짧을 때 압축을 요청하면 압축하지 않고 "대화가 아직 짧음"이라고 알려 주었습니다.

긴 자료를 읽힐 때​

문서 여러 개를 끝까지 읽히면 읽는 만큼 컨텍스트가 찹니다.
오른쪽 컨텍스트 칸의 비율로 얼마나 찼는지 봅니다.
요청문과 단계는 긴 문서 여러 개를 읽혀 요약 받기에 있습니다.

3. 모델을 고릅니다​

새 세션 화면에서 입력창 아래에 권한 모드와 모델이 보입니다.
입력창 오른쪽 아래의 모델 이름 단추를 누르면 쓸 모델과 노력 수준을 고릅니다.

4. 답 하나에 든 토큰과 시간을 봅니다​

답 아래의 아이콘 이 턴의 토큰과 시간을 누르면 그 답에 든 토큰 수와 처리 시간이 보입니다.

5. 기간별 사용 현황을 봅니다​

사용 현황은 이 PC에서 Fortress AI를 얼마나 썼는지 보여 줍니다.
사이드바의 사용 현황에서 엽니다.

이 화면은 이 PC에 저장된 대화를 기준으로 계산합니다.
날마다 모델이 일한 시간은 날짜별 사용량을 막대로 보여 줍니다.
표로 보기를 누르면 같은 내용을 표로 봅니다.
그 아래 모델별 표에서는 모델마다 턴, 호출, 첫 토큰 시간, 생성 속도, 도구 실패율을 봅니다.

느릴 때​

  • 첫 응답이 늦어졌다면 여러 사람이 동시에 쓰고 있는지 확인합니다. 입력창 아래의 점이 모델 서버의 실행⁠·⁠대기 요청 상태를 보여 줍니다.
  • 한 요청이 오래 걸렸다면 타임라인에서 어느 단계가 길었는지 봅니다.

다음에 볼 글

결과 확인하고 되돌리기에이전트가 한 일을 타임라인으로 보고, 바뀐 파일과 만든 파일을 확인하고, 마음에 들지 않으면 이전 시점으로 되감는 방법입니다.긴 문서 여러 개를 읽혀 요약 받기문서 여러 개를 끝까지 읽혀 문서별 한 줄 요약과 주의할 점을 받고, 그동안 컨텍스트가 얼마나 찼는지 보는 과정입니다.문제 해결파일, 검색, 예약, 로그인에서 자주 생기는 증상과 확인할 것을 정리합니다.
