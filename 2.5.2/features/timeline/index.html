결과 확인하고 되돌리기

Fortress AI 2.5.2 기준

이 쪽을 읽으면 에이전트가 한 일과 바꾼 파일을 확인하고, 마음에 들지 않는 변경을 이전 시점으로 되돌릴 수 있습니다.

1. 한 일을 타임라인으로 봅니다​

타임라인은 에이전트가 요청을 처리하며 한 일을 시간 순서로 보여 줍니다.
어디서 시간이 걸렸는지, 어떤 도구를 썼는지 확인할 때 씁니다.

  • 제목 옆의 대화 | 타임라인에서 타임라인을 고릅니다.
  • 진행 중일 때는 경과 시간을 눌러도 열립니다.

요청 줄을 펼치면 모델 호출과 그 호출이 부른 도구가 한 줄씩 같은 시간축에 놓입니다.
서브에이전트는 한 줄로 보이고, 누르면 그 안의 작업으로 들어갑니다.

이럴 때 봅니다.

  • 작업이 오래 걸렸을 때 어느 단계가 길었는지 찾습니다.
  • 결과를 검토할 때 에이전트가 어떤 파일을 읽고 어떤 명령을 실행했는지 확인합니다.

2. 바뀐 파일과 만든 파일을 봅니다​

대화 화면 오른쪽 칸에서 이 세션이 바꾼 것과 만든 것을 봅니다.

칸보이는 것
변경 사항이 세션에서 고친 파일, 커밋하지 않은 변경, 기본 브랜치와의 차이. 파일별로 되돌릴 수 있습니다.
파일작업 폴더의 파일 트리와 파일 내용. 여러 파일을 탭으로 엽니다.
계획에이전트가 내놓은 계획
미리보기이 PC의 localhost 개발 서버 화면
백그라운드 작업백그라운드에서 도는 명령의 출력. 여기서 중지합니다.
터미널작업 폴더에서 여는 내 셸

칸은 끌어서 배치와 폭을 바꿉니다.
세션 정보의 결과물에서 이 세션이 만든 파일을 모아 봅니다.

파일 칸은 코드, Markdown, CSV⁠·⁠TSV 표, JSON, HTML, 이미지, PDF를 보여 줍니다.
Office와 한글 문서는 에이전트가 읽는 텍스트로 보여 줍니다.
Markdown 파일은 한글 문서로 저장할 수 있습니다.

3. 이전 시점으로 되감습니다​

되감기는 대화의 이전 시점으로 돌아가 그 뒤에 바뀐 코드와 대화를 되돌리는 기능입니다.
잘못 고친 파일을 복구하거나 작업을 되돌리기 할 때 씁니다.

다음 중 하나로 엽니다.

  • 입력창에 /rewind를 입력합니다.
  • 입력창이 비어 있을 때 Esc 키를 두 번 누릅니다.

되감기를 연 뒤에는 아래 순서로 고릅니다.

  1. 돌아갈 메시지를 고릅니다.
  2. 되돌릴 범위를 고릅니다.
범위되돌리는 것
코드와 대화그 시점 뒤에 바뀐 파일과 대화
대화만대화만. 파일은 그대로 둡니다
코드만파일만. 대화는 그대로 둡니다

내 메시지에 마우스를 올리면 이 메시지 전으로 대화 되감기(파일은 그대로) 단추도 보입니다.
이 단추는 대화만 되돌리고 파일은 그대로 둡니다.

되돌려지는 것과 아닌 것​

파일이 바뀐 방식되감기 결과
편집 도구로 고친 파일되돌립니다
명령으로 바뀐 파일 (예: 명령으로 지운 파일)되돌리지 않습니다
주의

명령으로 지우거나 바꾼 파일은 되감기로 복구되지 않습니다.
되감기 창은 명령으로 바뀐 파일을 따로 표시합니다.
중요한 폴더는 작업 전에 따로 보관합니다.

권한 판단 기록은 감사 기록에서 따로 봅니다.
