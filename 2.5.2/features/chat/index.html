Fortress AI 2.5.2 기준

이 쪽을 읽으면 요청을 보내고, 작업 중에 다음 요청을 넣고, 파일을 넘기고, 지난 세션을 찾아 이어 갈 수 있습니다.

1. 요청을 보냅니다​

입력창에 맡길 일을 적고 보냅니다.

하려는 일WindowsmacOS
보내기EnterEnter
줄바꿈Shift+EnterShift+Enter
대기열에 넣기Ctrl+EnterCommand+Enter
중단EscEsc

보낸 메시지는 ↑ ↓ 키로 다시 불러옵니다.
입력창이 비어 있을 때 Tab 키를 누르면 다음에 보낼 만한 메시지를 제안합니다.
제안은 설정의 일반에서 끌 수 있습니다.

2. 작업 중에 다음 요청을 넣습니다​

에이전트가 일하는 중에도 요청을 끼워 넣거나 대기열에 넣을 수 있습니다.
일하는 동안 입력창에는 "↩ 지금 전달 ⁠·⁠ Ctrl+↩ 대기열" 안내가 보입니다.

화면 안내누르는 키동작
지금 전달Enter진행 중인 작업에 끼워 넣습니다.
대기열Ctrl+Enter지금 응답이 끝난 뒤에 처리합니다.

사이드 채팅​

작업을 방해하지 않고 물어볼 것이 있으면 사이드 채팅을 씁니다.

예
/btw 지금 고치는 파일이 몇 개야?

사이드 채팅의 질문과 답은 대화에 남지 않습니다.
작업 중에도 물을 수 있습니다.

3. 파일을 넘깁니다​

에이전트에게 파일을 넘기는 방법은 두 가지입니다.
PC의 파일을 첨부하거나, 작업 폴더에 있는 파일을 @로 가리킵니다.

첨부하기​

  1. 입력창의 + 메뉴를 엽니다. 단축키는 Windows Ctrl+U, macOS Command+U입니다.
  2. 파일이나 사진을 고릅니다.
  3. 요청 글을 함께 적고 보냅니다.

PDF, Office, 한글 파일은 글자를 뽑아 요청에 붙입니다.
형식별 처리 범위는 파일 형식에서 봅니다.

작업 폴더의 파일 가리키기​

입력창에 @를 입력하면 작업 폴더의 파일을 골라 가리킬 수 있습니다.
고른 파일은 입력창에 칩으로 표시됩니다.

예
@docs/현행분석서.md 의 3장을 표로 다시 정리해줘.

4. 답을 읽습니다​

화면에 보이는 것뜻
명령 줄에이전트가 실행한 명령입니다. 설명으로 보이고, 펼치면 실제 명령이 나옵니다.
편집 줄고친 파일입니다. 펼치면 바뀐 줄을 비교해 보여 줍니다.
승인 카드실행 전에 확인을 묻는 카드입니다. 내용을 읽고 허용하거나 거부합니다.
질문 카드에이전트가 사용자에게 되묻는 카드입니다.
계획 카드실행 전에 내놓은 계획입니다.
할 일에이전트가 나눠 둔 작업 목록입니다.

실패한 요청은 다시 시도할 수 있습니다.
에이전트가 한 일과 걸린 시간을 차례로 보려면 결과 확인하고 되돌리기를 봅니다.

5. 지난 세션을 찾아 이어 갑니다​

세션이 늘어나면 검색과 사이드바 정리 기능으로 찾습니다.

검색​

사이드바의 검색을 누릅니다.
단축키는 Windows Ctrl+K, macOS Command+K입니다.

기능설명
탭대화, 폴더, 보관함으로 범위를 나눕니다.
초성 검색초성만 입력해도 찾습니다. 예: ㄷㅍ
내용 검색두 글자부터 대화 내용에서 찾습니다.
명령 찾기/를 입력하면 명령을 찾습니다.

사이드바 목록​

세션은 폴더별로 묶여 보입니다.

할 수 있는 일선택지
묶기폴더, 날짜
정렬최근 활동, 만든 날짜
걸러 보기실행 중인 것만, 읽지 않은 것만

줄 오른쪽의 점은 상태를 나타냅니다.

점뜻
실행 중 표시에이전트가 일하고 있습니다.
주황사용자의 입력이나 승인을 기다립니다.
파랑읽지 않은 답이 있습니다.

세션 메뉴​

세션 줄의 ⁠·⁠⁠·⁠⁠·⁠ 메뉴에서 아래 일을 합니다.

메뉴동작
다음에서 열기작업 폴더를 파일 탐색기, VS Code, 터미널에서 엽니다.
고정사이드바의 고정됨에 올립니다.
읽음 표시읽음 상태를 바꿉니다.
이름 변경세션 이름을 바꿉니다.
포크지금까지의 내용을 복사해 새 세션을 만듭니다. 원래 세션 아래에 트리로 보입니다.
링크 복사세션 링크를 복사합니다.
보관목록에서 내리고 보관함에 둡니다. 검색의 보관함 탭에서 찾습니다.
삭제세션을 지웁니다.

단축키 전체는 단축키와 명령에서 봅니다.

다음에 볼 글

결과 확인하고 되돌리기에이전트가 한 일을 타임라인으로 보고, 바뀐 파일과 만든 파일을 확인하고, 마음에 들지 않으면 이전 시점으로 되감는 방법입니다.프로젝트로 묶기여러 갈래의 일을 프로젝트로 묶어 스레드로 나눠 맡기고 보고를 받는 방법과 프로젝트 화면의 구성입니다.업무별로 해 보기장애 처리 보고서, 현행 분석서, DB 구조 정의서, 한글 문서 저장, 보안 검토, 긴 문서 요약, 반복 업무 예약을 업무별로 따라 합니다.
