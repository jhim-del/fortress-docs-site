파일 형식

Fortress AI 2.5.2 기준

이 쪽을 읽으면 어떤 파일을 읽힐 수 있고 어떤 문서로 받을 수 있는지 형식별로 알 수 있습니다.

파일 형식마다 읽는 범위가 다릅니다.
화면에 보이는 내용, AI에 전달되는 내용, 새 파일로 만드는 기능은 서로 다르므로 나눠서 봅니다.

첨부해서 읽히기​

첨부한 것처리
PDF, Office, 한글(HWPX) 파일글자를 뽑아 요청에 붙입니다.
UTF-8이 아닌 텍스트 (예: 한국어 Windows 엑셀에서 저장한 CSV)풀어서 붙이고 원래 인코딩을 알려 줍니다.
256KB가 넘는 텍스트, 바이너리 파일파일로 남겨 두고 에이전트가 나눠 읽습니다.
글자 층이 없는 쪽이 있는 PDF (스캔 문서)그림을 읽는 모델이 연결되어 있으면 쪽을 그림으로 읽습니다.

화면에서 보기​

형식파일 패널에서 보이는 것
TXT, MD텍스트. Markdown은 미리보기와 원문을 전환하고 한글로 저장할 수 있습니다.
CSV행과 열로 정리한 표
PDF원본 페이지와 추출 텍스트를 전환해 봅니다.
DOCX본문, 제목, 목록, 표에서 뽑은 텍스트
XLSX시트 이름과 저장된 셀 값. 수식을 새로 계산하지 않습니다.
PPTX슬라이드의 텍스트와 발표자 노트. 배치와 그림을 모두 재현하지는 않습니다.

만들기​

만드는 것방법
한글 문서 (HWPX)Markdown으로 쓴 결과를 한글로 저장하거나 말로 요청합니다.
Word 문서 (DOCX)fortress docx로 Markdown을 Word 파일로 바꿉니다. 2.5.2부터 들어 있습니다.

알아 둘 제한​

  • 문서는 글자로 읽습니다. 서식, 배치, 그림은 그대로 전달되지 않습니다.
  • 한글과 Word 문서는 Markdown에서 변환해 만듭니다. 기관 양식의 표 모양과 로고를 그대로 채우는 기능이 아닙니다.
  • 구형 한글 파일(.hwp)은 형식 표에 없습니다. HWPX로 저장한 뒤 첨부합니다.
  • 암호가 걸렸거나 손상된 파일은 읽지 못할 수 있습니다.
