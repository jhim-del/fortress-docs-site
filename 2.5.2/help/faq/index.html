자주 묻는 질문

Fortress AI 2.5.2 기준

이 쪽을 읽으면 처음 보는 분이 먼저 묻는 질문과 보안, 파일, 예약, 설치 질문의 답을 찾을 수 있습니다.

처음 묻는 질문​

외부 AI 서비스와 무엇이 다른가요?​

모델이 회사 안에 둔 장비에서 돕니다.
데이터를 보내는 곳은 웹 화면의 보안⁠·⁠감사에 표시됩니다.
2.5.2 화면에서는 전송 대상이 "이 서버만"으로, 외부 버전 확인⁠·⁠원격 측정⁠·⁠자동 설치⁠·⁠세션 업로드가 "꺼짐"으로 표시됩니다.
어디로 무엇을 보내는지는 서버로 가는 데이터에 화면과 함께 있습니다.

공개된 모델을 직접 띄워 쓰는 것과 무엇이 다른가요?​

모델만 띄우면 질문에 답하는 서버가 생깁니다.
Fortress AI에는 모델 서버와 함께 아래가 들어 있습니다.

들어 있는 것설명
일하는 화면파일을 읽고 고치고 명령을 실행하는 에이전트를 웹 화면과 터미널에서 씁니다.
실행 전 확인권한 모드와 권한 규칙으로 무엇을 묻고 막을지 정합니다.
샌드박스샌드박스가 작업 폴더 밖 쓰기와 허용하지 않은 외부 접속을 막습니다.
관리자 정책관리자 정책의 거부 규칙은 어느 권한 모드에서도 우선하고, 에이전트는 정책 파일을 고칠 수 없습니다.
판단 기록도구를 쓸 때마다 허용⁠·⁠거부가 감사 기록에 남고, CSV로 내보냅니다.
되돌리기되감기로 대화와 코드를 이전 시점으로 돌립니다.

에이전트가 파일을 마음대로 바꾸면 어떻게 하나요?​

기본 설정에서는 파일을 고치거나 명령을 실행하기 전에 묻습니다.
작업 폴더 밖의 파일을 읽을 때도 묻습니다.
기본 동작은 권한 모드에 표로 있습니다.
이미 바뀐 내용은 되감기로 되돌립니다.
되돌려지지 않는 것도 있으니 그 쪽의 표를 먼저 봅니다.

에이전트가 틀리면 어떻게 확인하나요?​

결과는 담당자가 확인하고 씁니다.
에이전트가 읽은 파일, 실행한 명령, 걸린 시간은 타임라인에서 차례로 봅니다.
도구를 쓸 때마다의 허용⁠·⁠거부는 감사 기록에 남습니다.

보안​

회사 데이터가 밖으로 나가지 않는지 확인할 수 있나요?​

화면에서 확인합니다.
사이드바의 보안⁠·⁠감사를 열면 전송 대상이 "이 서버만"으로, 외부 버전 확인⁠·⁠원격 측정⁠·⁠자동 설치⁠·⁠세션 업로드가 "꺼짐"으로 표시됩니다.
서버로 가는 데이터에 화면이 있습니다.

어떤 내용이 모델 서버로 가나요?​

사용자가 쓴 요청과 에이전트가 읽은 파일 내용, 실행한 명령의 출력이 갑니다.
세션을 시작할 때는 작업 폴더 경로, 운영체제, 지침 파일도 함께 갑니다.
모델 서버는 사내 장비입니다.

개인정보를 입력하면 어떻게 되나요?​

입력창에 쓴 주민등록번호, 휴대폰 번호, 카드 번호는 모델로 보내기 전에 가립니다.
에이전트가 읽은 파일 안의 개인정보는 가리지 않습니다.
개인정보가 든 파일은 작업 폴더에 두지 않거나 권한 규칙으로 읽기를 막습니다.

기록은 어디에 남나요? 관리자가 한곳에서 볼 수 있나요?​

도구를 쓸 때마다의 판단이 각 PC의 파일에 남습니다.
중앙에서 모으는 기능은 없습니다.
모아서 보려면 각 PC의 기록 파일을 수집합니다.
감사 기록에 파일 위치가 있습니다.

거부된 기록만 골라 보고 파일로 받을 수 있나요?​

됩니다.
보안⁠·⁠감사에서 거부를 고르고 CSV 내보내기를 누릅니다.

조직 규칙을 사용자가 바꾸지 못하게 할 수 있나요?​

관리자 정책으로 정합니다.
관리자 정책의 거부 규칙은 어느 권한 모드에서도 우선하고, 에이전트는 정책 파일을 읽거나 고칠 수 없습니다.

파일과 문서​

스캔한 문서의 표도 읽나요?​

그림을 읽는 모델이 연결되어 있으면 읽습니다.
2.4.0에서 한 시험에서는 글자 층이 없는 공문 1쪽의 표 숫자 20개를 모두 맞게 읽었습니다.
여러 쪽이나 도표가 많은 문서는 결과를 대조해 확인합니다.

구형 한글 파일(.hwp)도 읽나요?​

형식 표에 없는 형식입니다.
2.4.0에서 한 시험에서는 본문은 읽었지만 문서 머리 부분의 날짜가 빠졌습니다.
HWPX로 저장한 뒤 첨부합니다.

우리 기관의 한글 양식에 그대로 채워 주나요?​

그대로 채우는 기능은 아닙니다.
결과를 Markdown으로 쓰고 한글 문서로 변환하므로 양식의 표 모양과 로고는 재현되지 않습니다.
결과를 한글 문서로 저장하기를 봅니다.

큰 파일도 첨부할 수 있나요?​

256KB가 넘는 텍스트와 바이너리 파일은 거절하지 않고 파일로 남겨 둔 뒤 에이전트가 나눠 읽습니다.
파일 형식에서 형식별 범위를 봅니다.

사내 문서 수천 건을 검색해서 답하나요?​

기본 제품에는 사내 문서 전체를 색인해 검색하는 기능이 없습니다.
작업 폴더에 둔 파일을 읽어 일합니다.

예약과 반복​

예약한 시각에 PC가 꺼져 있으면 어떻게 되나요?​

다시 켜서 Fortress 웹을 열 때 놓친 실행을 한 번 실행합니다.
최근 7일 안의 것만 해당합니다.
예약과 반복 실행에 조건이 있습니다.

반복 실행의 가장 짧은 간격은 얼마인가요?​

/loop의 간격은 1분에서 24시간 사이입니다.
예약과 반복 실행을 봅니다.

설치와 접속​

인터넷이 없는 망에서 설치할 수 있나요?​

됩니다.
반입한 묶음 파일의 설치 스크립트로 설치합니다.
설치 방식과 점검에 순서가 있습니다.

웹 화면을 다른 PC에서 열 수 있나요?​

웹 화면은 실행한 PC에서만 열립니다.
공용 개발 서버에 설치한 경우에는 fortress web이 보여 주는 명령으로 연결한 뒤 자기 PC 브라우저에서 엽니다.

업데이트는 자동으로 되나요?​

새 판이 있으면 알려 주고, 받는 것은 사용자가 fortress update로 직접 합니다.
