요청 보내고 이어 가기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 일을 처음 맡기거나, 작업 중에 다음 요청을 넣고 싶을 때
  • 파일을 전달하거나 작업 폴더의 문서를 열어 보고 싶을 때
  • 지난 세션을 찾아 이어 가거나 정리하고 싶을 때

(대화 하나)은 작업 폴더를 고르고 요청을 보내는 것으로 시작합니다.

1. 작업 폴더를 고릅니다​

새 세션 화면 가운데 "어디서 작업할까요?" 카드에서 어디서 일할지 고릅니다.
(에이전트가 읽고 고치는 폴더)는 최근 폴더를 누르거나 폴더 선택… 메뉴에서 고릅니다.

폴더 선택… 메뉴하는 일
폴더 검색…이미 써 본 폴더를 이름으로 찾습니다. 처음 쓰는 폴더는 여기에 나오지 않습니다.
폴더 찾아보기… (Ctrl+Alt+1)이 PC의 폴더 선택 창을 띄웁니다. 처음 쓰는 폴더는 여기서 고릅니다.
최근 폴더 (Ctrl+Alt+2부터)누르면 그 폴더가 작업 폴더로 정해집니다.
  • Windows의 폴더 선택 창은 Windows 기본 창이라 버튼 이름이 영어(Select Folder, Cancel)로 보일 수 있습니다.
  • 폴더 선택 창을 띄울 수 없는 곳에서는 웹 화면 안의 폴더 창이 대신 뜹니다. Windows에서는 "내 PC"에서 다른 드라이브로 옮겨 갑니다.
  • git 폴더라면 브랜치를 고를 수 있습니다. 고른 브랜치로 시작할 때 전환합니다.
  • 환경은 추가 폴더와 환경 변수를 묶어 둔 것입니다. 기본은 없음입니다.

2. 요청을 보냅니다​

입력창에 맡길 일을 적고 Enter를 누릅니다.
줄을 바꾸려면 Shift+Enter, 멈추려면 Esc를 누릅니다.

이렇게 보이면 된 것 보낸 글이 말풍선으로 올라가고, 대화 화면 오른쪽 환경 칸에 작업 폴더 이름이 보입니다.

보낸 메시지는 ↑ ↓ 키로 다시 불러옵니다.
입력창이 비어 있을 때 Tab을 누르면 다음에 보낼 만한 메시지를 제안합니다.
제안은 설정의 일반 탭에서 끕니다.

3. 작업 중에 다음 요청을 넣습니다​

에이전트가 일하는 중에도 요청을 끼워 넣거나 (지금 응답이 끝난 뒤 처리할 요청)에 넣습니다.
일하는 동안 입력창에는 "↩ 지금 전달 ⁠·⁠ Ctrl+↩ 대기열" 안내가 보입니다.

화면 안내누르는 키동작
지금 전달Enter진행 중인 작업에 끼워 넣습니다.
대기열Ctrl+Enter지금 응답이 끝난 뒤에 처리합니다.

이렇게 보이면 된 것 대기열에 넣은 요청은 말풍선 위에 대기 중이 붙어 보이고, 지금 응답이 끝나면 이어서 처리됩니다.

대기 중인 말풍선 아래에는 편집 버튼이 보입니다.

사이드 채팅​

작업을 방해하지 않고 물어볼 것이 있으면 을 씁니다.

예
/btw 지금 고치는 파일이 몇 개야?

사이드 채팅의 질문과 답은 대화에 남지 않고, 에이전트가 작업하는 중에도 씁니다.

4. 명령을 부릅니다​

입력창에 /를 입력하면 쓸 수 있는 명령 목록이 열리고, 고르고 있는 명령의 설명이 옆에 보입니다.
고른 명령은 입력창에 칩으로 표시되고, 보내면 명령의 결과가 대화에 남습니다.

이렇게 보이면 된 것 입력창에 명령이 칩으로 바뀌어 보입니다.

자주 쓰는 명령입니다.

명령하는 일
/btw 질문대화에 남기지 않고 작업과 별도로 질문합니다.
/rewind이전 시점으로 되감기를 엽니다.
/review, /security-review커밋하지 않은 변경을 검토하게 합니다. 보안 검토 결과는 답 글과 답 끝의 분류 보드로 나옵니다(보안 검토).
/init이 폴더의 지침 파일(AGENTS.md)을 쓰게 합니다.
/loop 간격 요청같은 요청을 간격마다 다시 넣습니다. 반복 실행을 봅니다.

입력창의 + 메뉴에서도 명령, (외부 도구 연결), 사이드 채팅을 고릅니다.
사이드바 검색에서 /를 입력하면 명령을 찾습니다.
직접 만든 명령을 더하는 법은 내 방식으로 맞추기에 있습니다.

5. 파일을 첨부하거나 가리킵니다​

에이전트에게 파일을 전달하는 방법은 두 가지입니다.
PC의 파일을 첨부하거나, 작업 폴더에 있는 파일을 @로 가리킵니다.

첨부하기​

  1. 입력창의 + 메뉴를 엽니다. 단축키는 Windows Ctrl+U, macOS Command+U입니다.
  2. 파일이나 사진을 고릅니다.
  3. 요청 글을 함께 적고 보냅니다.

PDF, Office, 한글 파일은 텍스트를 추출해 요청에 붙입니다.
한국어 Windows 엑셀이 만든 CSV처럼 UTF-8이 아닌 텍스트도 풀어서 붙이고, 원래 인코딩을 알려 줍니다.
256KB를 넘는 텍스트처럼 글로 넣을 수 없는 것은 파일로 남기고, 에이전트가 도구로 읽습니다.

형식별 처리 범위는 파일 형식에서 봅니다.

작업 폴더의 파일 가리키기​

입력창에 @를 입력하면 작업 폴더의 파일을 골라 가리킵니다.
고른 파일은 입력창에 칩으로 표시됩니다.

예
@docs/현행분석서.md 의 3장을 표로 다시 정리해줘.

@로 이 PC의 다른 세션도 가리킬 수 있습니다.
에이전트는 가리킨 세션을 읽고, 시키면 그 세션에 메시지를 보내거나 새 세션을 시작해 보고받습니다.
다른 세션을 읽는 것은 묻지 않고, 메시지를 보내거나 새 세션을 시작할 때는 묻습니다(권한 모드).

6. 답을 읽습니다​

답은 쓰는 중에도 굵은 글씨, 목록, 표로 그려집니다.
수식($…$, $$…$$)은 그림으로 바꿔 보여 줍니다.

이렇게 보이면 된 것 표를 요청하면 답이 끝나기 전부터 표 모양으로 보이고, 수식은 기호 그대로 그려집니다.

화면에 보이는 것뜻
명령 줄에이전트가 실행한 명령입니다. 설명으로 보이고, 펼치면 실제 명령이 나옵니다.
편집 줄고친 파일입니다. 펼치면 바뀐 줄을 비교해 보여 줍니다.
실행 전에 확인을 묻는 카드입니다. 내용을 읽고 허용하거나 거부합니다.
질문 카드, 계획 카드에이전트가 되묻거나 실행 전에 내놓은 계획입니다.
할 일에이전트가 나눠 둔 작업 목록입니다.
코드 블록문법에 맞게 색이 칠해지고, 복사 버튼이 있습니다.
생각 시간답하기 전에 생각한 시간입니다.

실패한 요청은 다시 시도할 수 있습니다.
내 말풍선에 마우스를 올리면 복사, 편집, 되돌리기 버튼과 보낸 시각, 읽음 표시가 보입니다.
편집 버튼은 그 메시지 전으로 대화를 되감고 파일은 그대로 둡니다(되감기).

긴 세션은 끝의 3턴을 먼저 그리고, 위로 올리면 앞의 대화를 더 불러옵니다.
에이전트가 한 일과 걸린 시간을 차례로 보려면 결과 확인하고 되돌리기를 봅니다.

7. 작업 폴더의 파일을 열어 봅니다​

대화 화면 위쪽의 파일을 누르면 오른쪽 칸에 작업 폴더의 파일 목록이 열립니다.
파일을 누르면 탭으로 열리고, 탭 위에 폴더 경로가 보입니다.

이렇게 보이면 된 것 오른쪽 칸에 파일 목록이 보이고, 누른 파일이 탭으로 열립니다.

형식보이는 모양
한글(.hwpx)텍스트를 미리 봅니다. 서식은 보이지 않고, 표는 칸이 하나씩 풀린 텍스트 줄로 보입니다. 탭 위에 구역 수와 "표는 풀어서" 안내가 붙습니다.
CSV, TSV표와 원문 가운데 골라 봅니다. 표 아래에 줄 수와 열 수가 나옵니다.
PDF원본(파일 그대로)과 텍스트(추출한 텍스트) 가운데 골라 봅니다.
PowerPoint슬라이드의 텍스트와 발표자 노트만 보입니다. 화면에는 "텍스트⁠·⁠발표자 노트만"으로 표시됩니다.
Word, 엑셀, 노트북에이전트가 읽는 글(Markdown)로 바꿔 보여 줍니다. 원래 서식은 보이지 않습니다.
이미지파일 그대로 보여 줍니다.
Markdown한글 문서(.hwpx)로 저장할 수 있습니다.
코드, JSON, HTML코드는 색을 칠해, JSON은 펼치는 트리로, HTML은 스크립트를 끈 상태로 보여 줍니다.

한글, PDF, PowerPoint 탭에는 기본 앱으로 열기 버튼이 있습니다.
원래 서식 그대로 봐야 할 때는 이 PC의 프로그램에서 엽니다.

Markdown을 한글로 저장하는 단계는 한글 문서로 저장에 있습니다.

8. 지난 세션을 찾아 이어 갑니다​

세션이 늘어나면 검색과 사이드바 정리 기능으로 찾습니다.

검색​

사이드바의 검색을 누릅니다.
단축키는 Windows Ctrl+K, macOS Command+K입니다.

검색 창 위쪽의 전체, 세션, 폴더, 보관됨 탭으로 범위를 나누고, 초성(ㄷㅍ)만 쳐도 찾습니다.
두 글자부터는 대화 내용에서도 찾습니다.

사이드바 목록​

세션은 폴더별로 묶여 보입니다.
폴더나 날짜로 묶고, 최근 활동이나 만든 날짜로 정렬하고, 실행 중이거나 읽지 않은 것만 골라 볼 수 있습니다.
한 세션과 서브에이전트의 세션은 원래 세션 아래에 트리로 보입니다.

줄 오른쪽 점뜻
실행 중 표시에이전트가 일하고 있습니다.
주황사용자의 입력이나 승인을 기다립니다.
파랑읽지 않은 답이 있습니다.

세션 메뉴​

세션 줄에 마우스를 올리면 오른쪽에 ⁠·⁠⁠·⁠⁠·⁠ 버튼이 보입니다.
누르면 나오는 메뉴에서 정리합니다.

메뉴동작
다음에서 열기작업 폴더를 파일 탐색기, VS Code, 터미널에서 엽니다.
고정사이드바의 고정됨 그룹에 넣습니다.
읽지 않음으로 표시읽음 상태를 바꿉니다.
이름 변경세션 이름을 바꿉니다.
포크지금까지의 내용을 복사해 새 세션을 만듭니다. 원래 세션 아래에 트리로 보입니다.
링크 복사세션 링크를 복사합니다.
보관사이드바 목록에서 내립니다.
삭제세션을 지웁니다.

보관을 누르면 화면 위쪽에 "보관됨: 세션 이름" 알림이 뜹니다.
잘못 눌렀으면 알림의 되돌리기를 누릅니다.
세션이 다시 사이드바 목록에 보입니다.

검색 창에는 보관됨 탭이 따로 있습니다.
세션을 다른 사람과 나누는 공유 기능은 없습니다.

이렇게 보이면 된 것 보관한 세션이 사이드바에서 빠지고, 위쪽에 "보관됨" 알림과 되돌리기가 보입니다.

다음에 볼 글

결과 확인하고 되돌리기에이전트가 한 일을 타임라인으로 보고, 바뀐 파일과 만든 파일을 확인하고, 마음에 들지 않으면 이전 시점으로 되감는 방법입니다.설정과 화면 맞추기웹 화면의 설정을 여는 법과 일곱 탭의 구성, 새 세션의 권한 모드·알림·야간 큐 시간·화면 모양·로그인·버전 번호를 보고 바꾸는 곳입니다.업무별로 해 보기월간 업무보고, 과업내용서, 보고서 검수, 회의록, 계약서 점검, 인수인계, 규정 질의 같은 사무 업무와 개발·운영 업무를 받는 결과물로 골라 따라 합니다.
