결과 확인하고 되돌리기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 작업이 오래 걸려 어느 단계에서 시간이 들었는지 알고 싶을 때
  • 에이전트가 어떤 파일을 읽고 무엇을 바꿨는지 검토할 때
  • 마음에 들지 않는 변경을 이전 시점으로 되돌리고 싶을 때

에이전트가 한 일은 세 곳에서 확인합니다.
답 안의 도구 실행 줄, 시간 순서로 보는 , 바뀐 파일을 보는 오른쪽 칸입니다.
되돌릴 때는 를 씁니다.

1. 답 안에서 읽은 파일과 실행한 명령을 봅니다​

답 맨 위의 도구 실행 줄(예: "명령 2개 실행")을 누르면 펼쳐집니다.
명령은 에이전트가 붙인 설명으로 보이고, 펼치면 실제 명령이 나옵니다.
편집 줄을 펼치면 바뀐 줄을 비교해 보여 줍니다.

이렇게 보이면 된 것 에이전트가 읽은 파일 이름과 실행한 명령이 줄마다 보입니다.

2. 한 일을 타임라인으로 봅니다​

타임라인은 요청마다 한 일을 시간 순서로 보여 줍니다.

  1. 제목 옆의 대화 | 타임라인에서 타임라인을 고릅니다. 진행 중일 때는 경과 시간을 눌러도 열립니다.
  2. 요청 줄을 펼칩니다.

이렇게 보이면 된 것 모델 호출과 그 호출이 부른 도구가 한 줄씩 같은 시간축에 놓입니다.

(일을 나눠 맡는 보조 에이전트)는 한 줄로 보이고, 누르면 그 안의 작업으로 들어갑니다.
맨 위 막대는 모든 요청을 합친 시간 비율입니다.

3. 바뀐 파일과 만든 파일을 봅니다​

대화 화면 오른쪽 칸에서 이 세션이 바꾼 것과 만든 것을 봅니다.

  1. 대화 화면 위쪽의 변경 사항을 누릅니다.
  2. 파일을 골라 바뀐 줄을 봅니다. 마음에 들지 않는 파일은 파일별로 되돌립니다.
  3. 오른쪽 결과물 칸에서 이 세션이 만든 파일을 모아 봅니다.

이렇게 보이면 된 것 변경 사항 칸에 바뀐 파일 목록과 줄 비교가 보이고, 결과물 칸에 새로 만든 파일 이름이 보입니다.

칸보이는 것
변경 사항이 세션에서 고친 파일, 커밋하지 않은 변경, 기본 브랜치와의 차이. 파일 트리와 커밋 목록, 파일별 되돌리기, 줄 의견이 있습니다.
파일작업 폴더의 파일 트리와 파일 내용. 여러 파일을 탭으로 엽니다.
계획에이전트가 내놓은 계획
미리보기이 PC의 localhost 개발 서버 화면
백그라운드 작업백그라운드에서 실행되는 명령의 출력. 여기서 중지합니다.
터미널작업 폴더에서 여는 내 셸

칸은 끌어서 배치와 폭을 바꿉니다.
파일 칸에서 형식별로 보이는 모양은 작업 폴더의 파일을 열어 봅니다에 있습니다.

4. 이전 시점으로 되감습니다​

되감기는 대화의 이전 시점으로 돌아가는 기능입니다.
대화만 되돌리는 방법과, 파일까지 고를 수 있는 방법이 있습니다.

내 메시지의 편집 버튼으로 대화만 되감기​

  1. 되돌아갈 내 메시지에 마우스를 올립니다.
  2. 연필 모양 버튼을 누릅니다. 버튼 설명은 "편집: 이 메시지 전으로 대화 되감기 (파일은 그대로)"입니다.

이렇게 보이면 된 것 화면 위쪽에 "대화를 되감음" 알림이 뜨고, 그 메시지의 글이 입력창에 다시 들어갑니다.

그 메시지와 뒤의 대화는 사라집니다.
입력창의 글을 고쳐서 다시 보냅니다.

이 방법은 대화만 되돌립니다.
에이전트가 이미 고친 파일은 그대로 남습니다.

/rewind로 파일까지 되돌리기​

  1. 입력창에 /rewind를 입력하거나, 입력창이 비어 있을 때 Esc를 두 번 누릅니다.
  2. 목록에서 돌아갈 메시지를 고르고 Enter를 누릅니다.

이렇게 보이면 된 것 "되감기 — 이전 메시지로 복원" 창이 뜨고, 돌아갈 수 있는 내 메시지가 목록으로 보입니다.

요령

목록의 메시지를 마우스로 누르기만 해서는 다음 화면으로 넘어가지 않습니다.
메시지를 고른 채 Enter를 누릅니다.

  1. "무엇을 복원할까요?" 화면에서 되돌릴 범위를 고르고 Enter를 누릅니다.
고르는 것화면의 설명
코드와 대화 복원파일 ⁠·⁠ 대화 모두 이 메시지 전으로
대화만 복원파일은 그대로
코드만 복원대화는 그대로

범위 아래에는 "명령(bash)으로 바뀐 파일은 제외"라고 적혀 있습니다.

이렇게 보이면 된 것 화면 위쪽에 "대화를 되감음" 알림이 뜨고, 고른 메시지의 글이 입력창에 다시 들어갑니다.

되돌려지는 것과 아닌 것​

파일이 바뀐 방식되감기 결과
편집 도구로 고친 파일되돌립니다
명령으로 바뀐 파일 (예: 명령으로 지운 파일)되돌리지 않습니다
주의

명령으로 지우거나 바꾼 파일은 되감기로 복구되지 않습니다.
되감기 창의 범위 아래에도 "명령(bash)으로 바뀐 파일은 제외"라고 적혀 있습니다.
중요한 폴더는 작업 전에 따로 보관합니다.

관리자가 되감기 기능을 끈 PC에서는 되감기 버튼이 보이지 않습니다.
권한 판단은 감사 로그에서 따로 봅니다.
