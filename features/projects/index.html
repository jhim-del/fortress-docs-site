프로젝트로 묶기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 한 세션에 담기 어려운 큰 일을 여러 부분으로 나눠 맡기고 싶을 때
  • 같은 업무의 대화와 폴더를 한곳에 모아 두고 싶을 때

(여러 세션과 자료를 묶은 단위)는 큰 일을 여러 부분으로 나눠 맡길 때 씁니다.
프로젝트의 대화가 일을 (나눠 맡긴 일 하나)로 나누고, 스레드마다 보고를 받습니다.
프로젝트는 웹 화면에만 있습니다.

1. 프로젝트를 만듭니다​

  1. 사이드바의 프로젝트를 누릅니다.
  2. 새 프로젝트를 누릅니다.
  3. 이름을 적습니다. 목표는 적지 않아도 됩니다.
  4. 프로젝트 생성을 누릅니다.

이렇게 보이면 된 것 프로젝트 목록에 새 프로젝트가 카드로 보이고, 사이드바의 고정됨에도 보입니다.

2. 프로젝트를 엽니다​

사이드바 고정됨에 있는 프로젝트 이름을 누릅니다.
프로젝트 화면이 열립니다.

보이는 곳하는 일
프로젝트 이름 옆 대화 ⁠·⁠ 타임라인프로젝트의 대화와, 그 대화가 한 일을 시간 순서로 봅니다.
시작 안내 버튼 4개최근 작업 이어서 하기, 폴더 추가, 계획 세우기, 내 도구 사용 가운데 하나를 골라 시작합니다.
입력창세션처럼 /로 명령을 부르고 @로 파일을 가리킵니다.

이렇게 보이면 된 것 대화 칸에 "다음 방법으로 시작해 보세요." 안내와 시작 안내 버튼 4개가 보입니다.

오른쪽 위의 개요 버튼은 오른쪽 스레드 칸을 열고 닫습니다.
스레드 칸에는 나눠 맡긴 일이 쌓이고, 아직 없으면 "대화에 일을 보내면 스레드가 생깁니다."가 보입니다.

3. 일을 나눠 맡깁니다​

프로젝트의 대화에 큰 일을 요청합니다.
대화가 일을 스레드로 나눠 맡기고, 스레드가 끝나면 보고를 받습니다.

4. 환경을 정합니다​

환경은 추가 폴더와 환경 변수를 묶어 둔 것입니다.
작업 폴더 밖의 자료 폴더를 함께 써야 할 때 추가 폴더로 넣습니다.
기본은 없음이고, 정한 환경은 이 PC에 저장됩니다.

새 세션 화면 카드에서는 기본 환경 줄에서 고릅니다.

5. 예약 작업을 겁니다​

프로젝트 안에서 만든 예약 작업은 사이드바의 예약됨에 다른 예약 작업과 함께 보입니다.
만들고 관리하는 법은 예약과 반복 실행에 있습니다.

세션과의 차이​

세션프로젝트
단위한 가지 일여러 부분으로 나눈 일
진행한 대화에서 이어 갑니다.스레드로 나눠 맡기고 보고를 받습니다.
폴더작업 폴더 하나를 고릅니다.시작 안내에 폴더 추가 버튼이 있습니다.
쓰는 곳웹 화면, 터미널 화면웹 화면
참고

관리자가 프로젝트 기능을 끈 PC에서는 사이드바에 프로젝트가 보이지 않습니다.

다음에 볼 글

예약과 반복 실행정한 시각에 실행하도록 일을 맡겨 두는 예약 작업, 붐빌 때 밤으로 미루는 야간 큐, 오래 걸리는 명령을 대화를 막지 않고 실행하는 백그라운드 작업, 같은 요청을 일정한 간격으로 다시 실행하는 반복 실행입니다.내 방식으로 맞추기지침 파일, 스킬, 서브에이전트, 명령, 커넥터, PowerShell 도구, 권한 규칙으로 Fortress AI가 일하는 방식을 조직과 업무에 맞추는 방법입니다.
