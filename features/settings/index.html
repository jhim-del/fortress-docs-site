설정과 화면 맞추기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 화면을 어둡게 하거나 글자를 키우고 싶을 때
  • 새 세션의 권한 모드나 야간 큐가 실행되는 시간을 정하고 싶을 때
  • 로그인 상태, 버전 번호, 설치 상태를 확인하고 싶을 때

웹 화면의 설정은 창 하나에 일곱 탭으로 모여 있습니다.
항목마다 한 문장 설명이 붙어 있고, 맨 위 검색 칸으로 항목을 찾습니다.

1. 설정을 엽니다​

어느 화면에서나 Windows는 Ctrl+,, macOS는 Command+,를 누릅니다.

이렇게 보이면 된 것 설정 창이 열리고 왼쪽에 일반, 모양, 모델, 권한, 계정, 키보드 단축키, 정보 탭이 보입니다.

2. 탭별 항목을 봅니다​

탭항목더 보기
일반새 세션의 권한 모드, 다음 메시지 제안, 브라우저 알림, 야간 큐 실행 시간대일반 탭
모양라이트⁠·⁠다크, 색 테마, 가벼운 화면, 코드 글꼴, 글자 크기, 기본 대화 기록 보기 방식화면 모양
모델모델마다 정하는 샘플링 값컨텍스트⁠·⁠모델⁠·⁠사용 현황
권한권한 규칙, 샌드박스, 관리 정책으로 가는 길권한 탭
계정게이트웨이 로그인 상태, 다시 로그인, 로그아웃계정과 로그인
키보드 단축키웹 화면의 단축키 목록단축키와 명령
정보버전 번호, 세션 서버, 기능 목록, 모델 정보, 설치 점검버전과 설치 점검

관리자 정책으로 정해진 값은 보기만 할 수 있습니다.

3. 일반 탭에서 새 세션과 알림을 정합니다​

항목정하는 것
새 세션의 권한 모드새 대화가 시작할 때의 권한 모드입니다. 대화 안에서는 Shift+Tab으로 바꿉니다. 모드별 차이는 권한 모드에 있습니다.
다음 메시지 제안답이 끝나면 입력창에 다음 메시지를 제안하고, Tab으로 채웁니다. 켜 두면 턴마다 모델 요청이 하나 더 나갑니다.
브라우저 알림답이 끝나거나 입력이 필요할 때 알립니다. 오래 걸리는 작업에 씁니다.
야간 큐 › 실행 시간대큐에 넣은 요청을 이 시간 안에, 서버가 한가할 때 하나씩 실행합니다. 처음 값은 22:00~07:00이고, 자정을 넘기는 시간대로 둘 수 있습니다. 쓰는 법은 야간 큐에 있습니다.

4. 화면 모양과 글자 크기를 맞춥니다​

모양 탭에서 바꿉니다.
항목이 길어서 아래로 스크롤해야 코드와 대화 항목이 보입니다.

하려는 일고르는 항목
어두운 화면으로 쓰기라이트⁠·⁠다크에서 다크를 누릅니다. 시스템을 고르면 PC 설정을 따릅니다.
화면 색 바꾸기색 테마에서 하나를 고릅니다. 기본은 Fortress이고, 테마는 모두 17가지입니다.
느린 PC나 가상 데스크톱에서 가볍게 쓰기가벼운 화면을 켜면 애니메이션, 흐림 효과, WebGL을 끕니다.
코드 글꼴 바꾸기코드 › 코드 글꼴에 고정폭 글꼴 이름을 넣습니다. 비우면 시스템 글꼴을 씁니다. 그 아래 코드 모양에서 바뀐 모습을 미리 봅니다.
답과 메시지의 글자 키우기대화 › 글자 크기에서 작게, 보통, 크게 가운데 고릅니다.
대화를 열 때 보이는 양 정하기대화 › 기본 대화 기록 보기 방식에서 일반, 사고 과정, 자세히 가운데 고릅니다. 일반은 도구 단계를 접고, 자세히는 전부 펼칩니다. 대화마다 바꿀 수도 있습니다.

색 테마는 라이트⁠·⁠다크마다 그 변형을 씁니다.
다크만 있는 테마는 라이트에서 기본 색으로 보입니다.

이렇게 보이면 된 것 고른 모양이 웹 화면 전체에 적용됩니다.

5. 권한 탭에서 규칙과 관리 정책을 찾아갑니다​

권한 탭은 규칙과 정책이 있는 곳으로 가는 길입니다.
새 세션의 권한 모드는 일반 탭에 있습니다.

항목화면의 설명더 보기
권한 규칙도구 호출마다 허용⁠·⁠질문⁠·⁠거부를 정하는 규칙입니다. 규칙 열기를 눌러 편집합니다.권한 규칙
샌드박스대화를 연 뒤 그 대화에 대해 켜고 끕니다.샌드박스
관리 정책관리자가 배포한 정책은 다른 규칙보다 늘 우선합니다. 보안⁠·⁠감사를 누르면 적용 중인 정책과 감사 로그를 봅니다.관리자 정책

6. 로그인 상태를 확인합니다​

계정 탭의 gateway 로그인 줄에서 (사내 인증⁠·⁠배포 서버) 로그인 상태를 봅니다.
같은 줄의 다시 로그인, 로그아웃 버튼을 씁니다.
터미널에서는 아래 명령을 씁니다.

터미널
fortress login <게이트웨이 주소>   # 로그인
fortress logout                   # 이 PC의 로그인 키 지우기

세션 안에서는 /login, /logout을 씁니다.
처음 로그인하는 단계는 설치와 첫 요청에 있습니다.

7. 버전 번호와 설치 상태를 확인합니다​

정보 탭에서 확인합니다.
아래로 스크롤하면 모델 정보와 설치 점검이 나옵니다.

항목보이는 것
Fortress지금 쓰는 버전 번호 (예: 2.6.1)
세션 서버이 PC에서 실행되는 웹 화면 서버 주소 (http://127.0.0.1:포트)
기능선택 기능마다 이름과 켜짐 또는 꺼짐
모델모델 이름, 컨텍스트 크기, 입력 종류, 생각 수준, 권장 샘플링, 모델 서버, 상태
설치 점검런타임, 로그인, 모델 서버, 정책 파일, 샌드박스, 도구를 점검하는 점검 버튼

이렇게 보이면 된 것 Fortress 아래에 버전 번호가 보이고, 맨 아래에 설치 점검과 점검 버튼이 보입니다.

점검 버튼은 터미널의 fortress doctor와 같은 결과를 냅니다.
점검 결과를 읽는 법은 설치와 점검에 있습니다.

선택 기능은 기본으로 모두 켜져 있습니다.
기능을 끄려면 정책 파일(policy.json)의 features.disable에 기능 이름을 넣습니다.
넣을 이름은 정보 탭의 기능 목록에 한글 이름과 함께 보입니다.

관리자가 정책으로 끈 기능은 메뉴와 칸이 화면에서 빠지고, 사용자가 다시 켤 수 없습니다.
이 문서에 나온 메뉴가 화면에 없으면 기능 목록부터 봅니다.

화면 안 도움말​

망 안에서도 볼 수 있는 짧은 한국어 안내가 웹 화면 안에 들어 있습니다.
계정 메뉴의 도움말에서 엽니다.

처음 쓸 때는 새 세션 화면의 입력창 아래에 "처음이라면 도움말"이 보이고, ×를 누르면 다시 나오지 않습니다.
다루는 내용은 아래와 같습니다.

  • 시작하기, 권한 모드, 샌드박스, 파일과 문서, 자주 쓰는 명령
  • 느릴 때, 붐빌 때와 야간 큐, 예약 작업, 프로젝트, 모델 고르기
  • 보안 검토, 문제 해결, 기록과 감사

막히면

  • "다시 로그인하세요"라고 나옵니다확인할 것 보기
자세히: 터미널 화면의 설정

터미널 화면에서는 /config로 설정을 엽니다.
/config features처럼 탭 이름을 붙이면 그 탭이 열립니다.

탭항목
Status폴더와 신뢰, 모델, 컨텍스트, 생각 수준, 모드, 샌드박스, 모델 서버, 로그인, 기능
Config이 세션 모드, 새 세션 기본 모드, 폴더 신뢰, 모델, 생각 수준, 모델별 샘플링
Features기능 켜고 끄기
Permissions종류별 규칙, 추가⁠·⁠삭제, 최근 판단, 관리자 정책
Account로그인, 로그아웃
Doctor설치 점검

웹 화면과 터미널 화면은 같은 파일을 씁니다.
정책, 폴더 신뢰, 샘플링, 로그인을 한쪽에서 바꾸면 다른 쪽에도 적용됩니다.

다음에 볼 글

컨텍스트, 모델, 사용 현황에이전트가 한 번에 참고하는 양을 보고 컨텍스트를 압축하는 법, 모델과 노력 수준을 고르는 곳, 모델 서버 상태와 답 하나·기간별 사용량을 보는 법입니다.권한 모드에이전트가 실행 전에 어디까지 묻는지 정하는 권한 모드와 기본 동작을 설명합니다.설치하고 첫 요청 보내기내 PC에 Fortress AI를 설치하고, 브라우저에서 로그인을 승인하고, 설치를 점검한 뒤 웹 화면에서 첫 요청을 보내는 순서입니다. 업데이트와 제거도 이 페이지에 있습니다.
