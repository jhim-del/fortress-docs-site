체험 첫날

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 체험 첫날, 설치가 끝난 PC에서 무엇부터 해 볼지 정할 때
  • 첫날 교육을 마친 뒤 혼자 다시 따라 해 볼 때
  • 함께 체험하는 동료에게 순서를 알려 줄 때

첫날 교육에서는 아래 다섯 단계를 함께 해 봅니다.
교육이 끝난 뒤에는 이 페이지를 보며 혼자 다시 따라 합니다.

설치와 로그인은 설치하고 첫 요청 보내기로 마친 상태에서 시작합니다.
계정은 관리자에게 받습니다(도입 첫날).

순서할 일이렇게 보이면 된 것
1설치 확인fortress doctor 끝에 "모두 정상입니다."가 나옵니다.
2웹 화면 열기왼쪽에 새로 생성, 프로젝트 같은 메뉴가 보입니다.
3첫 요청파일 이름과 크기가 표로 나옵니다.
4업무 하나 끝까지 해 보기결과 파일을 열어 숫자를 원본과 맞춰 봅니다.
5막혔을 때 볼 곳 알기문제 해결 페이지와 화면 안 도움말의 위치를 압니다.

1. 설치를 확인합니다​

(글자로 명령을 입력하는 창)을 열고 아래 명령을 실행합니다.
Windows는 PowerShell을 씁니다.

fortress doctor

첫 줄에 지금 쓰는 버전 번호가 나오고, 그 아래에 로그인, 모델 서버, 모델 응답, 게이트웨이, 권한 규칙, 샌드박스를 차례로 점검한 결과가 나옵니다.
문제가 있는 줄은 늘 보이고, 무엇을 고칠지 함께 알려 줍니다.

이렇게 보이면 된 것 첫 줄에 Fortress AI 2.6.1처럼 버전 번호가 나오고, 끝에 "모두 정상입니다."가 나옵니다.

참고

Windows PC에서는 샌드박스 줄에 "샌드박스 꺼짐 (Windows 기본값, 정책으로 켬)"이 나옵니다.
이때 허용 규칙에 없는 명령은 실행 전에 묻습니다.
영상의 PC는 관리자가 샌드박스를 켜 두어 "켜짐"으로 나옵니다.

켜는 순서는 관리자용 Windows 샌드박스 켜기에 있습니다.

2. 웹 화면을 엽니다​

fortress web

브라우저에 Fortress AI 웹 화면이 열립니다.
처음이면 입력창 아래의 처음이라면 도움말을 눌러 화면 안의 짧은 안내를 봅니다.

이렇게 보이면 된 것 왼쪽 사이드바에 새로 생성, 프로젝트, 예약됨, 사용자 지정, 보안⁠·⁠감사, 사용 현황이 보입니다.

쓰는 버전은 설정(Ctrl+,)의 정보 탭에서 봅니다.
2.6.1부터는 왼쪽 위 로고 옆에 버전 번호가 나오지 않습니다.
정보 탭 맨 아래의 점검 버튼은 fortress doctor와 같은 점검을 합니다.

화면의 메뉴는 화면 지도에서 번호별로 봅니다.

3. 첫 요청을 보냅니다​

  1. 새로 생성을 누르면 "어디서 작업할까요?"가 열립니다.
  2. 연습할 (맡길 파일을 넣어 둔 폴더)를 고릅니다.
    목록에 없으면 폴더 선택… › 폴더 찾아보기…(Ctrl+Alt+1)를 누르고, Windows 폴더 선택 창에서 폴더를 고른 뒤 Select Folder를 누릅니다.
    연습할 때는 원본 대신 사본 폴더를 씁니다.
  3. 아래 요청문을 입력창에 붙여 넣고 Enter로 보냅니다.

처음 여는 폴더면 입력창 아래에 신뢰 미정이 보이고, 첫 메시지를 보낼 때 이 폴더를 신뢰할지 묻습니다.
내가 만든 폴더인지 확인하고 고릅니다.
차이는 폴더 신뢰에 있습니다.

이렇게 보이면 된 것 대화창에 파일 이름과 크기가 표로 나옵니다.

이렇게 시작한 대화 하나를 (한 가지 일을 맡기고 주고받는 대화 하나)이라고 부릅니다.
세션은 사이드바 아래쪽 목록에 작업 폴더별로 남고, 나중에 다시 엽니다.

4. 업무 하나를 끝까지 해 봅니다​

업무마다 요청문, 단계, 결과를 확인하는 법이 한 페이지에 있습니다.
사무 업무를 맡는 분은 월간 업무보고부터 해 봅니다.
하나를 끝까지 해 본 뒤 다음으로 넘어갑니다.

월간 업무보고 초안 받기지난달 업무보고와 이번 달 실적 엑셀을 넣고, 같은 양식의 이번 달 초안을 한글 파일로 받습니다.회의록 정리하기회의 전사 발췌본을 넣고, 결정 사항과 후속 업무 표, 보류 안건을 받습니다.결함을 고치고 장애 처리 보고서 쓰기개발·운영 담당이라면 오류를 고치고 테스트를 더한 뒤, 장애 처리 보고서 초안을 받습니다.
예시 자료 내려받기34KB월간 업무보고 페이지의 요청문을 그대로 보내 볼 수 있는 실무 분량의 예시 자료입니다. 쓰는 법

결과는 초안입니다.
결과 파일을 열어 숫자와 근거로 적힌 내용을 원본과 직접 맞춰 봅니다.
업무 페이지마다 끝에 있는 확인할 점 표가 어디를 볼지 알려 줍니다.

이렇게 보이면 된 것 결과 파일이 열리고, 표의 숫자가 원본 자료와 같습니다.

요령

에이전트가 무엇을 읽고 무엇을 실행했는지는 (한 일을 시간 순서로 보여 주는 화면)에서 차례로 봅니다.
마음에 들지 않는 변경은 (이전 시점으로 되돌리기)로 되돌립니다.
명령으로 바뀐 파일은 되돌려지지 않습니다.

자세한 내용은 결과 확인하고 되돌리기에 있습니다.

더 많은 요청문은 요청문 모음에 있습니다.

5. 막혔을 때 볼 곳​

어디서무엇을
웹 화면 안입력창 아래 처음이라면 도움말, 계정 메뉴의 도움말
이 문서문제 해결, 자주 묻는 질문
담당자 문의fortress doctor --verbose 결과를 붙입니다. 비밀번호 같은 비밀값은 뺍니다.

막히면

  • 작업이 멈춰 있습니다확인할 것 보기
  • 답은 있는데 결과 파일이 없습니다확인할 것 보기
  • "다시 로그인하세요"라고 나옵니다확인할 것 보기

첫날이 끝나면 확인할 것​

  • fortress doctor 끝에 "모두 정상입니다."가 나옵니다.
  • 설정 › 정보에서 내 버전을 확인했습니다.
  • 웹 화면에서 첫 요청의 답을 받았습니다.
  • 업무 하나를 끝까지 해 보고 결과 파일을 원본과 맞춰 봤습니다.
  • 타임라인과 되감기가 어디 있는지 압니다.
  • 막혔을 때 볼 곳(문제 해결 페이지, 화면 안 도움말)을 압니다.

다음에 볼 글

업무별로 해 보기월간 업무보고, 과업내용서, 보고서 검수, 회의록, 계약서 점검, 인수인계, 규정 질의 같은 사무 업무와 개발·운영 업무를 받는 결과물로 골라 따라 합니다.요청 보내고 이어 가기작업 폴더를 고르고, 요청과 명령을 보내고, 파일을 전달하고 열어 보고, 답을 읽고, 지난 세션을 찾아 이어 가는 방법입니다.문제 해결설치, 로그인, 파일, 승인, 속도, 샌드박스, 예약에서 자주 생기는 증상과 먼저 확인할 것을 정리합니다.
