화면 지도

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 교육에서 들은 메뉴가 화면 어디에 있는지 찾을 때
  • 입력창 아래의 작은 표시가 무슨 뜻인지 알고 싶을 때
  • 문서에 나온 화면 이름이 내 화면의 어느 부분인지 맞춰 볼 때

사이드바 메뉴​

사이드바의 메뉴를 차례로 누르면 각 화면이 가운데에 열립니다.

메뉴여는 화면설명한 페이지
검색지난 대화와 폴더 찾기요청 보내고 이어 가기
새로 생성작업 폴더를 고르고 새 대화 시작설치와 첫 요청
프로젝트프로젝트 목록프로젝트로 묶기
예약됨모든 예약 작업예약과 반복 실행
사용자 지정스킬, 커넥터, 에이전트, 명령, 메모리, 권한 탭내 방식으로 맞추기
보안⁠·⁠감사망분리⁠·⁠샌드박스⁠·⁠정책 상태와 감사 로그서버로 가는 데이터, 감사 로그
사용 현황기간별 요청 수, 모델이 일한 시간, 토큰컨텍스트⁠·⁠모델⁠·⁠사용 현황

사이드바 위쪽에는 메뉴가, 아래쪽에는 대화 목록이 있습니다.
자주 여는 항목은 고정됨에 모입니다.
대화 줄의 ··· 메뉴에서 이름 바꾸기, 고정, 보관, 삭제를 합니다.

새 대화 화면​

새로 생성을 누르면 가운데에 "어디서 작업할까요?"가 열립니다.

  • 최근에 쓴 폴더가 목록으로 보입니다. 하나를 누르면 그 폴더에서 일합니다.
  • 폴더 선택…을 누르면 폴더 검색…과 폴더 찾아보기…가 나옵니다.
    폴더 검색은 이미 쓴 폴더를 이름으로 찾고, 폴더 찾아보기(Ctrl+Alt+1)는 Windows 폴더 선택 창을 띄웁니다.
  • 그 아래 기본 환경은 추가 폴더와 환경 변수를 묶어 둔 환경을 고르는 곳입니다. 기본은 없음입니다.
  • 처음 여는 폴더를 고르면 입력창 아래에 신뢰 미정이 보입니다. 폴더 신뢰에서 설명합니다.

대화 화면​

요청을 보내면 대화 화면으로 바뀝니다.

(한 일을 시간 순서로 보여 주는 화면)과 오른쪽 칸은 결과 확인하고 되돌리기에서, (에이전트가 답할 때 한 번에 참고하는 내용)는 컨텍스트⁠·⁠모델⁠·⁠사용 현황에서 설명합니다.

입력창 아래​

입력창 아래 줄에는 이 대화가 어떻게 도는지가 짧게 표시됩니다.

표시설명한 페이지
권한 모드권한 모드
샌드박스 상태샌드박스
모델 서버 상태, 모델컨텍스트⁠·⁠모델⁠·⁠사용 현황

설정과 도움말​

설정은 어느 화면에서나 Ctrl+,로 엽니다.
탭은 일반, 모양, 모델, 권한, 계정, 키보드 단축키, 정보입니다.
버전 번호와 설치 점검 버튼은 정보 탭에 있습니다.

탭별 항목은 설정과 화면 맞추기에 있습니다.

화면 안의 짧은 한국어 안내는 계정 메뉴의 도움말에서 엽니다.
처음 쓸 때는 입력창 아래에 처음이라면 도움말도 보입니다.

다음에 볼 글

요청 보내고 이어 가기작업 폴더를 고르고, 요청과 명령을 보내고, 파일을 전달하고 열어 보고, 답을 읽고, 지난 세션을 찾아 이어 가는 방법입니다.설정과 화면 맞추기웹 화면의 설정을 여는 법과 일곱 탭의 구성, 새 세션의 권한 모드·알림·야간 큐 시간·화면 모양·로그인·버전 번호를 보고 바꾸는 곳입니다.업무별로 해 보기월간 업무보고, 과업내용서, 보고서 검수, 회의록, 계약서 점검, 인수인계, 규정 질의 같은 사무 업무와 개발·운영 업무를 받는 결과물로 골라 따라 합니다.
