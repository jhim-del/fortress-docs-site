도입부터 사용까지 한눈에

Fortress AI 2.6.1 · 게이트웨이 3.3.0 기준

이럴 때 봅니다

  • Fortress AI를 도입하면 누가 무엇을 어떤 순서로 하는지 먼저 보고 싶을 때
  • 내 역할에서 어느 페이지부터 볼지 고를 때
  • 보안 설정과 정책 관리가 흐름의 어디에 들어가는지 알고 싶을 때

  1. 1도입 준비
    고객사 관리자

    어디서 회사 안

    • 관리 담당자를 두 명 이상 정합니다.
    • 임직원 PC에 설치할지, 공용 개발 서버에 한 번 설치할지 정합니다.
    • 임직원 PC에서 장비의 8080 포트에 접속할 수 있도록 사내 망을 준비합니다.

    도입 첫 주 점검표설치 방식과 점검

  2. 2장비 설치
    설치 담당자

    어디서 장비

    • 장비에 게이트웨이를 설치합니다.
    • 첫 관리자 admin의 비밀번호를 정해 관리자에게 전달합니다.
    • 홈 화면 주소 <장비 주소>:8080을 알려 줍니다.

    장비 설치와 첫 관리자 계정

  3. 3관리자 첫날
    고객사 관리자

    어디서 관리 화면

    • 관리 화면에 로그인해 비밀번호를 바꿉니다.
    • 두 번째 관리자를 만듭니다.
    • 임직원 계정을 만들어 전할 안내를 보내고, 처음 비밀번호는 따로 전합니다.

    도입 첫날관리자와 사용자

  4. 4임직원 설치·로그인
    임직원

    어디서 홈 화면, 내 PC

    • 홈 화면에서 설치 명령을 복사해 터미널에서 실행합니다.
    • 브라우저의 기기 로그인 화면에서 받은 계정으로 승인합니다.
    • fortress doctor로 점검하고 첫 요청을 보냅니다.

    설치하고 첫 요청체험 첫날

  5. 5업무 활용
    임직원

    어디서 웹 화면, 터미널

    • 작업 폴더를 고르고 평소 말로 일을 맡깁니다.
    • 결과를 원본과 맞춰 보고, 마음에 들지 않으면 되감습니다.
    • 반복 업무는 정한 시각에 실행되도록 예약합니다.

    업무별로 해 보기예시 자료 내려받기요청 보내기확인하고 되돌리기

  6. 6보안·정책
    고객사 관리자임직원

    어디서 내 PC, 웹 화면의 보안·감사

    • 임직원은 폴더 신뢰와 권한 모드로 실행 전에 묻는 범위를 정합니다.
    • 관리자는 권한 규칙과 샌드박스 설정을 PC 정책 파일로 배포합니다.
    • 관리 화면에서 정책을 배포하는 방법은 게이트웨이 3.4.0 이상에서 씁니다.

    한 장으로 보는 보안관리자 정책Windows 샌드박스

  7. 7운영·점검
    고객사 관리자

    어디서 관리 화면, 각 PC의 보안·감사

    • 관리 화면에서 사용량, 호출 기록, 감사 기록(계정·로그인)을 봅니다.
    • 비밀번호를 잊은 임직원은 비밀번호를 다시 정하고, 퇴사자 계정은 사용 중지하고, 복귀한 사용자는 사용 중지를 해제합니다.
    • 에이전트의 허용·거부를 남긴 감사 로그는 각 PC의 보안·감사에서 봅니다.

    관리 화면 둘러보기감사 로그

  8. 8업데이트
    설치 담당자임직원

    어디서 장비, 내 PC

    • 설치 담당자가 장비의 클라이언트를 새 버전으로 바꿉니다.
    • 임직원 PC의 클라이언트가 새 버전이 있다고 알립니다.
    • 임직원이 fortress update로 새 버전을 받습니다.

    업데이트릴리스 노트

다음에 볼 글

도입 첫날: 계정 발급과 전달장비 설치 뒤 고객사 관리자가 관리 화면에 로그인해 비밀번호를 바꾸고, 임직원 계정을 발급해 전할 안내와 처음 비밀번호를 전달하고, 임직원이 로그인했는지 확인하는 순서입니다.설치하고 첫 요청 보내기내 PC에 Fortress AI를 설치하고, 브라우저에서 로그인을 승인하고, 설치를 점검한 뒤 웹 화면에서 첫 요청을 보내는 순서입니다. 업데이트와 제거도 이 페이지에 있습니다.한 장으로 보는 보안Fortress AI의 보호를 경계와 안전망으로 나눠, 무엇을 막고 묻고 기록하는지 한 장으로 정리합니다.
