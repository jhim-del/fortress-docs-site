설치하고 첫 요청 보내기

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 내 PC에 Fortress AI를 처음 설치할 때
  • "다시 로그인하세요"가 떠서 로그인을 다시 해야 할 때
  • 새 버전으로 바꾸거나 프로그램을 지울 때

설치는 여섯 단계이고, 관리자 권한은 필요하지 않습니다.
막히면 페이지 아래의 안 될 때와 문제 해결을 봅니다.

순서할 일이렇게 보이면 된 것
1설치 명령 복사운영체제에 맞는 명령 한 줄이 복사됩니다.
2터미널에서 실행설치가 끝나고 브라우저가 열립니다.
3브라우저에서 로그인 승인승인이 끝났다는 화면이 나옵니다.
4설치 점검fortress doctor 끝에 "모두 정상입니다."가 나옵니다.
5웹 화면 열기왼쪽에 새로 생성, 프로젝트 같은 메뉴가 보입니다.
6첫 요청파일 이름과 크기가 표로 나옵니다.

준비할 것​

  • 게이트웨이 주소. 관리자가 안내한 주소입니다.
  • 발급받은 아이디와 비밀번호. 브라우저에서 로그인을 승인할 때 씁니다.
    계정은 회사의 Fortress AI 관리자에게 받습니다. 관리자가 계정을 만드는 순서는 도입 첫날에 있습니다.
  • 사내 망에 연결된 PC. Windows, macOS, Linux를 지원합니다.

1. 설치 명령을 복사합니다​

브라우저로 게이트웨이 홈페이지를 엽니다.
Fortress AI 클라이언트 설치 카드에서 내 운영체제를 고르고 설치 명령을 복사합니다.

이렇게 보이면 된 것 명령 한 줄이 복사됩니다. Windows용은 irm, macOS⁠·⁠Linux용은 curl로 시작합니다.

2. 터미널에서 명령을 실행합니다​

(글자로 명령을 입력하는 창)을 열고 복사한 명령을 붙여 넣어 실행합니다.
Windows는 PowerShell, macOS⁠·⁠Linux는 터미널 앱을 씁니다.
카드에서 복사한 명령에는 게이트웨이 주소가 이미 들어 있습니다.

Windows · PowerShell
irm <게이트웨이 주소>/install/ax-fortress.ps1 | iex
macOS · Linux · 터미널
curl -fsSL <게이트웨이 주소>/install/ax-fortress.sh | sh

설치 스크립트는 운영체제에 맞는 설치 패키지를 받고, SHA-256 값(받은 파일이 바뀌지 않았는지 확인하는 값)이 맞는지 본 뒤 사용자 폴더에 설치합니다.

이렇게 보이면 된 것 설치가 끝나고 브라우저에 로그인 승인 화면이 열립니다.

3. 브라우저에서 로그인을 승인합니다​

  1. 브라우저 화면의 코드가 터미널에 표시된 코드와 같은지 확인합니다.
  2. 발급받은 아이디와 비밀번호를 넣고 승인을 누릅니다.
  3. 승인이 끝났다는 화면이 나오면 브라우저를 닫고 터미널로 돌아갑니다.

이렇게 보이면 된 것 브라우저에 승인이 끝났다는 화면이 나옵니다.

요령

로그인 창을 닫았거나 승인하지 못했어도 설치는 끝난 상태입니다.
아래 명령으로 로그인만 다시 합니다.

fortress login <게이트웨이 주소>

4. 설치를 점검합니다​

터미널에서 아래 명령을 실행합니다.

fortress doctor

첫 줄에 설치한 버전 번호가 나오고, 로그인, 모델 서버, 모델 응답, 게이트웨이, 권한 규칙, 샌드박스를 차례로 점검합니다.
모델 응답은 짧은 요청을 실제로 보내 확인합니다.
문제가 있는 줄은 늘 보이고, 무엇을 고칠지 함께 알려 줍니다.

웹 화면을 연 뒤에는 설정 › 정보 탭 맨 아래의 점검 버튼으로도 같은 점검을 합니다.

이렇게 보이면 된 것 첫 줄에 Fortress AI 2.6.1처럼 버전 번호가 나오고, 끝에 "모두 정상입니다."가 나옵니다.

참고

Windows PC에서는 샌드박스 줄에 "샌드박스 꺼짐 (Windows 기본값, 정책으로 켬)"이 나옵니다.
영상의 PC는 관리자가 샌드박스를 켜 두어 "켜짐"으로 나옵니다.

관리자는 배포 전에 Windows 샌드박스 켜기의 순서로 켭니다.

5. 웹 화면을 엽니다​

fortress web

브라우저에 Fortress AI 웹 화면이 열립니다.
이미 실행 중이면 그 화면을 엽니다.
처음 열 폴더를 정하려면 fortress web --cwd <폴더>로 실행합니다.

이렇게 보이면 된 것 왼쪽 사이드바에 새로 생성, 프로젝트, 예약됨, 사용자 지정, 보안⁠·⁠감사, 사용 현황이 보입니다.

쓰는 버전은 설정(Ctrl+,)의 정보 탭에서 봅니다.
2.6.1부터는 왼쪽 위 로고 옆에 버전 번호가 나오지 않습니다.
정보 탭을 끝까지 내리면 설치 점검의 점검 버튼이 있습니다.

설정의 다른 탭은 설정과 화면 맞추기에 있습니다.
화면의 메뉴는 화면 지도에서 번호별로 봅니다.

6. 첫 요청을 보냅니다​

  1. 새로 생성을 누르면 "어디서 작업할까요?"가 열립니다.
  2. (맡길 파일을 넣어 둔 폴더)를 고릅니다.
    목록에 없는 폴더는 폴더 선택… › 폴더 찾아보기…(Ctrl+Alt+1)를 누릅니다.
    Windows 폴더 선택 창에서 폴더를 고르고 Select Folder를 누릅니다.
  3. 아래 요청문을 입력창에 붙여 넣고 Enter로 보냅니다.

같은 메뉴의 폴더 검색…은 이미 한 번 쓴 폴더를 이름으로 찾습니다.
폴더 선택 창을 띄울 수 없는 곳(ssh로 붙은 서버 등)에서는 웹 화면 안의 폴더 창이 대신 뜹니다.

처음 여는 폴더면 입력창 아래에 신뢰 미정이 보이고, 첫 메시지를 보낼 때 이 폴더를 신뢰할지 묻습니다.
(폴더마다 한 번 정하는 설정)에 따라 실행 전에 묻는 횟수가 달라집니다.
내가 만든 폴더인지 확인하고 고릅니다.

이렇게 보이면 된 것 대화창에 파일 이름과 크기가 표로 나옵니다.

이어서 해 볼 순서는 체험 첫날에 있습니다.

  • 작업이 멈춰 있습니다확인할 것 보기

설치 명령이나 fortress 명령에서 막히면 아래 안 될 때를 먼저 봅니다.

터미널에서 쓰기​

터미널에서 작업할 폴더로 이동해 fortress를 실행하면, 그 폴더에서 대화하는 터미널 화면이 열립니다.
처음 여는 폴더면 폴더를 신뢰할지 먼저 묻습니다.
터미널 화면의 글은 영어입니다.

터미널
cd <작업 폴더>
fortress

요청을 한 번만 보내고 답을 받으려면 fortress -p "요청"을 씁니다.

터미널
fortress -p "이 폴더에 있는 파일 이름과 크기만 표로 보여줘."

-p로 실행할 때는 물어볼 사람이 없습니다.
신뢰를 정하지 않은 폴더에서는 묻는 동작이 거부되므로, 먼저 fortress나 웹 화면에서 폴더 신뢰를 정합니다.

대화, 승인, 되감기, 설정, 변경 사항, 보안 감사 화면은 터미널에서도 씁니다.
프로젝트, 타임라인, 파일⁠·⁠미리보기⁠·⁠터미널 칸은 웹 화면에만 있습니다.
공용 개발 서버에 ssh로 접속해 쓰는 경우에는 터미널 화면이 기본입니다.

업데이트​

Fortress AI는 로그인한 게이트웨이에 하루 한 번 새 버전이 있는지 묻습니다.
새 버전이 있으면 터미널 화면을 열 때 한 줄로 알려 줍니다.
웹 화면에서는 알림과 설정 › 정보에, fortress doctor에서는 "업데이트" 줄에 나옵니다.

업데이트 실행은 사용자가 직접 합니다.
웹 화면만 쓰더라도 아래 명령은 터미널에서 실행합니다.

  1. 지금 버전을 확인합니다. 웹 화면에서는 설정 › 정보 탭에서도 봅니다.

    fortress --version

  2. 새 버전을 받습니다. 로그인한 게이트웨이에서 이 PC용 새 버전을 받고, 게이트웨이가 알린 SHA-256 값과 맞을 때만 설치합니다.

    fortress update

  3. Windows에서는 터미널을 닫고 새로 엽니다. 열려 있던 터미널은 이전 버전을 씁니다.

  4. fortress --version으로 버전 번호를 보고, fortress doctor로 다시 점검합니다.

이렇게 보이면 된 것 fortress --version에 새 버전 번호가 나옵니다.

다른 게이트웨이에서 받으려면 fortress update <게이트웨이 주소>로 실행합니다.

제거​

설치할 때와 같은 게이트웨이의 제거 명령을 실행합니다.

Windows · PowerShell
irm <게이트웨이 주소>/install/ax-fortress-uninstall.ps1 | iex
macOS · Linux · 터미널
curl -fsSL <게이트웨이 주소>/install/ax-fortress-uninstall.sh | sh

제거해도 설정과 대화 기록(~/.fortress 폴더)은 남습니다.

안 될 때​

"fortress"라는 명령을 찾을 수 없다고 나옵니다

터미널을 닫고 새로 엽니다.
설치가 실행 파일 위치를 사용자 PATH(명령을 찾는 경로)에 더하므로, 설치 전에 열어 둔 터미널은 새 위치를 모릅니다.

새로 열어도 같으면 사용자 PATH에 설치 폴더가 들어 있는지 봅니다.
Windows는 %LOCALAPPDATA%\Programs\fortress\<버전> 폴더입니다.
macOS⁠·⁠Linux는 ~/.local/bin 폴더입니다.

없으면 이 폴더를 사용자 PATH에 더하고 터미널을 새로 엽니다.

"다시 로그인하세요"라고 나옵니다

30일 동안 쓰지 않았거나, 로그인한 지 90일이 지났거나, 관리자가 로그인을 끝낸 경우입니다.
fortress login <게이트웨이 주소>로 다시 로그인합니다.

브라우저를 열 수 없는 곳에서 설치했습니다

원격 접속이나 컨테이너처럼 브라우저가 없는 곳에서는 아래 명령으로 로그인합니다.
터미널에서 아이디와 비밀번호를 입력합니다.
비밀번호는 화면에 보이지 않고 저장되지 않습니다.

fortress login --headless <게이트웨이 주소>
서버에 연결되지 않습니다

fortress doctor의 로그인, 모델 서버, 게이트웨이 줄을 봅니다.
브라우저로 게이트웨이 홈페이지가 열리는지, PC가 사내 망에 연결돼 있는지 확인합니다.

담당자에게 문의하려고 합니다

아래 명령의 결과를 문의 글에 붙입니다.
버전, 실행 환경, 도구까지 모두 나옵니다.
비밀번호 같은 비밀값은 빼고 보냅니다.

fortress doctor --verbose
자세히: 설치 위치와 버전 폴더
macOS ⁠·⁠ LinuxWindows
설치 위치~/.local/share/fortress/<버전>/%LOCALAPPDATA%\Programs\fortress\<버전>\
실행 파일~/.local/bin/fortress사용자 PATH에 추가됩니다.

새 버전은 지금 버전 옆 폴더에 설치되고, fortress 명령이 새 버전을 가리킵니다.
이전 버전의 폴더는 남습니다.
관리자용 설치 방식은 설치 방식과 점검에 있습니다.

다음에 볼 글

체험 첫날설치가 끝난 PC에서 설치 확인, 웹 화면 열기, 첫 요청, 월간 업무보고 같은 업무 하나까지 체험 첫날 순서대로 해 봅니다. 교육 뒤에도 이 페이지를 보며 다시 따라 합니다.화면 지도Fortress AI 웹 화면의 첫 화면과 대화 화면을 번호로 표시하고, 사이드바 메뉴와 입력창 아래 표시마다 설명한 페이지로 연결합니다.업무별로 해 보기월간 업무보고, 과업내용서, 보고서 검수, 회의록, 계약서 점검, 인수인계, 규정 질의 같은 사무 업무와 개발·운영 업무를 받는 결과물로 골라 따라 합니다.
