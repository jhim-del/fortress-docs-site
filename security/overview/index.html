Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 에이전트에게 일을 맡겨도 되는지 보안 담당자에게 설명해야 할 때
  • 어느 장치가 무엇을 막는지 한 번에 보고 싶을 때
  • 샌드박스가 꺼진 PC에서 무엇이 남는지 알고 싶을 때

경계와 안전망​

Fortress AI의 보호는 지키는 정도에 따라 두 가지로 나뉩니다.

구분무엇이 지키나지키는 정도
경계파일을 실제로 여는 지점, 운영체제의 (명령을 격리하는 장치)명령을 어떤 형태로 쓰든 막습니다.
안전망실행 전에 명령 문자열을 읽고 판단하는 권한 확인흔한 실수를 잡지만 모든 형태를 막지는 않습니다.

경계에 드는 것은 아래와 같습니다.

  • 샌드박스 안에서 실행되는 명령의 쓰기 제한, 읽기 금지 목록, 외부 접속 제한
  • 파일 읽기⁠·⁠고치기 도구에서 거부 규칙에 맞는 경로, 로그인 파일, 정책 파일 수정

안전망에 드는 것은 명령 규칙(Bash(...)), 작업 폴더 밖 읽기 질문, 권한 무시 모드의 중요 폴더 삭제 질문 같은 판정입니다.

주의

샌드박스 밖에서 실행되는 명령에는 안전망만 남습니다.
Windows 기본 설정, 사용자가 샌드박스를 끈 경우, 샌드박스가 뜨지 못한 경우가 여기에 듭니다.
파일 읽기⁠·⁠고치기 도구의 보호는 샌드박스와 상관없이 그대로입니다.

Windows 샌드박스는 2.6.1에서도 기본으로 꺼져 있습니다.
켜는 순서는 Windows 샌드박스 켜기에 있습니다.

무엇을 막고, 묻고, 기록하나​

장치하는 일정하는 곳
① 권한 확인파일을 고치거나 명령을 실행하기 전에 허용, 물어봄, 거부를 정합니다. 작업 폴더 밖의 파일을 읽을 때도 묻습니다.권한 모드, 권한 규칙, 폴더 신뢰
② 샌드박스에이전트가 실행하는 명령을 운영체제 수준에서 격리합니다. 쓰기는 작업 폴더 안으로 좁히고, 허용 목록 밖 접속은 묻습니다.샌드박스
③ 관리자 정책조직 공통 규칙입니다. PC의 정책 파일로 둡니다. 게이트웨이 3.4.0 이상이면 (사내 접속 관문)에서도 받습니다.관리자 정책
④ 감사 로그도구를 쓸 때마다 허용했는지 거부했는지 각 PC에 남깁니다. CSV로 내보냅니다.감사 로그

기본 설정에서는 파일을 고치거나 명령을 실행하기 전에 묻습니다.

확인하는 법​

사이드바의 보안⁠·⁠감사를 열면 장치마다 지금 상태가 보입니다.
2.6.1 화면에서는 전송 대상이 "이 서버만"으로, 외부 버전 확인⁠·⁠원격 측정⁠·⁠자동 설치⁠·⁠세션 업로드가 "꺼짐"으로 표시됩니다.
무엇을 언제 보내는지는 서버로 가는 데이터에서 봅니다.

  • 샌드박스가 꺼져 있으면 웹 화면의 입력창 아래에 주황색 샌드박스 꺼짐이, 터미널 화면의 상태 줄에 sandbox: off가 보입니다.
  • 게이트웨이 3.4.0 이상에서 정책을 받은 PC는 이 화면에 정책의 출처와 받은 시각이 함께 나옵니다.

장치마다 맡지 않는 것​

  • 샌드박스의 읽기 제한은 ~/.ssh 같은 짧은 금지 목록입니다. 작업 폴더 밖 읽기는 권한 확인이 실행 전에 묻습니다.
  • (입력한 개인정보 가리기)은 입력창에 쓴 글에만 적용됩니다. 에이전트가 읽은 파일 안의 개인정보는 가리지 않습니다.
  • 감사 로그는 각 PC의 ~/.fortress/agent/audit/permissions.jsonl 파일에 남습니다. 중앙에서 모으는 기능은 없고, 사내에서 쓰는 수집 도구로 PC마다 이 파일을 모을 수 있습니다(감사 로그).
  • 게이트웨이 관리 화면에 남는 것은 모델 호출 기록과 감사 기록(계정⁠·⁠로그인 기록)입니다. PC의 감사 로그(권한 판단 기록)와는 다른 기록입니다.
주의

개인정보가 든 파일은 작업 폴더에 넣기 전에 그 값을 지우거나 가린 사본을 넣습니다.
원본을 그 폴더에 둬야 하면 권한 규칙으로 읽기를 막습니다.

다음에 볼 글

샌드박스샌드박스가 에이전트의 명령에서 무엇을 막고 무엇은 다른 장치에 맡기는지, 켜져 있는지 확인하는 법입니다.관리자 정책조직 공통 규칙을 PC의 정책 파일로 배포하는 방법, 게이트웨이 3.4.0 이상의 관리 정책 화면, 둘이 겹칠 때의 우선순위, 받았는지 확인하는 법입니다.도입 첫 주 점검표관리자가 Fortress AI를 도입한 첫 주에 설치 방식, 계정 발급, 정책 배포, 샌드박스, 설치 뒤 점검, 사용자 안내, 기록 확인을 차례로 점검하는 목록입니다.
