서버로 가는 데이터

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 보안 담당자에게 데이터가 어디로 가는지 화면으로 보여 줘야 할 때
  • 에이전트가 읽은 파일 내용이 어디까지 전달되는지 알고 싶을 때
  • 입력한 개인정보가 어떻게 처리되는지 확인할 때

보내는 곳​

보내는 곳은 사이드바의 보안⁠·⁠감사 › 망분리 칸에 표시됩니다.
2.6.1 화면의 값은 아래와 같습니다.

항목화면 표시
전송 대상이 서버만
외부 버전 확인꺼짐
원격 측정꺼짐
자동 설치꺼짐
세션 업로드꺼짐

받는 곳은 사내 망에 둔 (로그인과 연결을 맡는 사내 서버)와 (AI가 실제로 실행되는 사내 장비)입니다.
요청은 게이트웨이를 거쳐 모델 서버로 갑니다.

무엇을 언제 보내나​

받는 곳언제무엇을
모델 서버세션을 시작할 때작업 폴더 경로, 운영체제, git 상태, 지침 파일(FORTRESS.md, AGENTS.md), PC의 스킬 목록
모델 서버일하는 동안사용자가 쓴 요청, 에이전트가 실행한 도구의 결과(읽은 파일 내용, 명령 출력)
모델 서버다음 메시지 제안이 켜져 있으면 턴마다 한 번제안을 만들기 위한 대화 앞부분
모델 서버새 대화마다 한 번대화 제목을 만들기 위한 대화 앞부분
게이트웨이로그인과 로그인 유지로그인 승인과 토큰 갱신
게이트웨이하루 한 번새 버전이 있는지 묻기
게이트웨이대화를 시작할 때, 켜져 있으면 1시간마다관리 정책 받기(게이트웨이 3.4.0 이상에 정책이 있을 때)
게이트웨이모델을 부를 때마다요청과 함께 클라이언트 버전, 적용 중인 정책의 출처, 샌드박스 상태(켜짐⁠·⁠꺼짐⁠·⁠실패). 게이트웨이 3.4.0 이상은 이 값을 관리 정책 화면에 보여 줍니다.

에이전트가 파일을 읽으면 그 내용이 모델 서버로 갑니다.
읽게 할 범위는 작업 폴더와 권한 규칙으로 정합니다.
다음 메시지 제안은 설정의 일반 탭에서 끌 수 있습니다.

개인정보 가림​

(입력한 개인정보 가리기)은 사용자가 입력창에 쓴 글에서 아래 값을 찾아, 모델과 대화 기록에 가기 전에 "가림" 표시로 바꿉니다.
기본으로 켜져 있고, 관리자 정책으로 정할 수 있습니다.

  • 주민등록번호, 외국인등록번호
  • 휴대전화 번호, 카드 번호
  • API 키와 토큰, 개인 키, 비밀번호 같은 비밀 값
주의

가림은 사용자가 입력창에 쓴 글에만 적용됩니다.
에이전트가 읽은 파일 안의 개인정보는 가리지 않습니다.

개인정보가 든 파일은 작업 폴더에 넣기 전에 그 값을 지우거나 가린 사본을 넣습니다.
원본을 그 폴더에 둬야 하면 권한 규칙으로 읽기를 막습니다.

붙여 넣은 글에 화면에 보이지 않는 문자가 섞여 있으면 모델에 보내기 전에 지웁니다.
웹 화면에서는 지운 것이 있으면 보내지 않고, 정리된 글을 입력창에 남겨 다시 보게 합니다.
이 동작은 설정으로 끄지 않습니다.

감사 로그​

에이전트가 도구를 쓸 때마다 허용했는지 거부했는지가 PC의 (권한 판단 기록)로 남습니다.

  • 자동⁠·⁠규칙 허용, 사람이 허용, 거부로 골라 봅니다.
  • 모든 대화와 이 대화 가운데 범위를 고릅니다.
  • 검색창에 도구, 대상, 규칙 이름을 넣어 찾습니다.
  • CSV 내보내기는 지금 보이는 기록을 파일로 받습니다.

기록 한 줄에는 시각, 결과, 도구, 대상, 근거, 모드, 대화가 들어 있습니다.
폴더를 신뢰한 결정도 도구 이름 trust 줄로 남습니다.

감사 로그는 각 PC의 ~/.fortress/agent/audit/permissions.jsonl 파일에 남습니다.
중앙에서 모으는 기능은 없습니다.
모아서 보려면 사내에서 쓰는 수집 도구로 PC마다 이 파일을 모읍니다(감사 로그).

게이트웨이 관리 화면에 남는 것은 모델 호출 기록과 감사 기록(계정⁠·⁠로그인 기록)이며, PC의 감사 로그와는 다른 기록입니다.

확인하는 법​

확인할 것어디서
보내는 곳웹 화면 보안⁠·⁠감사 › 망분리 칸 (터미널은 /audit)
관리자 정책이 깔렸는지보안⁠·⁠감사 › 정책⁠·⁠기록 칸의 관리자 줄
입력 가림이 켜져 있는지보안⁠·⁠감사 › 정책⁠·⁠기록 칸의 입력 가림 줄
무엇을 허용하고 거부했는지보안⁠·⁠감사 아래쪽 감사 로그 표

다음에 볼 글

감사 로그에이전트가 도구를 쓸 때 허용·거부한 감사 로그가 어디에 어떤 내용으로 남는지, 화면에서 골라 보고 파일로 받는 방법, 관리 화면의 감사 기록과 다른 점입니다.한 장으로 보는 보안Fortress AI의 보호를 경계와 안전망으로 나눠, 무엇을 막고 묻고 기록하는지 한 장으로 정리합니다.관리자 정책조직 공통 규칙을 PC의 정책 파일로 배포하는 방법, 게이트웨이 3.4.0 이상의 관리 정책 화면, 둘이 겹칠 때의 우선순위, 받았는지 확인하는 법입니다.
