권한 모드

Fortress AI 2.6.1 기준

이럴 때 봅니다

  • 에이전트가 실행 전에 어디까지 묻게 할지 정할 때
  • 확인 창이 너무 자주 떠서 줄이고 싶을 때
  • 어떤 모드에서도 묻거나 막는 것이 무엇인지 알고 싶을 때

는 에이전트가 파일을 고치거나 명령을 실행하기 전에 어디까지 묻는지 정하는 설정입니다.
웹 화면에서는 입력창 아래에 지금 모드가 표시됩니다.

무엇을 허용하고 묻고 막나​

따로 규칙을 두지 않았을 때의 동작입니다.

대상동작
작업 폴더 안의 파일 읽기허용
작업 폴더 밖의 파일 읽기물어봄
.env 파일 읽기물어봄
파일 수정, 읽기 전용이 아닌 명령물어봄. 샌드박스가 켜져 있으면 샌드박스 안에서 실행되는 명령과 그 쓰기는 자동으로 허용됩니다.
.git/ 안의 파일 수정항상 물어봄
예약 작업 만들기와 고치기물어봄
다른 대화의 목록⁠·⁠검색⁠·⁠읽기허용
다른 대화에 보내기, 새 대화 시작물어봄
문법으로 읽지 못한 명령 줄물어봄. 모든 모드에서 같습니다.
정책 파일 수정항상 거부
게이트웨이 로그인 파일 읽기와 수정항상 거부
세션 서버 접속 정보(~/.fortress/agent/server.json) 읽기와 수정항상 거부

실행 전에 묻는 모습​

"물어봄"이면 실행 전에 확인 창이 뜹니다.
내용을 읽고 허용하거나 거부합니다.

모드​

화면 이름명령에서 쓰는 이름동작
수동default위의 기본 동작. 편집 전에 묻습니다.
편집 자동 수락acceptEdits작업 폴더 안의 파일 수정은 묻지 않습니다.
계획plan읽기만 합니다. 파일을 고치거나 쓰는 명령을 거부하고, 살펴본 뒤 계획을 보여 줍니다. 문법으로 읽지 못한 명령 줄도 거부합니다.
권한 무시bypassPermissions물어볼 일을 허용으로 처리합니다. 거부 규칙과 정책 파일 보호는 그대로 적용됩니다.
묻지 않기dontAsk물어볼 일을 거부로 처리합니다. 문법으로 읽지 못한 명령 줄도 거부합니다.

모드 바꾸기​

  • 웹 화면에서는 입력창 아래의 모드 이름을 눌러 메뉴에서 고릅니다. Shift+Tab으로 차례로 바꿀 수도 있습니다.
  • 세션 중에는 입력창에 /mode <모드>를 입력합니다.
  • 시작할 때 정하려면 --permission-mode <모드>를 붙여 실행합니다.
  • 새로 여는 세션이 처음부터 쓸 모드는 설정 › 일반 › 새 세션의 권한 모드에서 고릅니다.
예
/mode acceptEdits

모드와 상관없이 묻는 것​

bypassPermissions 모드에서도 아래 두 가지는 실행 전에 묻습니다.

  • 문법으로 읽지 못한 명령 줄. 명령 치환, 반복문, heredoc 안의 명령은 하나씩 읽어 판정합니다. 함수 정의처럼 읽지 못하는 형식이 든 줄은 샌드박스 안에서도 묻습니다. 계획과 묻지 않기 모드에서는 거부합니다.
  • 되돌릴 수 없는 삭제. 루트와 그 한 단계 아래 폴더, 홈 폴더, 작업 폴더와 그 위 폴더를 지우거나 모두 비우는 명령입니다. Windows의 rd, PowerShell의 Remove-Item과 그 별칭도 같습니다.

확인하는 법​

  • 지금 모드는 웹 화면의 입력창 아래에 보입니다.
  • 무엇이 허용되고 거부됐는지는 감사 로그에서 모드와 함께 봅니다.

사람 없이 실행할 때​

화면 없이 실행하면 물어볼 수 없어서 "물어봄"이 거부로 처리되고, 멈춰서 기다리지 않습니다.
파일을 고치게 하려면 acceptEdits 모드나 허용 규칙을 씁니다.

다음에 볼 글

권한 규칙허용, 물어봄, 거부 규칙을 쓰는 문법과 평가 순서, PowerShell 규칙, 거부 규칙과 샌드박스의 관계, 규칙이 막지 못하는 경우입니다.폴더 신뢰처음 여는 폴더를 신뢰할지 정하는 폴더 신뢰와, 결정에 따라 달라지는 동작, 결정을 확인하고 바꾸는 법입니다.샌드박스샌드박스가 에이전트의 명령에서 무엇을 막고 무엇은 다른 장치에 맡기는지, 켜져 있는지 확인하는 법입니다.
